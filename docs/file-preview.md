# ファイルを会話の横で読む

## 範囲（2026-09-15）

ファイルリンクは右パネルで開く（HTML だけは例外で、ブラウザーで開き、右パネルは原文と保存。下の「HTML の開き先」）。Markdown・HTML（原文）・画像/SVG・CSV/TSV・コード/テキスト・PDFに対応。原文切替、行指定、再読み込み、完全パスの確認、保存、幅変更、全面表示、会話への添付、狭い画面の全面プレビューを実装した。Office文書の変換表示は未対応で、保存を案内する。

取得は認証付き `/file-preview`、保存は既存 `/local-file` を使う。テキストはUTF-8で8 MiB、画像/PDFは32 MiBまで。原文は最大5000行（指定行の周辺を優先）、表は見出しと先頭500行・100列までを表示する。保存も32 MiBが上限。パネルは現在のファイルの取得時刻を表示し、自動では再取得しない。

HTML ファイルは右パネルでは描画しない（原文と保存だけ。2026-10-14、[ADR 0206](adr/0206-html-route-and-remote-browser-panel.md)）。動かして見るのはブラウザーのタブで、可視化の写しは今も[可視化](visualize.md)と同じ隔離（[ADR 0009](adr/0009-sandboxed-html-with-scripts.md)、[ADR 0042](adr/0042-preview-loads-external-by-default.md)）で実行する。以下の iframe の隔離の説明は可視化の枠の方針の記録で、HTML ファイルのパネルには適用しない。iframe は `sandbox="allow-scripts"` だけで `allow-same-origin` を付けず、`referrerpolicy="no-referrer"` と同じ `allow` 指定を持つ。CSP は可視化と共通で、既定では HTTPS の画像・スクリプト・スタイル・フォント・通信・埋め込み・メディア・worker を許し、object・base・フォーム送信は止める。`<script>` とイベント属性は残す。ローカルの `<script src>` は認証経由で読み、スクリプト本文として埋め込む（各512 KiBまで。読めないものは省いて注記する）。ローカル画像・CSSも認証経由で解決して埋め込む。HTTPS の画像・stylesheet・CSS import・URL・メディアは残す。フレーム・`<base>`・`meta http-equiv`・フォームは除き、ローカルのリンクは原文で確認する。枠内の http/https リンクは親が送り元を確認して設定の開き先（[内蔵ブラウザー](inapp-browser.md) / 既定のブラウザー）で開き、`#…` は枠内で動く。補助資源は24件・合計8 MiBまで、画像は各4 MiB、CSS・スクリプトは各512 KiBまで。省いた資源はパネルに表示する。Markdown内のファイルリンクはその文書のフォルダーを基準に開く。

ファイルの操作とパスの自動リンク（2026-09-23、承認済み）。ファイルが見える所（右パネルの頭の ⋯、ツリーの行の ⋯ と右クリック、ディレクトリのカード、会話のファイルリンク・画像）で同じメニューを開く: 右パネルで開く／ブラウザーで開く（HTML）／エクスプローラーで表示（フォルダーは「開く」）／パスをコピー／相対パスをコピー／保存／会話で使う。画像（本文の `![](…)`・Codex の生成画像・添付）はパスを持ち、下に所在の一行（ファイル名のリンク・フォルダー・⋯）を添える。押したときは今までどおり拡大表示で、下端にフルパスとコピー・右パネルで開く・エクスプローラーで表示・保存を並べる（パスの無い data URI の画像は保存だけ）。自動リンクは `web/file-reference.mjs` の厳しい判定（`looksLikePath`・`findWindowsPaths`）で、インラインコードの中身全体が 1 つのパス（ドライブ文字始まり、`./` `../` 始まり、区切りを含み最後が既知の拡張子）と、地の文の Windows の絶対パスだけ（日本語・空白・括弧で止め、末尾の句読点を外す）。コードブロックとリンクの中は対象外。読む・書く・編集の対象と添付の元パスもファイルリンクにする。自分の発言も同じ判定でリンクにする（2026-09-27。Markdown としては解釈せず、字は書いたとおり。`web/render.mjs` の `plainTextHtml`）。存在は押したときに右パネルが確かめる。

作業ディレクトリのツリーは畳んだ状態で開き、頭の行のフォルダーのボタンで開く（2026-09-27）。開くと今のファイルまで祖先を開いて、その行を見える位置へ送る。開閉は同じパネルの中では保ち、閉じたら畳みに戻る（design-system.md「ファイルプレビュー」）。

OS の操作（エクスプローラー・既定のブラウザー）はサーバーのある PC で動くので、その PC の画面から見ているときだけ出す（[ADR 0010](adr/0010-os-actions-only-on-host-screen.md)）。サーバーは WebSocket の接続ごとに接続元がループバックで中継のヘッダーが無いかを記録し（`core/os-open.mjs` の `isLocalRequest`）、`hostCapabilities` で画面に伝え、`revealPath`／`openPath` は遠隔の接続から断る。パスは `/file-preview` と同じ許可範囲・同じ相対の解き方で、実体を解決した後の値を渡す。「ブラウザーで開く」は `.html/.htm` のファイルだけ（既定のアプリで開くと `.bat` や `.lnk` が実行されるため）。内蔵ブラウザーを選んだデスクトップ版では、`openPath` の `returnPath:true` で OS を起動せず実体パスと作業ディレクトリを返し、`file:` URL を内蔵ブラウザーのタブで開く。同じフォルダーの相対 CSS・JS・画像も読める。ほかの画面では従来どおり既定のブラウザーで開く。Windows のブラウザー版は `%SystemRoot%\explorer.exe` に `/select,"…"` をシェルを通さずそのまま渡す（`cmd /c start` は使わない。終了コードでは失敗と判定しない）。デスクトップ版の既定のブラウザーへの経路は本体が形を確かめ直して `shell.showItemInFolder`／`shell.openPath` で実行する。10 秒に 5 回までに制限し、失敗は画面下の短い知らせで示す。

PDFはPDF.jsを開いた時だけロードし、ページ移動・拡大縮小・ページ内テキスト表示を提供する。ブラウザー資源をローカル配信し、CDNに依存しない。Node 20系と互換のある5.5.207を固定（追加時のnpm auditでPDF.jsの既知の脆弱性なし）。開発環境の下限は依存の要件に合わせNode.js 20.19.0。APIの参考: [PDF.js examples](https://mozilla.github.io/pdf.js/examples/)。

同じパネルは、会話の git（ブランチ・この会話でしたこと・変更の一覧と統一差分）にもなる（2026-10-03、[ADR 0085](adr/0085-host-reads-git-and-turn-snapshots.md)。枠の表は `gitSlots`、中身は `web/git-panel.mjs`）。差分は `/file-preview` ではなく WS の `gitDiff` で取り（統一差分をハンクの行に構造化して返す）、色を付けない。ファイルの「現在のファイルを読む。取得時刻を表示し、再読み込みは明示操作」の原則と同じく、取得時刻を下の行に出して再読み込みで取り直す。コミットの行は押すとその直下に変わったファイルの箱が開き（同時に 1 つ）、ファイルを押すとこのパネルの中で差分が開く。左右の差分は常に折り返し、新規・削除だけのファイルは 1 列で見せる（2026-10-09）。詳細は `docs/design-system.md`「git の動き」。

デスクトップ版のホストの画面では、同じパネルを Web ページの[内蔵ブラウザー](inapp-browser.md)にもする（2026-09-27、[ADR 0041](adr/0041-inapp-browser-beside-conversation.md)）。

### HTML の開き先

承認済み（2026-10-14、[ADR 0206](adr/0206-html-route-and-remote-browser-panel.md)。2026-10-02 の [ADR 0079](adr/0079-html-opens-in-inapp-browser.md) の開き先を置換）。HTML ファイルのリンク（会話・ツリー・ディレクトリのカード・Markdown の中・パスの札・添付・コンテキストの「開く」）と、ファイルのメニューの「ブラウザーで開く」、可視化のカードの「ブラウザーで開く」は、すべて `web/file-preview.mjs` の `htmlRoute` 1 か所で開き先を決める。

- ホストの画面で「リンクの開き先 = 内蔵ブラウザー」: 内蔵ブラウザーのタブ。同じ実体パスのタブがその会話にあれば前に出して読み直す。リンクには「表示中」を添える。
- ホストの画面で「リンクの開き先 = 既定のブラウザー」・ホストの PC の普通のブラウザー: 既定のブラウザー。右パネルのプレビューは経ない。設定の「外部の読み込みの前に確認」は外のブラウザーには効かない（設定の説明に書く）。
- リモートの端末でホストが内蔵ブラウザーの映像を送れる: ホストの内蔵ブラウザーにこの会話のタブを足し（ホストの窓は前に出さない）、右パネルの「ブラウザー」でその映像を見る。
- リモートの端末でホストが映像を送れない（`npm start`）: 右パネルの原文と保存だけ。
- Ctrl/⌘+クリックと中クリックは、設定によらず既定のブラウザー（ホストの画面）。ファイルのメニューの HTML は「ブラウザーで開く」が先頭で、右パネルで開くものは「原文を見る」。

右パネルの HTML は原文（行番号付き）と保存・パス・会話で使うだけで、プレビューとの切り替えは無い。sandbox の描画・外部の読み込みを止める一行・「読み込む」は、ブラウザーのタブ（内蔵ブラウザーの PC のファイルのタブ。[内蔵ブラウザー](inapp-browser.md#pc-のファイルのタブhtml-ファイル可視化の写し)）の側にある。プレビューで動かなかったもの（http の資源・フォームの送信・`localStorage` などのストレージ・ポップアップ・ページの遷移）は、ブラウザーのタブでは動く。

同じパネルで[可視化](visualize.md)も開く（2026-09-16）。こちらは保存済みのスナップショットを `sandbox="allow-scripts"` で実行する。HTMLファイルも同じ隔離で動くが、こちらは現在のファイルを読む。読む対象が違うので、可視化では再読み込み・原文・会話で使うを出さず、「保存済みの可視化」と示す。保存はホストへ取りに行かず、会話に残っている内容を渡す。開いている間は会話の「サイドパネルに表示」に印を付け、閉じるとそこへフォーカスを戻す。

枠の操作（広げる／会話と並べて表示、閉じる／会話へ戻る）はアイコンにし、名前は title と aria-label に持たせる。パス欄にはコピーを置き、成功した場合だけボタンの上で知らせる。プレビュー／原文と下端の保存・会話で使うは文字のまま。

相対リンクは発言の時刻と作業場所の変更履歴から解決する。変更履歴があるのに時刻がない場合は場所を推測せず絶対パスを案内する。作業場所外の絶対パスも読める。明示された別 OS のパス、UNC・デバイスパス、Pleiad のデータ置き場（添付の uploads を除く）は拒否する。UNC・デバイスパスは実パスの解決前後に、データ置き場はリンクを解決した実パスで検査する。文書内リンクの基準となるファイル、一覧とツリーにも同じ検査を適用する（[ADR 0050](adr/0050-local-file-access.md)）。別会話や設定へ移動するとプレビューを閉じる。読み込みのキャンセルと世代番号で、遅い応答が次のファイルを上書きするのを防ぐ。

検証: パス・行指定・CSV・認証・作業場所の履歴・欠損・上限・symlink・保存・PDF資源配信を通常テストに追加。fakeサーバーを使い、実ファイルをクリックして表示、HTMLのCSS/画像と隔離、PDFの2ページ表示、保存、下書き保持、幅変更、360px表示、フォーカス復帰をplaywright-cliで確認する。

## 基本動作

- 普段は通常の会話。ファイルリンクには小さなファイル記号を添える。生のパスがリンクとして認識された場合も同じ入口とする。Web サイトへの通常リンクは従来の扱い。
- 押したファイルを右の一枚のパネルに表示する。次のファイルを押すと同じ場所で切り替わる。開いているリンクには「表示中」を添える。タブ列やファイル一覧は最初から増やさない。
- パネル幅は初期約48%。会話を最低360px確保し、境界のドラッグと左右キーで調整。「広げる」で読む面を広げ、同じボタンで会話との並列表示に戻す。
- 会話とプレビューは別々にスクロール。切り替えても会話の位置と下書きを保持。閉じる／Esc は元のリンクへフォーカスを戻す。入力欄の IME 変換中の Esc は奪わない。
- 見出しはファイル名、下に作業ディレクトリからのパス。長い名前は折り返す。完全パスは「パス」で確認・選択できる。コピーに成功した場合だけ成功を表示する。
- 「会話で使う」で入力欄へファイル参照を追加する。既存の下書きは保持し、自動送信しない。ファイル名だけから参照先を曖昧に推定せず、内部では完全パスを保持する。
- 760px 以下は画面内の全面プレビューに切り替え、ヘッダーの「会話へ」で戻す。背景にはフォーカスを移さない。会話で使う操作でも会話に戻る。

## ファイルと状態

| 種類・状態 | 最初の表示 | 次の操作 |
|---|---|---|
| Markdown | 見出し・表・リストとしてレンダリング | 原文と切り替え |
| HTML | ブラウザーのタブで開く（右パネルは原文と保存だけ） | 原文 |
| 画像 / SVG | 全体が収まるサイズ、寸法を表示 | 拡大・縮小 |
| CSV / TSV | 行・列を保持した表 | 原文と切り替え。大きな表は表示範囲を明示 |
| ソース / テキスト | 行番号つきの原文 | `:42` / `#L42` の指定行を強調しスクロール |
| PDF | ページとして表示 | ページ移動・拡大 |
| DOCX / XLSX / PPTX など | 未対応。ファイル名と理由 | 保存 |
| 読み込み中 | ファイル名は先に確定、「読み込み中…」 | 閉じる・別ファイルへ切り替え可 |
| 存在しない | 「ファイルが見つかりません」と探したパス | 再読み込み、パス確認 |
| 読み取り不可 | 「このファイルを読み取れません」と原因 | 接続先・アクセス権の確認へ |
| 大きすぎる / 未対応 | 制限・形式とファイル名 | 保存。本文としてバイナリを見せない |

## 読む対象の意味

リンクは**ホスト上に現在あるファイル**を読む。会話の過去時点の写しではない。取得時刻を表示し、再読み込みは明示操作にする。自動更新で読んでいる箇所を動かさない。Visualize の保存済みスナップショットとは区別する。

実装ではメッセージに対応する作業ディレクトリを使い、Windows ドライブ・POSIX 絶対パス・相対パス・空白・日本語・行番号を正規化する。ブラウザーの URL を基準に解決しない。別マシン上のパスをローカルと決めつけない。異なるディレクトリにある同名ファイルへ推測でフォールバックしない。

ファイル取得は既存の認証付きホスト経由。HTML/SVG は親画面から隔離し、トップ画面への遷移・ホスト権限を渡さない。HTML の外部通信は確認の設定に従う。相対画像・CSS の扱いはホストで許可範囲を解決し、表示できない資源は明示する。HTML ファイルのスクリプトは既存 Visualize の分離方針（opaque sandbox・同じ CSP）で実行する。


## HTML の外部読み込みの確認

設定 › ブラウザーの「外部の読み込みの前に確認」は、内蔵ブラウザーで開いた PC の HTML ファイル（リモートの端末からホストの内蔵ブラウザーで開いたものも）と可視化に効く。既定のブラウザーで開いた HTML ファイルには効かない（既定 OFF、デスクトップ以外の画面でも利用可。内蔵ブラウザーの側は [内蔵ブラウザー](inapp-browser.md#pc-のファイルのタブhtml-ファイル可視化の写し)）。ON のときは常に許可した HTTPS origin だけを CSP に含める（http は localhost も止まる）。止めた資源は本文の端の一行「外部の読み込みを N 件止めています」にまとめ（件数には http も数える。「読み込む」は https があるときだけ出す）、「読み込む」でその表示だけの許可を加えて描き直す。「設定」は許可したサイトへ移り、止めた出どころを「許可」付きで示す。枠からの通知は送り元を照合する。ローカル資源の埋め込みと sandbox の分離は変えない。詳しい方針は [可視化](visualize.md#外部の読み込みの確認) と共通。
