# ファイルを会話の横で読む

会話のファイルリンクは、その会話の Chrome のタブで開く。ファイル・フォルダーは Pleiad のページとして表示し、Web・可視化・git・プラグインと同じタブの列に並べる。Chrome が無い会話では同じページを本体の iframe で開き、接続を求めない。共通の枠と操作は [会話のブラウザー](inapp-browser.md) を参照。

## 読む内容

ファイルのページは Markdown・画像・SVG・CSV/TSV・コード・テキスト・PDF を表示する。プレビューと行番号付きの原文を切り替え、行指定・保存・パスのコピー・会話で使う操作を備える。Office 文書は変換せず保存を案内する。PDF の表示資源はローカルに配り、開いたときだけ読み込む。

ファイルは表示した時点の内容を読む。取得時刻を出し、再読み込みは人の明示操作にする。同じ実体パスをもう一度開くと、そのタブを選ぶだけで読み直さない。遅れて届いた取得結果が別のファイルを上書きしないよう、取り消しと世代番号を使う。

| 内容 | 上限 |
|---|---|
| UTF-8 のテキスト | 8 MiB |
| 画像・PDF・保存するファイル | 32 MiB |
| 行番号付きの原文 | 5000 行。指定行の周辺を優先 |
| 表 | 見出しと先頭 500 行・100 列 |

フォルダーのページは名前・更新時刻・大きさを並べる。ファイルのツリーは必要なとき開き、現在のファイルまで祖先を開いて該当する行を見える位置へ送る。アドレスバーには PC で絶対パス、スマホで作業場所からの相対パスを出す。プレビュー／原文の切り替えは PC のアドレスバー、スマホの ⋯ に置く。

## パスの解決と検査

相対パスは発言の時刻と、会話の作業場所の変更履歴から解決する。変更履歴があるのに時刻が無い場合は推測せず、絶対パスを案内する。Markdown 内の相対リンクは、その文書のフォルダーを基準にする。作業場所の外の絶対パスも読める。

ファイルの検査は、実パスの解決前後で UNC・デバイスパスを拒み、実パスが Pleiad のデータ置き場に入る場合も添付の uploads 以外を拒む。文書内のリンク、一覧、ツリー、HTML の資源にも同じ検査を適用する（[ADR 0050](adr/0050-local-file-access.md)）。

会話のパスの自動リンクは、パスと分かるインラインコードと Windows の絶対パスに限る。コードブロックやリンクの中は対象にしない。自分の発言も同じ規則でリンクにし、存在は押したときに確かめる。画像や添付には、名前・フォルダー・⋯ の所在の行を添える。

## HTML のファイル

HTML のファイルは Pleiad の外枠の中で、別の出どころの iframe として実行する。Chrome のタブのアドレスと履歴には外枠の URL を残し、資源を読む鍵を表へ出さない。原文と描画を切り替えられる。Chrome が無い会話も、同じ外枠と隔離した iframe を使う。

HTML の鍵は 128 bit の乱数で、元の HTML のフォルダーに結び付ける。隔離のリスナーの `/f/<鍵>/<相対パス>` から読み、要求ごとに実パスとファイルの検査を行う。鍵はメモリーだけに持ち、24 時間またはサーバーの再起動で失効する。現在のファイルを読むので、保存済みの [可視化の束](visualize.md#保存する束) とは別である。

HTML の iframe と応答の Content Security Policy（CSP）は `sandbox allow-scripts` にし、`allow-same-origin` を付けない。保存領域・親画面・ポップアップ・上位ページの移動などへ権限を渡さない。外部の読み込みの確認は [可視化](visualize.md#外部の読み込みと隔離) と共通にする。Markdown は安全な要素へ絞り、SVG は画像として読む。

## ファイルのメニュー

ファイルの ⋯・右クリック・Shift+F10 は同じメニューを開く。題はパスで、外で開く操作、パス／相対パスのコピー、保存、会話で使う操作をまとめる。使えない操作は出さない。画像の拡大表示でも同じパスの操作を使う。パスの無い画像は保存だけにする。

外で開く操作は、サーバーのある PC の画面でだけ使える。エクスプローラー／Finder で表示するほか、HTML は既定のブラウザーで開ける。フォルダーは一度限りの入場券を使い、Pleiad のフォルダーのページを既定のブラウザーで開く。入場券と Cookie の規則は [会話のブラウザー](inapp-browser.md#pleiad-のページと認証) に従う。

既定のアプリで開く操作は、サーバーが `defaultAppAllowed: true` とした種類だけに出す。任意のパスを OS へ渡さない。実体パス・許可範囲・ローカルの人からの操作かをサーバーで検査し直す。リモートの端末には、ホストの OS を開く操作を出さない。

## ページの配信

ファイルのページは `/_pleiad/s/<会話>/<file|dir>` で配り、取得には既存のファイルの検査を使う。Chrome では派生 Cookie を使うページ専用の出どころ、Chrome が無い会話とスマホでは本体と同じ出どころを使う。URL に本体の鍵を付けない。入口の Host・Cookie・`Sec-Fetch-Site` の検査は [ADR 0295](adr/0295-pleiad-page-origins.md) に従う。

git・プラグイン・新しいタブも同じ Pleiad のページとして開く。git の差分はファイルの原文とは別に読み、取得時刻と再読み込みを出す。PR の表示は [git の PR](git-panel-pr.md) を参照。
