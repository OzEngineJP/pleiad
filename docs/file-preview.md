# ファイルを会話の横で読む

会話の右の欄は、利用者が開くファイル・フォルダー・git・プラグイン・HTML・可視化を端末内のページとして描く。PC・スマホ・Chrome が無い会話で同じタブを使い、開いただけでは会話の Chrome にタブを作らない。エージェントが開いた Web のタブは Chrome の映像で表示する。 共通の枠と操作は [会話のブラウザー](inapp-browser.md) を参照。

## 読む内容

ファイルのページは Markdown・画像・SVG・CSV/TSV・コード・テキスト・PDF を表示する。プレビューと行番号付きの原文を切り替え、行指定・保存・パスのコピー・会話で使う操作を備える。Office 文書は変換せず保存を案内する。PDF の表示資源はローカルに配り、開いたときだけ読み込む。

ファイルは表示した時点の内容を読む。取得時刻を出し、再読み込みは人の明示操作にする。同じ実体パスをもう一度開くと、そのタブを前に出して読み直す（入力のあるタブだけは「更新を表示」。[ADR 0320](adr/0320-browser-file-reread-and-loading-display.md)）。遅れて届いた取得結果が別のファイルを上書きしないよう、取り消しと世代番号を使う。開いているファイル・フォルダーがディスク上で変わると（`core/page-watch.mjs` → `page:changed`）、画面の中のタブでは、まだページに触れていなければそのまま読み直し、触れていれば「更新を表示」を出して人の操作を待つ。Chrome の映像に切り替えたページには `pleiad:page-command` が届き、ページが同じ規則で読み直し・通知を出す（web/pages/app.mjs）。入力済みのページを更新・移動・閉じるときは確認する。

| 内容 | 上限 |
|---|---|
| UTF-8 のテキスト | 8 MiB |
| 画像・PDF・保存するファイル | 32 MiB |
| 行番号付きの原文 | 5000 行。指定行の周辺を優先 |
| 表 | 見出しと先頭 500 行・100 列 |

フォルダーのページは名前・更新時刻・大きさを並べる。アドレスバーには PC でもスマホでも絶対パスを出し、狭ければ祖先から省く。プレビュー／原文は PC のアドレスバー、スマホの ⋮ に置く。

ファイルのツリーは、右の欄が 640px 以上ならページの左側、狭ければページに重ねて出す。並べるときの初期幅は 208px、160〜320px かつ欄の 40% 以内で、境界のドラッグか左右キー（16px 単位）で変える。開閉と幅は会話ごとに覚える。重ねるときは 280px（欄の右端に少なくとも 48px を残す）で、保存した幅は変えない。矢印は選択と枝の開閉だけを行い、クリック・Enter は現在のタブ、Ctrl／⌘＋クリック・中ボタン・Ctrl／⌘＋Enter は新しいタブで開く。同じ実体パスのタブがあれば選ぶ。「現在のファイルへ戻る」「すべて畳む」、行の ⋮・右クリック・Shift+F10 を備える。狭い画面では Escape で閉じてツリーのボタンへフォーカスを戻す。

## パスの解決と検査

相対パスは発言の時刻と、会話の作業場所の変更履歴から解決する。変更履歴があるのに時刻が無い場合は推測せず、絶対パスを案内する。Markdown 内の相対リンクは、その文書のフォルダーを基準にする。作業場所の外の絶対パスも読める。

ファイルの検査は、実パスの解決前後で UNC・デバイスパスを拒み、実パスが Pleiad のデータ置き場に入る場合も添付の uploads 以外を拒む。文書内のリンク、一覧、ツリー、HTML の資源にも同じ検査を適用する（[ADR 0050](adr/0050-local-file-access.md)）。

会話のパスの自動リンクは、パスと分かるインラインコードと Windows の絶対パスに限る。コードブロックやリンクの中は対象にしない。自分の発言も同じ規則でリンクにし、存在は押したときに確かめる。画像や添付には、名前・フォルダー・⋮ の所在の行を添える。

## HTML のファイル

HTML・htm のファイルは `pageOpen` が返した URL を、画面内の iframe で開く。アドレスバーにはパス、タブにはファイルの印を出し、隔離 URL を表示名に使わない。「Chrome の映像」を選んだときも同じ返却 URL を使う。

HTML の鍵は、フォルダー・入口・会話・「一度だけ読み込む」の出どころを AES-256-GCM で閉じた自己完結の文で、元の HTML のフォルダーに結び付ける。隔離のリスナーの `/f/<鍵>/<相対パス>` から読み、要求ごとに実パスとファイルの検査を行う。期限は 24 時間。秘密は `page-secrets.json` にあるので、サーバーの入れ替えをまたいでも引ける。現在のファイルを読むので、保存済みの [可視化の束](visualize.md#保存する束) とは別である。

HTML の iframe はアプリごとの専用の出どころ `f<フォルダーの印>.localhost`（`core/isolated-origins.mjs`。フォルダーの HMAC。パスは出さない）で動き、応答の CSP と iframe の sandbox は `allow-scripts allow-same-origin allow-downloads allow-forms allow-modals allow-popups allow-pointer-lock`（`APP_SANDBOX`）。`allow-same-origin` が付くので localStorage・相対パスの資源・fetch はその origin の中で本物が効く。上位ページの移動（`allow-top-navigation`）は渡さず、camera・microphone・geolocation・clipboard は Permissions-Policy で止める。外部の読み込みの確認は [可視化](visualize.md#外部の読み込みと隔離) と共通にする。隔離の出どころの port が替わると `page:moved` で行き先を付け替え、元ファイルの更新は `page:changed` で届く。Markdown は安全な要素へ絞り、SVG は画像として読む。

## ファイルのメニュー

ファイルの ⋮・右クリック・Shift+F10 は同じメニューを開く。題はパスで、外で開く操作、パス／相対パスのコピー、保存、会話で使う操作をまとめる。使えない操作は出さない。画像の拡大表示でも同じパスの操作を使う。パスの無い画像は保存だけにする。

外で開く操作は、サーバーのある PC の画面でだけ使える。エクスプローラー／Finder で表示するほか、HTML は既定のブラウザーで開ける。フォルダーは一度限りの入場券を使い、Pleiad のフォルダーのページを既定のブラウザーで開く。入場券と Cookie の規則は [会話のブラウザー](inapp-browser.md#pleiad-のページと認証) に従う。

既定のアプリで開く操作は、サーバーが `defaultAppAllowed: true` とした種類だけに出す。任意のパスを OS へ渡さない。実体パス・許可範囲・ローカルの人からの操作かをサーバーで検査し直す。リモートの端末には、ホストの OS を開く操作を出さない。

## ページの配信

通常のファイル・フォルダーのページは、PC・スマホ・Chrome が無い会話とも本体と同じ出どころの `/_pleiad/s/<会話>/<file|dir>` で配る。Chrome の映像に切り替えたときはページ専用の出どころと派生 Cookie を使う。HTML・可視化は `pageOpen` の URL を使う。URL に本体の鍵を付けない。入口の検査は [ADR 0295](adr/0295-pleiad-page-origins.md) に従う。

git・プラグイン・新しいタブも同じ Pleiad のページとして開く。git の差分はファイルの原文とは別に読み、取得時刻と再読み込みを出す。PR の表示は [git の PR](git-panel-pr.md) を参照。
