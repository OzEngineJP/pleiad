# Devin のトークン実績

Pleiad 内の実績は、ライブの `usage_update._meta` に含まれる `cognition.ai/inputTokens`・`outputTokens`・`cachedReadTokens` を記録する。入力はキャッシュ読み込みを含む総量で、キャッシュはその内訳。`used` / `size` は文脈の占有量なので、消費トークンには換算しない。

Devin CLI 3000.11.92 の通知は直近のモデル呼び出し1回分。同じターンで複数回呼び出す場合は合計する。`session/prompt` の完了応答も最終呼び出しの値なので、合計へ追加したり合計を上書きしたりしない。途中送信による追加のモデル呼び出しも実績に含める。

重複は記録対象の3値で判定する。同値の連続通知と、同じ実績を含む `subagent_context` の更新は重複計上しない。応答・思考・ツール・ユーザー発言の更新を挟んだ通常の通知は、値が同じでも計上する。通知に呼び出しの識別子はないため、出来事を挟まずに届く同値通知は区別できない。履歴の再生は計上せず、新しい Pleiad ターンで集計をリセットする。

欠測や不正な値は不明のままにする。一部の呼び出しで値が欠けた項目は、そのターンの合計も不明とし、ゼロで埋めない。失敗・中断したターンでは届いた実績だけが記録され、未通知分は補完しない。更新前に計測されなかった過去分も補完しない。

サブスクリプションの使用率とは別の値であり、トークン数から残り枠や費用を推定しない。`totalCreditCost` / `totalAcuCost` は USD として扱わない。
