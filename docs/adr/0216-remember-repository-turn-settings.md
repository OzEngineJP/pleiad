# 0216 送った設定をリポジトリごとの次の会話に使う

- 状態: 承認（2026-10-16）

## 状況

全体の既定だけでは、リポジトリを替えるたびにエージェント・モデル・承認モードなどを選び直す。worktree で作業するリポジトリでも、新しい会話ごとに「worktree で始める」を押す必要がある。

## 決定

人が送ったターンのエージェント・モデル・エフォート・承認モード・Claude のアカウント・互換の接続先と、Pleiad の worktree の中で動いたかを、リポジトリの本体のパスをキーに覚える。Git 管理外ではフォルダー自身をキーにする。bot と委譲の子は覚えない。記録は `prefs.json` に最大 50 件を持ち、古く使ったものから落とす。

新しい会話はそのリポジトリの記録を使い、記録がなければ全体の既定を使う。開いている会話から同じリポジトリに作るときは、その会話の設定を優先する。送る前に作業場所を別のリポジトリへ替えたときは、手で選んだ項目を保って残りを切り替える。

前回 Pleiad の worktree で送ったリポジトリでは、新しい会話に worktree を予約する。送る前は軽い 1 行で知らせ、取り消せる。最初の送信直前に作り、作れなければ送らない。これは [ADR 0136](0136-worktree-opt-in.md) の決定 1 の例外とする。

## 理由

実際に送った設定だけを次の作業へ反映し、試しにチップを触っただけの選択を残さない。worktree は送るまで作らないので、空の会話がディスクを使わない。

## 影響

全体の既定は引き続き記録のないリポジトリに使う。worktree の予定は送信前に見え、× で元の場所を選べる。
