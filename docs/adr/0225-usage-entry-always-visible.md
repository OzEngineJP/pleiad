# ADR 0225: 使用量の一覧への入口を常設する

## 状態

承認（2026-10-18）

## 状況

入力欄の上の使用量の札は、現在のエージェントの使用枠を表示できるときだけ現れていた。OpenCode の接続先などで枠を取得できない場合、ほかのエージェントの使用量の一覧を開く入口も消えていた。

## 決定

- 使用量の札は取得状況に関わらず常設する。現在のエージェントの使用枠があれば、使用率が最も高い枠をこれまでどおり出す。
- 互換の接続先、または表示可能な枠が無い場合は「使用量」＋未充填の棒＋「—」＋開閉の印を出す。ラベル・棒・値の配置は、値がある場合と揃える。狭い画面での省略も既存の規則に従う。
- 押すと、現在のエージェントを先頭に使用量の一覧を開く。枠が無いエージェントも省かず、初回取得中・取得不可・認可が必要な状態を示す。
- 別のエージェントの率で現在の札を埋めない。互換の接続先の行にはサブスクの率を出さない。
- 取得元、更新頻度、前回取得した値の保持、認可、設定の詳しい使用実績への入口は引き継ぐ。

## 理由

ほかのエージェントの使用量を確認する操作は、現在の会話で使うエージェントや使用枠の取得可否に依存しない。表示の形を揃えることで、取得できないときも同じ場所から同じ操作を続けられる。

## 影響

取得前・失敗後・枠なしでも札と一覧を保つ。表示可能な前回の枠は保持し、表示可能な枠が無いときは「—」で示し、0% と表示しない。使用量の取得処理や外部への問い合わせ回数は変更しない。
