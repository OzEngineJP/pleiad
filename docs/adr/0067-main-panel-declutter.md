# 0067 メインパネルの情報整理

- 状態: 承認（2026-09-30）。一部置換（[0301](0301-session-list-without-ai-label.md)、承認（2026-11-08））: 決定 6 の会話一覧の「AI」の印は廃止し、変更の記録は維持する。ほかの決定は引き続き有効。

## 状況

会話のログ（メインパネル）は、ツールの行・委譲カード・完了通知・発言者の行・添付の行・コンテキストの札など、本文でない行が本文と同じ濃さで並び、どこから発言が始まるかを目で探す作りになっていた。具体的には次の点が読みにくかった。

- ツールのまとまりの見出しが、件数・動詞の内訳・変更したファイル数・経過を全部出す。閉じた状態で読む人はほとんどいない。
- 本文でない行が本文と同じ `--ink` で、区別が付かない。
- 右端の時刻・結果・経過・開閉の印が、行ごとに 16px ずれる。時刻「00:35」と経過「0:00」が同じ等幅で縦に並び、区別が付かない。
- 委譲の状態が 5 か所に出て、経過が「14 分」「1:38」「1:37」と 3 つの形になる。「実行中」の字が 3 回繰り返される。
- 会話の中のコンテキストの札が、タイトル行のプラグインのアイコンと入口として 2 重になる。
- 書体: `--font` の先頭が `system-ui` で、日本語の Windows では欧文まで Yu Gothic UI で描かれ、バックスラッシュが「¥」の字形になる。等幅の欄の中の日本語は MS Gothic に落ちる。ファイルのリンクの「▧」はどの書体にも無く Meiryo に落ちる。
- 分岐ボタンが発言者の行とツールの行に重なる。長い発言の畳みは、続きがあるのに終わった文に見え、開くと「折りたたむ」が途中に残る。送った直後の添付画像は、パスの行が画像に替わって高さが跳ねる。

## 決定

3 段に分けて実装する。この ADR は 3 段分の決定をまとめて記録し、後の段はこの ADR を参照する。形は 2026-09-30 にモック（`temporary/mockups/main-panel-declutter.html`）で承認された。

1. **まとまりの見出し**: 「≡ ツール実行 N」だけ。件数は見出しの語の後ろの弱い字の数字（丸いバッジにはしない。100 以上は「99+」）。読み上げ名は「ツール実行 12 件」。内訳・変更数・終わった後の経過は出さず、右端は失敗のときの「✕ 失敗 N」と走っている間の経過だけ。
2. **沈め方**: 不透明度 .7 で、畳んでいるものだけ。開いた中身・失敗の印・承認待ち・走っている行は沈めない。触れる・焦点・開いているときは 1。コントラスト比は弱い字で白地 3.14:1・ダーク 3.40:1（3:1 を守る最小の刻み）。
3. **時刻・右端**: 時刻は触れている・焦点があるときだけ（タッチは発言を押すと 4 秒・⋯ のメニューの先頭）。経過と状態は常に。右端は値の列と、幅 24px の操作の列の 2 列。
4. **委譲**: 閉じたカードは 1 行・状態は印。委譲先のロゴは題の前（カード・一覧の行・完了通知でそろえる）。完了通知は ✓ / ✕ の印だけ。経過は m:ss。
5. **子の詳細**: 依頼と追加の指示は自分の発言と同じ部品。追加の指示は途中送信で差し込み、メインパネルの作業中の送信と同じ状態の行。差し込めないときだけ末尾で時計の印。
6. **添付・コンテキスト・出来事の行**: 添付は「📎 N ▾」。コンテキストの札は会話から外す。設定の変化を知らせる行は出さず、失敗だけ残す。「AI が変えた」は脇の行の「変更の記録」と状態の語の「AI」の印。
7. **ロゴと書体**: 発言者の名前の左にロゴ。欧文は Segoe UI、日本語は Yu Gothic UI。等幅はコードそのものだけ（閉じたツールの行の主役も UI の書体）。`--font-mono` に日本語の書体。「▧」は SVG に。
8. **分岐とコピー**: 分岐とコピーは発言者の行の ⋯ と右クリック（長押し）のメニュー。⋯ からの分岐はその返答の終わりから。コピーは返答全体の本文の Markdown。原文はメニューからモーダル。
9. **その他**: 言語札は右上に重ねる。狭い幅の溝は 40px。長い発言はフェードの上にシェブロンだけ。エージェントの返答は畳まない。同じ部品を委譲の「依頼」に。
10. **送った直後の画像**: 枠 → 光 → フェード。読めなかったら同じ枠で「もう一度」。画像以外は札をすぐ出す。

1 段目の実装は 1（見出し）・2・3（時刻と右端。⋯ のメニューの先頭の時刻を除く）・6（添付の行の「📎 N ▾」・コンテキストの札）・7（ロゴと書体）・9（言語札と溝）。残りは後の段で、その段の変更はこの ADR を参照する。

## 理由

- 見逃すと困るのは、失敗と待ちと、走っていること。それ以外は、開けば分かる情報を閉じた状態で本文と同じ濃さで出す必要がない。畳んだものを沈め、触れたら戻す形は、内容を消さずに本文を目で拾いやすくする。
- 時刻を触れたときだけにすると、右端に残るのは経過・状態だけになり、時刻と経過が同じ形で並ぶ混乱が消える。場所は取ったままなので並びは動かない。
- 欧文と日本語を 1 書体ずつにすると、バックスラッシュが円記号の字形に化ける問題と、等幅の中の日本語が MS Gothic に落ちる問題が同時に解ける。等幅を残すのは、0/O・l/1・字下げの区別が意味を持つコードそのものだけにする。
- 件数を丸いバッジにすると目立ちすぎる（承認時の指摘）。見出しの語の後ろの弱い字なら、沈め方と同じ扱いで済む。

## 影響

- 会話の見た目が変わる。テストは「N 件」「実行 2」のような今の見出しの字を前提にしていたものを、新しい形に合わせる。
- 沈める規則は `:where()` で詳細度を 0 にして書く。戻す側（触れる・焦点）が詳細度で負けない代わりに、沈める側を足すときは同じ書き方に従う。
- 時刻の表示はホバー・焦点・押して 4 秒（`web/message-peek.mjs`）に頼る。ホバーの無い端末で、リンク・文字の選択・ボタンとぶつからないよう、それらの上の押下は無視する。
- コンテキストの札（`paintContextLine`・`.ctx-chip`）を除く。入口はタイトル行のアイコンだけになる。
- `--font` の順序が変わる。書体の見た目は、Windows の日本語環境で欧文が Yu Gothic UI から Segoe UI に替わる。
- 狭い幅の溝は 40px で、筋は x=20 のまま。分岐の曲線（`web/branch-view.mjs`）は溝の外の自分の行に描くので、そのまま動く。
