# 0265 稼働表示を会話の筋の末尾の節に戻し、印は弧と衛星のままにする

## 状態

承認（2026-10-24）。利用者が、元の弧・衛星の印と会話末尾の置き場所へ戻すよう依頼。

- 置き換えた: [0261](0261-wait-dot-and-composer-strip.md) の待ちの印（脈打つドットと流れる帯）と、待ち行を入力欄の上の段に置く部分。作業ボタンの常時背景を透明にすること、メーターの面、入力欄の8px上の1段に作業・文脈・使用量を置くことは 0261 のまま

## 状況

0261 で、待ちの印を本文色の脈打つドットに共通化し、送信・ツール・作業一覧・委譲カード・脇・接続・設定の弧と衛星もすべてドットに替えた。待ち行は入力欄の上の段の左に移し、文言の下に左から右へ流れる帯を添えた。

使ってみると、ドットの点滅はこのアプリの線画の印（§2.2）と馴染まず、裏の結果待ち（衛星、点の数が本数）と走っている間（弧）の区別も消えた。待ち行が入力欄の上に固定されたことで、最後の発言との間が離れ、筋（会話の時間の線）の末尾から状態が読めなくなった。右のパネルを開いて列が狭まると、待ち行と作業・メーターが同じ段で押し合い、文言が縦に折り返した。

## 決定

- 走っている印は `runMark()` の弧（約 115°、2 秒で 1 周）、裏の結果待ちは `satMark(n)` の衛星（点は本数、3 個まで、4 秒で 1 周）に戻す。台・輪郭は置かず、色は本文の文字色。呼び出し元はすべて 0261 の前の見た目に戻る。ドットの部品と帯の CSS は消す。
- 会話末尾の稼働表示は `#thread` の最後の子の節にする。筋は節の点（ほかの発言の節と同じ溝の中。直径 7px、PC は列の左から 20px・狭い画面は 12px）の中心で終わる。弧か衛星の左端はほかの発言の本文の左端（見出しの発言者名・段落と同じ列）に揃え、その 8px 右に文言を 1 行で置く。PC・スマホ・右のパネルで狭まった列のどれでも同じ揃え方。経過時間は PC で行の右端、狭い画面で文言のすぐ後ろ（短い文言でも間を空けない）。
- 行は上 4px + 高さ 24px。帯・40px の段は作らない。新しい発言は節の手前に入り、節は末尾のまま。読み取り専用の会話も同じ形。
- 入力欄の上の段（`#contextStrip`）は作業ボタン・文脈・使用量だけにし、出し入れは稼働表示の有無に左右されない。
- 段は画面幅ではなく段の幅で詰める。入り切らなければ `.compact`（480px 以下と同じ形）、それでも入らなければ `.tight`（メーターの棒を外し、札を縮める）。字は折り返さない。

## 理由

稼働表示は「この会話が今どこまで進んだか」を示すので、筋の先端にあるのが読みやすい。最後の発言のすぐ下に、本文と同じ列で置けば、目を動かさずに状態が分かる。印と文言を溝の側（画面の左端）に寄せると、本文の列から外れて釣り合いが悪い。弧と衛星は線画の族の印で、形で「考えている」と「裏を待っている」を分けられる。段の幅で詰めれば、右のパネルの有無や窓の幅に関係なく段が列に収まる。

## 影響

`web/wait-mark.mjs` を消し、`runMark()` / `satMark()` は `web/arc.mjs` の元の形に戻る。会話の末尾に待ち用の枠を確保しないことは 0261 のまま。データ形式・エージェントの実行には変更がない。
