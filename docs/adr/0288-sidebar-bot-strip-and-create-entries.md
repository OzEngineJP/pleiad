# 0288 脇の Bots を検索の下の帯にし、ルーティンを木の先頭へ、作る入口を見出しに置く

- 状態: 承認（2026-11-05。AsIs / ToBe のモックを利用者が承認。決める点は「全部お勧めで」: Bots の帯は名前付き、ルーティンは木の一番上の畳める見出しで最初は畳む、新しいチャットの近道は Ctrl+Shift+O／⌘⇧O）。[ADR 0251](0251-sidebar-place-tree.md) の決定 1 の並び順と、決定 5 の「Bots を隠す」を置き換える。一部置換（[0289](0289-sidebar-rail-p-mark-footer.md)、承認（2026-11-06））: 決定 5 の開閉ボタンの位置（頭の左端・閉じた後も同じ位置に開くボタン）は、閉じるボタンを通知の右に置き、閉じている間は P の印で開く形にする。ほかの決定は引き続き有効

## 状況

脇の置き場所の木（ADR 0251）は、一時チャット → チャンネル → Bots → ルーティンの順だった。チャンネルや会話が増えると、Bots とルーティンは木の一番下に押し出され、スクロールしないと届かなかった。利用者は Bots とルーティンが遠いこと、脇の開閉ボタンの位置と見た目、アイコンの置き場所を問題に挙げた。

また、Channels の節の見出しの ＋ でチャンネルを作る入口は、置き場所の木に統合した後は脇に出ておらず、画面からチャンネルを作る方法が無かった。頭の ＋（新しいセッション）と一時チャットの見出しの ＋（触れたときだけ出る）は同じ「新しいチャット」が 2 か所にあり、どちらも目立たなかった。

## 決定

1. Bots を木から出し、検索の下に名前付きのアイコンを横 1 段に並べる帯（`#botStrip`）にする。帯は木をスクロールしても隠れない。作業中は回る弧、あなた待ちは ◆。押すと DM、右クリック・Shift+F10 で bot のメニュー。帯の幅に入りきらない分は最後の枠の「+N」にまとめ、押すと全部の bot と「bot を作る」のメニューを出す。「+N」は隠れた bot の弧・◆ を引き継ぐ。入りきれば最後の枠は ＋（bot を作る）。
2. ルーティンを木の一番上の畳める見出しにする（一時チャット・チャンネルと同じ形）。最初は畳み、開閉は端末ごとに覚える。畳んでいる間は、走っているものの弧と直近の失敗の数「✕N」を見出しに出す。
3. 木の並びは、ルーティン → 一時チャット →「チャンネル ＋」→ チャンネル（名前順）にする。「チャンネル ＋」はチャンネルの並びの頭の見出しで、押すとその場に名前の欄を出して作り、作ったチャンネルの流れを開く。
4. 頭の ＋ を外す。新しいチャットの入口は一時チャットの見出しの ＋（常に見せる）と、Ctrl+Shift+O（macOS は ⌘⇧O）にする。どちらも絞り込みの条件（作業ディレクトリ・状態・1 つだけ絞ったエージェント）を引き継ぎ、近道は脇を閉じていても効く。
5. 脇の開閉ボタンを頭の左端に置く（閉じた後に開くボタンも同じ位置に出る）。頭と見出しのボタンは枠線の無いアイコンのボタンにする。
6. 絞り込んでいる間は、ルーティンと「チャンネル ＋」を木から外す（ADR 0251 の決定 5 のとおり）。Bots の帯は木の外なので出したままにする。

## 理由

Bots とルーティンは、チャンネル・会話の数に関係なく毎回使う入口なので、一覧の長さに押し出されない位置に置く。Bots は数が少なくアイコンで見分けられるため、横の帯にすると縦の場所をほとんど使わない。名前を付けるのは、アイコンが似た bot を見分けるため。ルーティンは毎回は開かないので、畳んだ見出しにして、知るべきこと（走っている・失敗した）だけを見出しに出す。

新しいチャットの入口を、それが入る場所（一時チャット）の見出しに 1 つにまとめると、どこに作られるかが分かり、頭の ＋ との重複も無くなる。キーボードの近道は、ブラウザーの Ctrl+N（新しいウィンドウ）とぶつからない Ctrl+Shift+O にする。チャンネルを作る入口は、チャンネルが並ぶ場所の頭に置く。

## 影響

保存形式・操作の一覧・会話とスレッドの正本は変えない。端末ごとの好みに `agent-host-side-routines-open`（ルーティンを開いているか）が加わる。頭の `#newSession` は一時チャットの見出しの ＋ に移る（id は同じ）。不要になった文言を辞書から外し、帯・「+N」・「チャンネル ＋」・「✕N」の文言を足す。画面の今の形は design-system.md「脇」と §4.1、docs/channels.md の脇（W1）に書く。
