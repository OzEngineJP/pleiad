# 0236 状態の移動・エージェント切替・新しい会話の帯の待ちを、止めず・古い値を見せず・揺らさずに見せる

- 状態: 承認（2026-10-20）
- 関連: [0228](0228-agent-picker-list.md)（エージェントの選び方）、[0160](0160-header-and-destination-chip.md)（宛先とモデルのチップと面）

## 状況

- 会話の状態やグループの移動は、保存に加えて一覧と入力欄の取り直しが終わるまで「移動中」だった。その間の続けた移動は捨てられ、保存が遅れると、古い値で表示を巻き戻した。
- エージェントを切り替えた後、取得が終わるまで前のエージェントのモデル一覧が残った。
- 新しい会話の帯は、「ほかの会話も書き込み中」などの付帯情報が、確認中・失敗・空を区別せず、会話の id が変わるたびに消えて取り直され、揺れた。
- 利用者が、挙動の方針と、スマホ幅の入力欄の 2 段の帯のモック（AsIs / ToBe）を承認した（2026-10-20）。

## 決定

- **移動は、受け付けた瞬間に最新の移動先を画面へ出す。** 保存は行ごとに 1 本ずつ順に流し、未送信の同じ対象の移動は最新の 1 件にまとめる。保存の応答で「移動中」を外し、一覧の取り直しは裏で行う。失敗は、後続の移動 → 最後に受けたサーバーの値 → 操作前の値の順で戻し、逆向きの書き込みで直さない。戻し先が確かでないときは「元に戻す」を出さない。
- **エージェントを切り替えた直後は、前のエージェントの選択肢を出さない。** 取れるまでは骨組みを出し、選択肢は押せない。取得は鍵（エージェント・接続先・アカウント・モデル・作業ディレクトリ）ごとに共有し、失敗を覚え込まない。最後に選んだエージェントは、保存の応答や取り直しの写しより優先して見せる（書く前の写しで前のエージェントへ戻さない）。
- **新しい会話では、選んだモデルと作業ディレクトリを作成の前後で変えない。** 付帯情報は「確認中」「取得できなかった」「確定」を区別し、確定したときだけ「ほかの会話も書き込み中」を出す。確認中・失敗を「書き込みなし」の顔で出さない。
- **480px 以下の入力欄の設定は 2 段にする。** 1 段目は宛先とモデル・承認モード（アイコンだけ）・送信、2 段目は作業ディレクトリ（全幅）。

## 理由

- 続けた操作を捨てると、利用者は何が反映されたかを確かめられない。保存と取り直しを分けると、遅い取得が操作の完了を巻き込まない。
- 古い値を見せると、選んだ直後の選択が戻ったように見え、間違った一覧から選ぶことになる。最後の意図を正本にすれば、遅い応答の順序に表示が左右されない。
- 空・失敗・確認中を同じ顔で出すと、安全でないものを安全に見せる。区別して見せれば、帯が揺れず判断を誤らない。

## 影響

- `web/sidebar-moves.mjs`（移動の列）、`web/composer-vocab.mjs`（エージェント切替の一覧）、`web/composer-aux.mjs`（帯の付帯情報）を追加。`web/client.mjs`（`sidebarChange`・`reserveSettings`・`pendingChoice`・`settleNext`）、`web/composer-controls.mjs`、`web/style.css`、`web/worktree.css` を変更。サーバーの変更は無い（保存は既存の `setStatus` の `alone` を使う）。
- 見た目の決まりは [design-system.md](../design-system.md)「会話の状態の移動・エージェント切替・新しい会話の帯」。
