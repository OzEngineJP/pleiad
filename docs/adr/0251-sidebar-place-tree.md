# 0251 脇の並べ方を置き場所の木に統合する

- 状態: 承認（2026-10-22）。一部置換（[0255](0255-sidebar-show-all-rows.md)、承認（2026-10-23））: 決定 2・4 の「ほか n 件」に畳む形は廃止し、どの区画もすべての項目を出す。ほかの決定は引き続き有効

## 状況

脇の「チャンネル」「状態」は同じ会話を 2 通りに並べていた。切り替えると置き場所と状態のまとまりのどちらかが見えなくなり、フィルターも並べ方によってスレッドに効く条件が違っていた。ユーザーは置き場所の木の中で一時チャットを状態ごとに分ける形を承認した。

## 決定

1. [ADR 0157](0157-unify-chat-thread.md) の決定 3（2 通りの並べ方）を置き換える。脇を一時チャット → チャンネル（名前順）→ Bots → ルーティンの木にし、並べ方の帯と端末の並べ方設定を廃止する。他の決定は変更しない。
2. 一時チャットを既存の状態の見出しで分け、2 行の会話と fork の器、状態へのドラッグと ＋ を保つ。状態ごとに 5 件を超えた分を「ほか n 件」に畳み、開いている会話・あなた待ちは残す。fork の器は分断しない。状態と置き場所は手動でも畳める。
3. 「あなたを待っている」の区画は作らない。待ちは元の場所の行と、畳んだ見出しに ◆ で示す。Bots の行は今の「あなた待ち」。全部の待ちを集めて見る入口はベルとし、既読でも解決までベルの ◆ を残す。未解決の待ちは通知の件数・日数による整理から除外する。待ち以外の未読の扱いは変えない。
4. チャンネルのスレッドは最近 3 件と開いている行・あなた待ちを 1 行で出し、残りは「ほか n 件」。状態は右のアイコン（名前は title・読み上げ名）で示し、変更は行のメニューから行う。
5. 状態と期間のフィルターは会話・スレッドに同じ条件で効かせる。絞っている間は空のチャンネルと Bots・ルーティンを隠す。作業ディレクトリ・エージェントを持たないスレッドは、その値で絞る間は出さず、チャンネルの見出しに 0 件を出さない。検索は平らな結果のまま。
6. スマホの引き出しも同じ木とする。

## 理由

置き場所と状態を同時に追え、同じ一覧で会話の状態へのドラッグとチャンネルの入口を保てる。待つたびに行を移動せず、ベルとの重複も避ける。件数が増えたときは状態ごとの畳みで一覧の長さを抑える。値を持たないスレッドをフィルターの結果に混ぜると条件が一貫しないため、その間は隠す。

## 影響

保存形式・操作の一覧・会話とスレッドの正本は変えない。並べ方を切り替えるコードと CSS、不要な文言を削除する。通知の waiting 件数は未読ではなく未解決の件数にする。開閉と「ほか n 件」は既存の端末ごとの好みに追加して覚える。画面の今の形は design-system.md「脇」と §4.1 に記録する。
