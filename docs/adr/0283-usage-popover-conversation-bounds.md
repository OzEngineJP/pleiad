# 使用量のポップアップを会話列の内側に収める

## 状態

承認（2026-10-27）

## 状況

会話列は通話背景のため独立した重なり順を持つ。使用量のポップアップを列の子に置き、画面全体だけを基準に位置を決めると、右パネルの下に隠れる。低い窓では札の上の空きより面が高くなり、見出しも画面外へ出る。

## 決定

ポップアップはbody直下に置き、会話列の実測範囲から左右8pxを除いた幅に収める。最大幅は340px。開いている間は列と札の位置に追従し、最大高さは560pxと札の上の空きの小さい方にする。会話列上端、デスクトップの帯、表示ビューポートを避ける。見出しと1枠を置けないときは既存の下部シートへ切り替える。

見出しの更新・閉じるを固定し、本文だけをスクロールする。PCでもこの会話のエージェントを先頭に残し、残りを既存の「ほかのエージェント」に畳む。使用枠はラベルと右寄せの率、全幅の棒、全幅の回復時刻の順に並べる。ラベルとアカウント名は折り返す。360pxは既存のモーダルの下部シートを維持する。

開くと使用量のdialogへフォーカスする。PCは非モーダルで、Esc・閉じるから入口へ戻す。更新でフォーカス・展開・スクロールを失わない。率の分かる棒は名前と値を持つmeterにする。

## 理由

使用量を読むために右パネルを閉じる操作を不要にし、狭い会話列でも名前・率・回復時刻を読めるようにする。他のエージェントは必要なときだけ展開でき、現在の会話を先に確認できる。

## 影響

通話背景のisolationと会話列全体の重なり順は維持する。使用量の取得、アカウントやモデルの選択、上限判定、費用の集計は変えない。内蔵ブラウザーはbody内の.popとモーダルを検知する既存の仕組みを使う。
