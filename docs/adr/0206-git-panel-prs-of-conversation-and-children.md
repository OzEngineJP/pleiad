# ADR 0206: git パネルの頭に、会話と委譲した子の会話の PR を状態つきで 1 つの一覧に出す

- 状態: 承認（2026-10-14）
- 日付: 2026-10-14
- 関連: [git-panel-pr.md](../git-panel-pr.md)、[ADR 0085](0085-host-reads-git-and-turn-snapshots.md)、[ADR 0135](0135-git-panel-tabs.md)、[ADR 0081](0081-control-surface-registry.md)

## 状況

git パネルの頭には、会話の履歴から拾った PR を 1 件だけ「PR #412 ↗」と出していた。次の不足があった。

- `gh pr create` を拾えない呼び方がある（`powershell -Command`・`bash -lc`・`cmd /c` で包んだ形、`gh -R`、前置き、`X=$(…)`、`&&` / `;` の連結）。
- 結果を切るときに、末尾の PR の URL まで切り捨てていた。
- 委譲した子の会話が作った PR は、親のパネルに出ない。
- 状態（オープン・ドラフト・マージ済み・クローズ、チェック）も題も分からず、リンクを開いて確かめるしかなかった。

ユーザーは、モック（`git-panel-load-and-pr.html` の 4 と `session-pr-link.html` の 1・3・4）を見て、この形を承認した（2026-10-14）。

## 決定

1. **PR の拾い方を直す。** シェルの包み・`-R`・前置き・連結・Codex と Antigravity の形を読み、結果を切っても末尾の URL を残す。PR は「会話が `gh pr create` で作ったもの」だけで、現在のブランチの PR を `gh` で探しはしない。
2. **PR を会話ごとに覚える。** 会話のデータ `prs`（`{ number, url, at }`。上限 30）に、ターンの間と終わりに足す。親の一覧は、自分の分と、委譲の記録（`agentTasks.descendants`）から辿れる子孫の分を 1 つにする。**今から作る PR だけ**で、子の昔の PR は戻さない。
3. **読み取り専用の操作 `git.prs` を足す**（旧 WS `gitPrs`。risk: read）。`gh pr view <URL> --json …` だけを呼び、状態（open・draft・merged・closed）とチェック（pass・fail・pending）を 60 秒覚えて返す。`gh` が無い・ログインしていないときは、番号・repo・リンクだけと理由（`no-gh` / `no-auth`）を返す。`states: false` は `gh` を呼ばない。
4. **頭の PR の行を作り替える。** 輪郭の形 + `#番号` + 題 + 状態の語 + チェックの語 + ↗。**色は使わない**（形と語で分ける。`--diff-*` も使わない）。オープン → ドラフト → マージ済み → クローズ、同じ状態の中は新しい順、3 件まで・「ほか N 件」。番号は覚え書きからすぐ出し、残りは `.history-line` の骨組みから埋める。狭いパネルはチェックの語をたたむ。PR が無ければ何も出さない。
5. **子の会話の PR に見える印は足さない。** 1 つの一覧のまま、行の `title` と読み上げの名前に「子の会話で作成」を入れる。
6. **PR は git パネルの頭にだけ出す。** 会話の頭の行・委譲カード・脇の一覧には出さない（脇に git の印を出さない [ADR 0085](0085-host-reads-git-and-turn-snapshots.md) を守る）。

## 理由

- 会話が作った PR だけを拾うので、推測で別の PR を出さない。覚え書きにすることで、履歴が切られても、会話が閉じても PR が消えない。
- 親が自分の子の仕事を一覧で見られるのは、委譲の目的（任せて、結果だけ見る）に沿う。見える印を足さないのは、一覧を静かに保つためで、どれが子のものかは `title` と読み上げで辿れる。
- 状態は GitHub が持つので、画面は読むだけにする（書かない）。`gh` が無くても、番号とリンクは使えるままにする。
- 色を使わないのは、状態を色だけで伝えない（読み上げ・色覚）のと、色の意味を差分に限る約束（`--diff-*`）を守るため。

## 影響

- 操作が 1 つ増える（`git.prs`。`tests/ops-surface.snap.json` を更新）。
- `gh` を呼ぶのは `core/git-prs.mjs` だけで、`pr view` の読み取りに限る。試験と画面の確認は `AGENT_HOST_GH` で偽の `gh` を指す。
- 子が作った PR が親に出るのは、この変更の後に作ったものから。
