# 0305 ブラウザーの外周を直角にし、可視化は元の HTML と保存した版を分けて開く

## 状態

承認（2026-11-09）。会話選択の combo・タブ列・スマホの [N]・AI 操作の印は [ADR 0303](0303-browser-tabs-and-viewing.md) のまま変えない。

## 状況

会話の右の欄（会話のブラウザー）には 4 つの見直しがあった。

1. 右の欄の外周が角丸で、メインの画面との一体感を削っていた。タブ自身の上端の丸みはブラウザーらしさとして残したい。
2. 「新しいタブ」ページの「この会話」の領域に、入口が増えて込み合っていた。可視化への入口もその中に紛れ、過去の可視化へ戻る道が分かりにくかった。
3. 会話に保存した可視化（当時の HTML と資源の束）と、その元になったファイル（今の中身を持つ現在版）の区別が曖昧だった。カードの「ページで開く」は保存した束を開き、元のファイルの今の状態へ行く道が無かった。アドレスバーが保存版に元のパスを出すと、今のファイルを見ているように誤読できた。
4. アドレスバーの入力欄は、外側のピルの丸枠と中の入力欄・パンくずの四角枠が二重に出ていた。

## 決定

### 外周

- 右の欄（Chrome の窓のパネル）の外周は直角にする。タブの上端の丸みは残す。スマホの全画面は従来どおり端まで平ら（ADR 0303）。

### 新しいタブの「この会話」

- 「変更」「プラグイン」の入口は折り返せる chip にする。
- 可視化は別の「可視化」節の行一覧にする。新しい順に 5 件＋「すべて表示／少なく表示」。行は主操作のリンク（題は 1 行省略）・時刻・「⋯」の順で、`role="button"` の行の中に操作を入れない。幅 360px でも「保存した版」の状態（バッジ）は残し、時刻だけを畳む。
- 行の「⋯」と右クリックは、元のパスが分かる記録には Explorer／既定のブラウザーを残す（消えていれば「元のファイルが見つかりません」）。元パスの記録が無いもの・リモートの画面には OS の操作を出さない。「パスをコピー」は残す。

### 可視化の開き分け

- カードの「ページで開く」と新しいタブの行の主操作は、**元の HTML の現在版**をページタブで開く。会話の中のカード（インライン）は従来どおり、回答した当時に保存した束を表示する。
- 元のファイルが消えていれば保存した版へ進み、「元のファイルが無いため、保存した版を開きました」と知らせる。消えたと分かるのは not-found 系の失敗だけ（権限・通信などは消失と誤表示しない）。元パスの記録自体が無いものは、知らせずに保存版を開く（正常系）。
- 元の HTML のタブの題はファイル名とし、そのタブをどの可視化から開いたか（束の印・入口・題・元パス）は固定の記録として別に持つ。タブの中で別のファイルへ移った間は「会話に保存した版を開く」を出さず、元のファイルへ戻れば再び出す。
- 保存した版のタブは、アドレスバーに「保存した版」の札と題を出し、元のパスを現在のファイルのように見せない。タブの「⋮」には「元のファイルを開く」（元パスがあるもの）・「HTML を保存」・「題をコピー」を置く。
- 「HTML を保存」は、カードのように中身を手元に持つ経路では従来どおりその中身から保存し、手元に中身の無い経路（新しいタブの行・保存版のタブ）だけが会話の記録にある束を取る認証つきの口（`api/viz`）を使う。束の印の無い記録からは保存版を開く項目を出さない。

### アドレスバーのフォーカス

- アドレスバーのフォーカスは外側 1 本の丸枠にそろえ、入力欄・パンくずの部品自身の四角枠は出さない。

## 理由

- 保存した束は「当時の見た目を保つ写し」、元のファイルは「今の中身」であり、役割が違う。主操作を現在版に寄せると、続きの作業（元ファイルの編集・最新の表示）へまっすぐ進め、保存版は「あのときのもの」として明示に辿れる。
- 束の印・元パス・題を可変のページ状態と分けて固定で持つことで、タブの中で移動しても古い保存版を誤って提示しない。
- 行を素のコンテナーにし主操作をリンクにすることで、補助の「⋯」が入れ子の操作にならず、支援技術へそれぞれ独立に届く。

## 影響

- `tab.request.viz = {hash, entry, title, path}` を可視化の固定の記録として持つ（可変の `request.path`／`page.path` と分離）。`api/viz` はその会話の記録にある束の入口だけを、認証つきで返す。束・記録・隔離 origin・sandbox・パス検査の契約は変えない。
- 元パスの記録は、OS の操作と「元のファイルを開く」が使うので保持する。データの移行・設定の追加は無い。
- 利用者向けの操作が変わる点: 可視化の「ページで開く」の行き先（保存束 → 元の HTML）、新しいタブの可視化一覧、保存版の表示、外周の角、アドレスバーのフォーカス。
