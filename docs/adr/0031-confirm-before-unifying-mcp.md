# 0031 外部 MCP を「Pleiad がそろえる」に切り替える前に、その場で確かめる

- 状態: 承認（2026-09-27）。設定 › プラグインの外部 MCP は [ADR 0325](0325-external-mcp-by-name-and-agent.md) で名前 × エージェントの一覧に置き換えた（担当の 2 択と、この確認はなくなった）。会話の右パネルには残る。

## 状況

設定のコンテキストは、変えた瞬間に保存する（保存ボタンを置かない。design-system.md「コンテキスト」の保存）。
外部 MCP の担当を「エージェントに任せる」から「Pleiad がそろえる」へ押すと、その場で保存され、各エージェントに登録されていた MCP のうち有効なものが、どのエージェントにもつながる形で全部オンになった。Codex だけに登録していた MCP も Claude の会話に広がる。何が広がるのかを切り替える前に見る段が無かった（2026-09-27 の UX 監査 setup#5）。

## 決定

- 外部 MCP の担当を「Pleiad がそろえる」へ変えるときだけ、すぐには保存しない。2 択は今の形を選んだまま、その下にその場の確認の面を出す（モーダルは使わない）。
  - つなぐものを先に全部並べる。片方のエージェントにだけ登録していたものは「ほかのエージェントにも広がります」と強い字で添える。元の設定で無効のものはオフで押せない。
  - 行ごとにその場でオフにでき、塗りのボタンの件数（「2 件でそろえる」）が追う。「やめる」で何も保存しない。
  - 決めた時点で、担当と除外（名前で外すもの）を 1 回で保存する。
- 「エージェントに任せる」へ戻すときは確かめない。つなぐ MCP が 1 つも無いときも確かめずに切り替える。
- 会話の右パネルの「この場所だけ変える」の担当の 2 択も同じ。
- 担当を変えた後の行ごとのスイッチ、指示・Skills の担当は、今どおり変えたらすぐ保存する。

## 理由

- この切り替えは 1 回押すと、複数のエージェントに渡る道具の範囲が同時に変わる。オンで始めてもオフで始めても、どこかのエージェントの状態が黙って変わる。すぐ保存の決まりは「押した結果が画面で見え、戻すのも 1 回」を前提にしているが、この操作は結果が次の会話まで見えず、広がった道具はエージェントがすでに使っているかもしれない。
- 確かめるのを「広がる向き」だけに絞れば、すぐ保存の決まりの例外を最小にできる。戻す向きは各エージェントの元の設定に戻るだけで、何も広がらない。
- 採らなかった案: 即時に切り替え、片方だけの登録はオフで始める（確認の一手は減るが、Codex からは github が黙って外れる。逆向きの驚きで、次のターンで道具を失った理由に気付きにくい）。

## 影響

- 画面は design-system.md §9「コンテキスト」（② の保存・① の「この場所だけ変える」）、実装は `web/mcp-config.mjs` の `unifyConfirm`、`web/context.mjs`・`web/session-context.mjs` の担当の 2 択。
- 保存の形（`setContextSettings` の `kind: mcp` の `value`）は変わらない。担当と `disabled` を同じ値で送るだけ。
