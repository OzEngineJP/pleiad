# 0370 管理下のホストで実行するエージェントを Pleiad Agent に限る

- 状態: 承認（2026-11-28）。実行場所ごとのエージェントの範囲を承認。サーバーでの強制方法と PC への委譲は提案。

## 状況

Pleiad は、会話ごとに利用できるエージェントを選べる。Pleiad Plus の管理下で動くクラウドのホストと、利用者の PC とでは、実行できるエージェントの範囲が異なる。[ADR 0004](0004-multiple-agent-backends.md)、[ADR 0263](0263-accounts-and-hosted-relay.md)

## 決定

- **承認（2026-11-28）。** クラウドを実行場所に選んだ会話は Pleiad Agent で動く。Claude Code など他社のエージェントは、それを使える PC を実行場所に選んだときに候補に出す。[ADR 0373](0373-personal-pc-in-workspaces.md)
- **提案。** 管理下のホストは、ホストの起動時に決まる印に従い、サーバー側で Pleiad Agent だけを実行できるようにする。画面の候補もサーバーの許可に合わせる。他社のエージェントを指定された場合は、新規作成・再開・切り替え・委譲のどの経路でも実行を断る。
- **提案。** クラウドの会話から他社のエージェントが必要になったら、利用者が使える PC で、そのエージェントを実行でき、委譲を受け付けるものを選んで任せる。依頼の主体と承認は既存のリモート委譲の規則に従う。条件に合う PC がなければ、依頼元の会話に理由を返す。[ADR 0146](0146-remote-agent-delegation.md)
- **提案の範囲。** 起動時の印の表し方と、クラウドの会話から委譲先の PC を選べる条件は未承認。

## 理由

- サーバーが実行時に判断すれば、古い画面や画面以外の経路から依頼しても、実行場所ごとの制限を適用できる。
- 他社のエージェントが必要な作業を利用者の PC に委譲できれば、クラウドの会話で依頼と結果を追える。PC での実行には、その PC で使えるエージェントと既存の承認の流れを使う。

## 影響

- ADR 0004 のバックエンド選択は、ホストが利用を許す範囲で働く。クラウドから PC に任せる場合は ADR 0146 の用途が広がる。
- 実装時に、管理下のホストと PC それぞれの選択肢と委譲の条件を記す。[複数のエージェント](../multi-backend.md)、[エージェントへの委譲](../agent-delegation.md)
