# 0042 プレビューは外部の読み込みを既定で許し、確認は設定で入れる

- 状態: 承認（2026-09-27）。エージェントの操作は 0148 の第 7 段で Chrome だけになり、サイトの利用の確認は Chrome の中継で続く（2026-10-08）。一部置換（0291・0292）: 内蔵ブラウザーの `file:` のタブの守りは、内蔵ブラウザーと一緒に無くなる。確認の設定は、可視化と HTML のファイルの応答のヘッダーの CSP に効かせる形で続く

## 状況

可視化と右パネルの HTML ファイルのプレビューは、CSP で外部の画像・通信・埋め込みを止めている（ADR 0009）。止めたことは画面に出ず、外部の資源を使う成果物が崩れて見える。プレビューの中のリンクも押せない。ユーザーは、既定で確認なしに使え、確認したい人だけが設定で入れられる形を求めた（2026-09-27）。

## 決定

- プレビューの CSP を既定で `https:` に開く（画像・スクリプト・スタイル・フォント・通信・埋め込み・メディア）。**sandbox は `allow-scripts` だけのまま、`allow-same-origin` を付けない。** 枠は不透明なオリジンで動き、Pleiad の DOM・Cookie・トークンには届かない。
- プレビューの中のリンクは押せるようにする。枠に入れた小さなスクリプトがクリックを親へ知らせ、親は送り元の枠と http/https を確かめて開く（ADR 0041 の開き先に従う）。
- 設定 › ブラウザーに「外部の読み込みの前に確認」「エージェントがサイトを使う前に確認」を置く。どちらも既定 OFF。ON のときだけ、止めた件数を表示の端に一行で出し、「読み込む」（この表示だけ）と「設定」（許可したサイトへ。止めた出どころが「許可」付きで並ぶ）を置く。エージェントのサイトの利用は、ON のときだけ会話の中で承認を求める（一度だけ / このサイトは常に / 断る）。
- 送信・購入・削除などの操作ごとの確認は入れない。

## 理由

- 境界として守るべきは Pleiad 本体（トークン・保存領域）で、sandbox の不透明なオリジンがそれを担う。外への通信を止めても本体の守りは強くならない。
- 開いた後に残るのは「生成された HTML が自分の中身を外へ送れる」ことだけで、気にする人は設定で止められる。
- 操作ごとの確認は、どの操作が重要かをページの中身から正しく判定できず、使いにくさだけが残る。

## 影響

- ADR 0009 の CSP の許可範囲（CDN だけ・通信と埋め込みの禁止）はこの ADR で置き換える。sandbox・`allow` の指定・高さの通知の扱いは 0009 のまま。
- 詳細は visualize.md「実行範囲」、file-preview.md。

## 追記（2026-10-06）: Chrome では一部の移動を止められない

エージェントのブラウザー操作が Chrome の専用の窓に移る（[ADR 0148](0148-agent-browser-in-chrome.md)）と、サイトの利用の確認（`confirmAgentSites`）は、Electron のナビゲーションのイベントではなく中継の `Page.navigate`・新しいタブの作成（と、確かめられれば `Fetch`）で止める。ページの中のリンク・リダイレクト・`window.open` による別のサイトへの移動は止められない可能性が高く、ON のときは設定にその旨を出す。プレビューと内蔵ブラウザー（ビューア）の外部の読み込みの確認は変わらない。
