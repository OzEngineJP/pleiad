# 0312 右の欄はタブの列の ✖ で閉じ、タブは最小幅で横に流し、大きな面の動きはばねにする

## 状態

承認（2026-11-11）。docs/design-system.md の「会話の頭の行のアイコン」（開いている間は青い頭のアイコン）、「PC のタブとアドレスバー」（右端に固定の ＋）、「ファイルのツリーと更新」（ツリーの既定は開く）を置き換える。0294・0305 の本文は書き換えない。

## 状況

- PC の右の欄を閉じる手段は、会話の頭の行のアイコン・⋮ の「パネルを閉じる」・Esc・Ctrl+Shift+B だった。頭のアイコンは開くとパネルの左端のすぐ左へ移り、押した場所と閉じる場所が別だった。760px 以下はパネルが全画面になって頭のアイコンが隠れ、⋮ と Esc しか残らなかった。
- ＋ はタブの列の外で右端に固定していたので、タブが 1 枚だとタブと ＋ の間が大きく空いた。タブは際限なく縮み、1 枚あたり 64px を切ると題が消えた。たくさん開くと、どれが何か読めなかった。
- ツリーは既定で開き、640px 以上の欄では本文が 208px 減った。
- パネル・ツリー・タブの動きは時間と曲線（または動き無し）で、動いている間に押し直すと速さ 0 から始め直すか、受け付けなかった。

## 決定

- **✖ とフォーカス**: 右の欄を開いている間は頭のアイコンを並びから外し、タブの列の右端に ✖（パネルを閉じる）を置く。760px 以下の全画面でも出す。600px 以下は今の ‹ のまま。開いたらパネルの中（新しいタブならアドレスバー、ほかは今のタブ）へ、閉じたら頭のアイコンへフォーカスを移す。閉じた直後は、ポインターが動くまで題の ✨ を出さない。
- **受け渡しの動き**: 開閉の間は、頭のアイコンが 1 つの絵として ✖ の位置・大きさ・色へ移り、閉じるときは戻る。絵は上の層に 1 つだけ出し、止まったときは本物と同じ姿にする。頭のアイコンの置き場と左の通話・目次のアイコンも、パネルと同じばねで寄る。
- **＋ と多いタブ**: ＋ は最後のタブのすぐ右に置き、列が埋まったら右端で止まる。タブは 96px（今のタブは 120px）より細くせず、入らなければ横に流して端をぼかす。入らない間だけ ∨ を出し、文字で絞れる一覧で選ぶ。タブの上で ← → Home End Delete、デスクトップのアプリでは Ctrl+Tab などで移る。ポインターで続けて閉じる間は残りの幅を止める。
- **タブの ✕**: 22px の丸に 16px の ✕（線 1.9。パネルの ✖ と同じ太さ）。
- **ツリー**: 既定は閉じる。開閉と幅は会話ごとに覚える。押して開け閉めしたときはばねで動かす。
- **動きの語彙**: 大きな面の出入りと幅は 2 つのばね（smooth 0.45 秒・弾み 0、snappy 0.30 秒・弾み 0.15）で動かす。共通の口 `web/motion.mjs` に置き、値は `web/tokens.css` の `--spring-*` から読む。途中で逆へ押すと今の位置と速さから続ける。OS の動きを減らす設定では終わりの値へ置く。割り当ては docs/design-system.md §8「動きの語彙」。

変えないもの: ほかの場所の今の動き（§8 の表の時間と曲線）、スマホ（600px 以下）の右の欄の入口と ‹、Esc・Ctrl+Shift+B・⋮ の「パネルを閉じる」。

## 理由

- 閉じる物を開いた物の中に置くと、押した手が届く所で閉じられる。全画面でも閉じる手段が目に見える。
- 頭のアイコンがその場で ✖ に変わって見えると、目が追う物が 1 つで済み、閉じた直後に同じ場所を押せば開き直せる。
- ＋ を最後のタブに付けると、「次のタブが出る所」と「＋ の位置」が一致する。最小幅を決めると題の 4 文字（英数で 8 文字）ほどが読め、入らない分は ∨ の一覧で探せる。
- ツリーを既定で閉じると、開いただけで本文が狭くならない。要る会話では開いたまま覚えている。
- ばねは途中で押し直しても速さが続き、角が出ない。式で解くので、時計を止めたコマ送りの試験が決まった値で書ける。動きを減らす判定を 1 か所に置ける。

## 影響

- 右の欄を開いている間、頭の行のアイコンは 1 つ減る。開いているかどうかは、頭のアイコンの青ではなく、✖ とパネルそのもので分かる。
- 今まで開いていたツリーは、覚えていない会話では閉じて始まる（一度開くとその会話では覚える）。
- 右の欄の開閉は、動いている間は会話の幅とパネルの中身のはみ出しを毎フレーム描き直す。中身は幅を固定して切り抜くので、走るのは外側の幅と会話の行だけ。
- ほかの場所の動きをばねへ載せ替えるか、動きを減らす判定を `web/motion.mjs` へ寄せるかは、別に決める。
