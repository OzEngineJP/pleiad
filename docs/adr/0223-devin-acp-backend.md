# ADR 0223: Devin CLI を ACP で接続する

日付: 2026-10-18

## 状態

提案

## 状況

Devin CLI のモデルと既存のログインを Pleiad の会話から利用したい。CLI は標準入出力で ACP の JSON-RPC を提供し、会話、承認、モデル設定、履歴の読み込みを扱える。

## 方針

- Devin を独立したバックエンドとして登録し、共通の能力契約とイベントを使う。未対応の機能は能力で明示し、共通の会話保存と代替処理を利用する。
- CLI の資格情報は CLI に任せ、Pleiad が既存の設定や資格情報を直接書き換えない。通常の会話では CLI の設定を利用する。
- 初版の `plyContext` は `false` とする。ほかのエージェントからのインポートを無効にしても、Devin 自身のプロジェクト設定や hooks の抑止までは確認できていない。能力が未対応、または能力を取得できない場合、画面では Pleiad 担当を選べなくする。保存済みの選択は消さず、適用されないことを説明する。
- モデルの一覧は CLI から取得する。カタログの variant ID は利用者が選ぶもので、ACP の `model` の選択肢には系列の代表だけが出る。variant ID を系列の基部・思考の強さ・速度の印に分解し、同じ基部で ACP が示す代表に読み替えて、思考・速度はその系が出す設定項目があるときだけ送る。対応する設定項目や候補が無い形（`-priority`、項目の無い系での `-fast`、代表の無い `-1m` など）や、段が 1 つに絞れない形は、別のモデル・別の値で実行せず拒否する。
- 無料表示は取得した時点の情報として扱う。提供期間、無制限利用、請求額を保証する表示にはしない。取得できない使用枠は不明として扱う。
- 通常の試験は偽の CLI を使う。実 CLI の接続確認では、利用者の設定と試験用の会話・MCP を分離する。

## 実装と制限

会話のターン、履歴の読み込み、一覧取得ごとに、その作業場所で ACP を起動する。別の作業場所の設定を共有する常駐プロセスは使わない。Pleiad の会話の記録と分岐・巻き戻し・タイトルの共通処理を利用する。既存 CLI のログインを使い、会話の記録は Pleiad 専用のセッション領域へ保存する。

各ターンは承認モード、モデル、思考、速度の設定応答を確認してから送信する。モデルは系列の代表、思考の強さと速度は model の切替後の応答にその設定項目があるときだけ送る（思考・速度の項目は系によって無く、候補も系で変わる）。設定の応答と変更通知を受信順に扱い、送信直前と応答中の変更も検出する。承認は一度だけの許可・拒否に対応し、取り消した接続の要求を後から開始しない。ツールの部分更新は同じ ID に統合し、引数や出力を保持する。

初版はテキストの会話を対象とする。画像コンテンツの直接送信、複数アカウント、Pleiad のコンテキスト・委譲・コンピューター操作、ネイティブの圧縮、実行中のモデル・モード変更、ターンの保持役による引き継ぎは提供しない。対応しない能力は明示し、更新時は作業の終了を待つ。使用枠の残量は不明として表示する。

Windows の終了処理は既存のプロセスツリー終了を使う。CLI が先に異常終了した場合の全子孫の回収を、Job による所有と同等に保証するものではない。実 CLI の確認では、試験全体を Job で所有し、利用者のプロセスと分離する。

## 検証

契約試験に Devin の偽 CLI を登録し、能力・イベント・画面の登録漏れを検査する。モデルの完全一致と設定の順序、承認の実際の応答形式、部分的なツール更新、履歴の再開、中断と接続終了を専用試験で確認する。通常 CI は Windows・Linux、macOS のリリースは関連試験と Keychain の検査を公開条件とする。本物の認証とモデルへの接続は、偽 CLI の試験とは分けて確認する。
