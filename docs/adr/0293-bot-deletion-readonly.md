# bot の削除と過去の会話の保護

## 状態

承認済み（2026-11-06）。

## 状況

使わなくなった bot を消しても、過去の会話と共通の「あなたについて」は残したい。会話から bot の印だけを外すと、その会話を普通の会話として再開でき、bot のフォルダー制限まで外れる。

## 決定

組み込み以外の bot は、サイドバーの右クリック・キーボードメニューの区切り付き末尾と、bot ページの「DM を開く」横の「⋯」から削除できる。確認には対象名、「元に戻せません。」、人格・動かし方・活動メモ・専用記憶を消すこと、共通の「あなたについて」を残すことを示す。残す会話と一時停止するルーティンは件数付きで示し、0 件の行は省く。「やめる」に最初のフォーカスを置き、閉じれば起点へ戻す。削除中は再実行とキャンセルを止め、失敗は理由を表示して再試行できる。

削除と新しい活動は bot ごとの受付で排他にする。会話の作成・送信・ルーティン・心拍・時刻予約・要約・操作接続の呼び元は、読み取り前から最後の保存まで受付を保持する。会話削除の既存基準に加え、配送・開始準備・再試行を待つ通常投稿も削除拒否対象にする。静かな内部通知だけなら削除でき、通知は片付ける。

削除開始を bot に永続化し、会話へ由来を含む `deletedBot` を保存してから所属を外す。専用記憶（忘れた記憶の復元履歴・検索索引を含む）、活動メモ、予約、隠れた会話、チャンネルのメンバー参照、専用要約を片付ける。ルーティンは削除せず一時停止し、bot 不在の再開をサーバーが拒否する。すべての片付けが成功した後に bot 本体を削除して通知する。失敗時は定義と削除開始の印が残り、再試行できる。

会話本文は変更せず、一時チャットから開ける閲覧用として保持する。API・WebSocket・起動時の自動再開・送信予定・シェル実行・圧縮・題の自動生成などの実行入口で拒否する。エージェントの操作は対象の会話に加えて呼び元を承認前と実行時に確認し、削除前のトークンから別の生存会話を動かすことも拒否する。人が履歴を整理する題の手動変更・既読・会話単位の削除は可能。共有スレッドの他 bot の会話・本文・要約は保持し、既存の送信先選択で生存 bot を呼べる。

閲覧用会話では音声入力を伴う通話の入口も表示せず、通話中に閲覧用へ変わった場合は未送信の言葉を捨てて終える。共有スレッドで生存 bot を送信先に選んだ場合の通話は維持する。

## 理由

本体削除を最後にすることで、途中の保存失敗が「削除済みなのに専用情報が残り、再試行できない」状態にならない。閲覧用の印を永続化し、実行時にも確認することで別端末・承認待ち・再起動をまたいだ抜け道を閉じる。承認の risk 区分は実行可否の代用にしない。

## 影響

保存形式番号を3に上げ、旧版が閲覧用の制限や記憶履歴を無視して書き込むことを拒否する。既存の記憶履歴は起動時に写し→取り込み→読み戻し照合→番号更新の順で移す。以降は既存 SQLite の `memory_state` へ行単位で追記・削除し、増大するログ全体の書き直しを避ける。既存の rev と共通・他 bot の履歴は保持する。新しいテーブルは追加しない。旧版へ戻すには更新前のデータ置き場全体の退避が必要である（[移行計画](../migrations/bot-delete/migration-plan.md)）。

削除した bot のページは既存の削除済み表示を使い、一覧は通知で更新する。過去の発言の編集・再送信・分岐、まとめて再開、シェル結果を次の入力に渡す操作は閲覧用会話で無効になる。隠れた会話を物理削除できないバックエンドでも、閲覧用の印で実行を拒否し、人の会話一覧には出さない。
