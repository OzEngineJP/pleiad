# ADR 0301: 入力欄の Markdown は編集行だけを構造の正にする

- 状態: 承認（2026-11-08）
- 置き換えた: [0300](0300-markdown-exit-in-place.md) の段落境界（`breakBefore`）と空引用の Shift+Enter

## 状況

0298・0300 では、行の描き方を「送る Markdown を CommonMark で読み直した結果」から決め、解除した行が前の構造へ戻らないように行に `breakBefore` を持たせていた。記号の無い行は遅延の続き（lazy continuation）として読み直され、空のうちは引用の外、字が入ると引用の中に描かれた。引用の中で複数行を貼ってから改行すると、打った字が別の入れ物へ飛んだ。行・送る Markdown・読み直しの 3 つがそれぞれ構造を持ち、操作の組み合わせのどこかで食い違っていた。

## 決定

- 構造（行の種類・確定した記号・深さ）は編集行だけが持つ。Markdown は行から一方向に作り、描くときも行の記号だけを使う（`web/md-rows.mjs` の `createMatcher`、`rowTree`）。
- 送る Markdown は次の 3 つを守る。
  - S1: どの行も自分の入れ物の記号を全部持つ。遅延の続きの行は作らない。
  - S2: 区切りの空行は、隣り合う行から作る（段落の後の入れ物の外の行・段落を打ち切れない項目・字下げのコードの前）。行には持たない。引用の中の空行は `>` だけ。空の行は区切りを要らない。
  - S3: 確定していない行頭の記号はエスケープする（`>a` → `\>a`、`# ` → `\# `）。
- 表・setext の見出し・区切り線は字のまま送る。項目の中身の頭の空白は送らない。段落の続きの行の頭の空白は送る（構造の変わる所を除く）。
- 引用の行の Shift+Enter は、空の行でも次の引用の行を足す。引用を抜けるのは、空の行の Enter と行頭の Backspace（同じ行で 1 段）だけ。
- 項目の頭の行の中身の頭で打った `> `・`- `・`1. ` は、Space で項目の中の引用・入れ子の項目として確定する。
- 中身の無い項目の頭のすぐ下には空の行を作らない（空行が項目を閉じ、下の行が外へ出る）。Shift+Enter・改行の貼り付けはそこで行を足さない。項目が無くなる操作（空の項目の Enter・空の行に項目の頭をつなぐ Delete）では、その項目の中身の行も字下げを外して一緒に出す。
- 貼った行は、キャレットのあった行の入れ物（引用・項目）の中に入れる。自分の記号を持つ行は、入れ物の記号の後ろに足して入れ子にする。HTML の貼り付けは、Markdown にしたときに前の塊の遅延の続きになる所に空行を挟む。
- 読み込んだ Markdown は、行を変えないうちは元の字のまま送る。下書きの編集情報の版 1 はそのまま読み、行の記号は送る行に書いた形で保存する。
- 共通構造解析（`web/md-structure.mjs`）と履歴の描画（`web/render.mjs`）は変えない。

## 理由

構造の持ち主を 1 つにすれば、描く・送る・保存して戻す・読み直すが同じ行から決まり、操作の組み合わせで食い違う余地が無くなる。S1〜S3 は、送った Markdown を履歴と同じ読み方で読んでも行ごとの入れ物が同じになるための条件である。

## 影響

- 0300 の `breakBefore` は消した。0298 の本文と編集情報の分離・範囲 API・保存時の検証は引き継ぐ。保存形式は `v: 1` のままで、データ移行は要らない。
- 送る Markdown は、遅延の続きの代わりに記号の付いた行、区切りの空行、エスケープした行頭の記号を含むようになる。履歴での見え方は同じ。
- `docs/design-system.md` の入力欄の規則を更新する。

## 検証

- `tests/unit/md-rows-serialize.mjs`: でたらめな行の並びで、送った Markdown を読み直すと同じ行・履歴と同じ読み方で入れ物が同じ・遅延の続きが無い・整えが 2 回目に何も変えない。
- `tests/unit/md-rows-search.mjs`: 打鍵の並びの総当たりとでたらめで、打った字で行の入れ物が変わらない（TYPE）・見え方と送る形（SENT）・下書きの往復（DRAFT）・別の PC での読み込み（LOAD）・例外（CRASH）。CI は 3 打鍵と 300 件、`MD_ROWS_SEARCH=full` で 4 打鍵と 20000 件。
- 実ブラウザーの `tests/browser/markdown-rows-cases.cjs` で、打鍵・貼り付け・送信・再読込を確かめる。
