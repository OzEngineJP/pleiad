# 0327 外部 MCP を、名前 × エージェントの一覧にする（担当の 2 択をやめる）

- 状態: 承認（2026-11-14）
- 承認の内容: プロダクトオーナーが、モックの形（temporary/mockups/context-owner-both-v2.html の 01〜07、行ごとに並べる読み）を承認した。タブで分ける読み（08）は作らない。
- 置き換えるもの: [ADR 0031](0031-confirm-before-unifying-mcp.md)（外部 MCP の担当を「Pleiad がそろえる」へ切り替える前の確認）。指示・Skills の担当の 2 択と、会話の右パネルの「この場所だけ変える」の MCP の 2 択は、この ADR では変えない。

## 状況

設定 › プラグインの外部 MCP は、担当を「エージェントに任せる」か「Pleiad がそろえる」の 2 択で決めていた。
- 「そろえる」は全部か全く無しで、「Codex の slack だけ Claude にも渡す」「Claude の github だけ止める」ができなかった。
- プラグインの MCP と claude.ai のコネクターは、どちらの担当でも一覧に出なかった。
- 「そろえる」へ切り替えるときだけ確認の面が出た（ADR 0031）。広がる範囲が一度に決まるためで、名前ごとに決めれば不要になる。

## 決定

- 担当の 2 択をやめ、名前 × エージェント（Claude・Codex・Antigravity・OpenCode・Devin・Grok）の 1 つの一覧にする。行は種類の記号・名前・出どころのロゴ・全体のスイッチ・6 つのエージェントのアイコン。組は「Pleiad に登録」（末尾に「MCP を追加」）と「エージェントの設定」。
- 名前に無いエージェントのアイコンを入れると、その名前だけを広げる。広げる前に名前ごとに 1 回、その場で聞く（「Codex の設定の slack を、Claude にもつなぎます」）。外すときは聞かない。
- プラグインの MCP（`plugin:<プラグイン>:<名前>`）と claude.ai のコネクター（`claude.ai <名前>`）を同じ一覧に出す。コネクターは Claude の列だけ押せる。
- エージェント自身の MCP を名前ごとに止められるのは Claude・Codex・OpenCode。Devin・Grok・Antigravity は鍵を付けて押せない（Devin のユーザーの設定の定義は、[ADR 0335](0335-grok-devin-native-mcp-off.md) で止められるようにした。Grok は確かめた結果、鍵のまま）。止め方は「起動のときに Pleiad が止める」だけで、エージェントの設定ファイルは書き換えない。
- 保存は `context-scans.json` の外部 MCP の `agents`（`off`・`spread`、名前 → エージェントの配列）。これがあると中継は常に開き、名前ごとの止めと広げが効く。

## 追加の決定（レビュー後、2026-11-14）

- **Antigravity・Devin・Grok の自身の MCP**: 名前ごとの一覧でも、自身の設定の MCP は自身がつなぐ（`inheritMcp: true`）。Pleiad が中継するのは Pleiad の登録と、ほかのエージェントから広げた名前だけ。自身側に同じ名前があれば自身側が勝つ。この規則は能力の印 `nativeMcpOff` から導く（エージェント名で分けない）。Devin の止められる定義は [ADR 0335](0335-grok-devin-native-mcp-off.md) で変わった（Grok は鍵のまま）。
- **「Pleiad がそろえる」からの移行**: プラグインの MCP とコネクターも写す。旧 `owner: 'ply'` では、Claude のそれらは最初オフ（画面も保存前から同じ）。コネクターの一覧が未読なら読み終えるまで待つ。Claude が使えるのに読めなかったときは保存せず、画面に 1 行のエラーを出す。旧 `disabled` の名前はすべてのエージェントでオフにし、`agents` を書くときに `disabled` を消す（走査で二重に効かせない）。エージェント自身の設定で無効にされた MCP は、オンに見せず、広げる初期の集合にも入れない（押せないオフ）。
- **広げる範囲**: 旧の探す場所（`sources`）に入っていたエージェントの名前だけを広げる。
- **壊れた無関係の設定**: 名前ごとの一覧では、読めない・解釈できない・大きすぎる MCP の設定ファイルだけを飛ばし、ターンは続けて理由を記録に残す（指示と Skills の失敗は今までどおり止める。旧来の担当では変えない）。飛ばしても、オフにした名前は止めたまま（「止めた」が「つながる」に変わらない）。0 バイトのファイルは「MCP なし」。
- **同名の止め漏れ**: 隠れた（`shadowed`）行と、この会話では外した（`removedMcp`）行でも、エージェント自身の同名の MCP は止める。止められないエージェントは鍵のまま。
- **コネクターの読み取り**: 読み取りで MCP を起動しないよう、`claude.ai ` で始まらない既知の名前（Claude の設定の MCP・プラグイン・Pleiad の登録すべて）を deny にする。成功した読み取りは約 5 分覚える。読み取りは Pleiad が管理する Claude のアカウントで行い、画面の待ちは 20 秒以上、最初の `refresh: true` の応答にも「探しています」の行を出す。
- **右パネル**: 有効な設定に `agents` があるとき、「この場所だけ変える」は MCP の 2 択を出さず一文だけ。
- **何もしないターン**: 指示と Skills がエージェント任せで、中継するサーバーも止める名前も 0 のときは、エージェント任せの経路で走る。
- **Codex の名前**: `^[A-Za-z0-9_-]+$` に合わない名前は止められず、画面でも `context.setMcpAgent` でも鍵。
- **プラグインの MCP は Claude の列だけ押せる**。同じ名前のコネクターがオンのときは、重複を隠す。プラグインは現在の作業場所に有効なものだけを出す（`enabledPlugins` はプロジェクトの設定も見る。ほかのプロジェクトだけに入れたものは出さない）。
- **OpenCode の専用フォルダー**: `<data>/opencode/managed/` は、12 件を超え、かつ 1 日以上使っていないものだけを古い順に消す（使い始めに印を付けるので、走っているものや最近使ったものは消えない）。

## 追加の決定（再レビュー後、2026-11-14）

- **コネクターの一覧は「未読」と「読めて 0 件」を最後まで分ける**。未読（`null`）のまま、旧「Pleiad がそろえる」からの最初の保存へ進まない。読み取りを起こして待ち、それでも読めず Claude が使えるなら、保存せずエラーにする。未読のコネクターの行を押したときのエラーは `connectorsUnread`（`unknownMcp` ではない）。
- **自身の設定で無効の定義は「そのエージェントが持っていない」扱い**（画面も実行時も同じ）。Pleiad の登録があれば登録の行、ほかのエージェントから広げられるなら広げる行、どちらも無ければ列は押せないオフ。出どころのロゴは出さない。旧 2 択からの変換は今までの接続を保つ（旧「Pleiad がそろえる」で Codex へ中継していた名前は、Codex が無効の定義を持っていても、そのままオン）。
- **オフの名前は常に止める名前に入れる**。存在しない名前でも無害: Claude は `deniedMcpServers` に名前を足すだけ、Codex は設定に在る名前にだけ `-c` を付け、OpenCode は設定に在る定義にだけ `enabled: false` を付ける。止められない（Codex の点つきの名前など）ものは、止める名前に入っていても画面では鍵のまま。
- **旧「任せる」からの変換**: 登録と同じ名前をそのエージェント自身が持つときは、そのエージェントを off に入れない（入れると自分の分まで止まる）。
- **同名の定義の選択（`prefer`）**: 選んだ定義は、その名前をまだ持たないエージェントへ広げるときだけ効く。そのため、広げている行の詳細にだけ選択を出す。
- **画面の注記（新しい文言は足さない）**: 登録の行は状態（ログイン済み・ログインが必要・追加の権限が必要・未入力の値あり・`authStatus.message`）、コネクターは前回の読み取りで `needs-auth` だったものに「ログインが必要」を出す（覚えは名前と状態を持ち、古い形も読む）。
- **`shape`（待機中のエージェントを起こし直す印）**: 止める名前があるときだけ含める。無ければ今までの値のままで、更新の直後に待機中のエージェントを起こし直さない。
- **場所ごとの上書きは旧 2 択のまま残る。場所ごとの一覧は別の仕事。**

## 移行

- `agents` が無い人（今の人全員）の今の接続は変えない。最初にアイコンを触った時点で、そのときの実効の状態を `agents` に書き写す（`mcpAgentsFromLegacy`）。
  - 「Pleiad がそろえる」の人: 広げられていた名前は全エージェントでオン。外してあった Claude のコネクターはオフのまま。
  - 「任せる」の人: Pleiad の登録が残っていても、その名前はオフ。
- 更新の前後で各エージェントから見える MCP が同じことは `tests/unit/context-mcp-matrix.mjs` で確かめる。

## 理由

- 名前ごとに決められれば、全部か全く無しかを選ばなくてよい。広がる範囲は 1 つの名前に限られ、確認も名前ごとで足りる。
- 一覧にあるものだけを操作できる形にすると、プラグインとコネクターも同じ操作で止められる。
- 止める手段のないエージェントは、押せるように見せず、鍵と理由を出す。

## 影響

- `core/context-settings.mjs`・`core/context-runtime.mjs`・`core/context-mcp-matrix.mjs`・`core/context-claude-extras.mjs`・`core/ops/context.mjs`（`context.mcpMatrix`・`context.setMcpAgent`）・`core/backends/*`（起動のときの止め方）・`web/mcp-matrix.mjs`・`web/context.mjs`。
- コネクターの最後に読めた一覧を `<data>/claude-connectors.json` に小さな JSON で残す（`tests/data-writes-allowlist.mjs`）。
- Grok は指示・Skills を「Pleiad がそろえる」にすると `ply_context` を受け取れない（`PLY_CONTEXT_CONFLICTS`）。その間、中継に頼る Grok の列は鍵と同じ見た目で押せない。
- 会話の右パネルの「この場所だけ変える」の MCP の 2 択は残る（場所ごとの一覧は別の仕事）。
