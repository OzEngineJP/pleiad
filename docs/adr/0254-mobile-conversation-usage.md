# 0254 スマホの会話の文字と使用量・圧縮の入口を整理する

- 状態: 承認（2026-10-22）

## 状況

スマホでは本文と操作対象の字が小さく、時間の溝と余白が本文の幅を狭めていた。上部の会話メニューはサイドバーと同じ操作をすべて並べ、使用量と圧縮の状況を読むには複数の入口を辿る必要があった。ブラウザーの独立した入口が隠れる画面では、ビューアを開く場所が無かった。

## 決定

- 700px 以下だけ、本文17px/1.7、ツールの対象15px・動詞13px、入力欄17px、サイドバーの題16px・補足13px、上部の題20px・所属13pxにする。履歴の外側は左0/右8px、時間の溝24px・中心12px、自分の発言の左右8px、ツール行の左右4px・行内6px、入力欄の外側4px・箱2px・本文8pxとする。分岐の曲線も中心12pxへ合わせる。
- 上部の「…」はプラグイン・git の状態・ブラウザー・使用量・圧縮と作業ディレクトリのコピーを並べる。条件付きの入口は利用可能なときだけ出す。各行のアイコンは16px・線1.6。使用量の行は現在のエージェント・アカウント・モデルに適用される最も使用率の高い枠、圧縮の行は文脈の使用率を棒と%で示す。値が無い棒は描かない。
- 使用量は下部シートで文脈・自動圧縮までの残り・現在の使用枠を示し、ほかのエージェントは畳む。圧縮は文脈・残り・今すぐ圧縮・この会話の自動圧縮を切るスイッチをシートにまとめる。予約中の時刻とキャンセルも残す。
- スマホの入力欄上部の使用量チップは表示しない。PCのチップとポップは維持する。PCの「会話を圧縮」は直接実行、スマホの「圧縮」はシートを開く操作として文言を分ける。
- 題は直接編集し、編集中に ✦（タイトルを生成）を表示する。状態・記録・末尾から分岐・グループ・親の枝・IDのコピー・削除はサイドバーの行のメニュー、モデル・承認モード・エフォート・接続先・アカウントは入力欄の既存の入口を使う。ホスト一覧は題の下のホスト名から戻る。
- 作業場所の面にはコピー操作が無いため、上部の「作業ディレクトリをコピー」は残す。サイドバーの全操作メニューは削らない。

## 理由

承認された文字サイズと余白で本文の読みやすさを保ち、普段使わない会話の管理操作はサイドバーに集める。使用量と文脈はメニューを開いた時点でも判断でき、詳しい値と操作はシートで確認できる。別入口が無い操作は外さず、機能への到達性を維持する。

## 影響

使用量の取得・期限切れ・アカウントとモデルの判定はPCとスマホで共有する。データ形式とサーバーの操作は変更しない。入力欄の下の操作の配置には影響しない。単体試験と実ブラウザーでメニュー、棒、シート、スイッチ、スマホ/PCの入口を確認する。
