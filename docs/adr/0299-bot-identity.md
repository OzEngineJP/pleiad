# 0299: bot の未設定アイコンと変更の入口

- 状態: 承認（2026-11-07）。

## 状況

同じ既定の絵文字が並ぶと bot を見分けにくく、アイコンを変える入口も絵文字と画像に分かれていた。bot が未登録の帯では空であることが伝わらず、追加ボタンの空の名前欄が位置をずらしていた。

## 決定

新規 bot のアイコンは未設定を既定とする。画像、明示した絵文字、名前の先頭の書記素 1 文字の順で表示する。名前をまだ入力していない場合は山と太陽の写真の線画を表示する。画像を読み込めない場合も同じ順で代替する。既存の 🤖 は明示的に選んだものと区別できないため変更しない。組み込みの「bot なし」の ✦ も維持する。

編集ページの入口は丸いアバター全体を押せる「アイコンを変更」ボタン 1 つにする。右下に小さな鉛筆を常時表示し、鉛筆自体は別の操作にしない。クリック・Enter・Space で未設定・絵文字・画像の選択面を開く。画像から絵文字または未設定へ切り替えると画像を外す。「画像を削除」は画像だけを外し、既存の絵文字または名前の先頭文字へ戻す。選択のキャンセルや処理・保存の失敗では前の状態を保つ。

未設定は既存の `bots.create`・`bots.update` の `icon: ''` で扱い、画像を外すには `iconImage: null` を使う。画像は既存の添付と保存経路を通す。画面では PNG・JPEG・WebP の 10 MiB までを受け、中央を切り抜いた 256px 四方の WebP に変換し、出力を 1 MiB 以下に限る。変換・アップロード中は作成とアイコン変更を待たせる。

Bots 帯で未登録の場合は「bot はまだありません」をルーティンと同じ弱い短文として表示する。追加の「＋」は名前の空行を持たない 44px 四方の中央配置にし、hover・focus でも位置と寸法を変えない。キーボードの矢印移動と Tab の入口を保つ。

## 理由

名前の先頭文字は設定なしでも bot を識別できる。アイコン自体を変更の入口にまとめ、常時見える鉛筆で操作できることを示す。未登録の短文と中央に置く追加ボタンは、空の状態でも次の操作を伝える。

## 影響

新規 bot はアイコン未設定で保存する。既存 bot の明示した絵文字や画像は移行せず保持し、未設定の保存と題名の生成・解析を対応させる。画像の処理・保存には既存の仕組みを用い、操作の追加や保存場所の変更は行わない。
