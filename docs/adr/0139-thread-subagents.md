# 0139 チャンネルのスレッドで、bot が委譲した子（サブエージェント）を Chats と同じ部品で追う

- 状態: 提案

## 状況

チャンネルの bot が `ply_delegate` で子を委譲しても、スレッドからは子の様子（動いているか・終わったか・何を頼んだか・子の会話）が追えなかった。Chats には入力欄の上のサブエージェントのチップと一覧（[ADR 0076](0076-composer-strip-and-background-chip.md)・[ADR 0025](0025-persistent-background-entry-and-task-titles.md)）、会話の中の委譲カード（[ADR 0067](0067-main-panel-declutter.md)）があるが、スレッドの作業ログ（[ADR 0117](0117-thread-replies-and-implicit-wake.md)）の委譲ツールは、素のツールの行（「MCP ply_agents ply_delegate kind=… · task=…」）で描かれていた。

ユーザーの依頼（2026-10-04）:「スレッドごとに、入力欄の上に Chats と同じサブエージェントのボタンを置く（Chats の部品を使い回す）。押すとモーダルが開き、bot ごとのグループで子を並べる（状態・題・経過時間、子の会話を開ける）。子がいないときはボタンを出さない」「スレッドの中の委譲ツールの表示を Chats に合わせる（同じ描画を使う）」。

## 決定

- **入口はスレッドの入力欄のすぐ上の右端に、Chats の入力欄の上と同じチップ**（`createBackgroundChip`。ロゴ・数・承認待ちの ◆・弧）を置く。数えるのは、そのスレッドの bot の会話から委譲した子（子孫を含む）。子がいなければ出さない。
- **押すと Chats と同じ作業のダイアログ（`#workDialog`）が、そのスレッドの範囲で開く。** 題は「サブエージェント」。一覧は **bot ごとに見出し（アイコン・名前）で区切り**、中は動いているものが先・終わった親は bot ごとに 10 件ずつ（子孫は親の直後）。行は Chats と同じ（状態の印・ロゴ・題・経過・モデル）。詳細は Chats と同じ部品で子の会話を読む。子の会話をメインの画面で開く入口は無い（[ADR 0318](0318-child-conversations-only-in-modal.md)）。裏のコマンド・過去のネイティブの子は一覧に含めない。
- **スレッドの作業ログの委譲ツール（`ply_delegate`・ネイティブの Task / Agent）は、Chats の委譲カードと同じ描画と仕上げ**（「委譲」・委譲先のロゴ・依頼の題・右端の状態の印と経過・子の会話への矢印・開いた中の依頼と委譲先）を通す。矢印・チップと同じく、押すとスレッドの一覧でその子を選んで開く。
- **実装は Chats の部品を引き回す。** `web/client.mjs` の `backgroundItems`・`openWork`・`linkDelegateCard`・委譲カードの描き直しが、省略できる範囲（`scope`: そのスレッドの bot の会話の集合・bot の見出し・会話を開く口）を受け取る。範囲が無ければ今まで通り「今開いている会話」。スレッドは `host.background`（見る会話・項目・購読・開く・カードの仕上げ・置き場の登録・描き直し）でこれを使う。見ている bot の会話の委譲の行（子孫まで）は、Chats の会話の分とは別の入れ物（`watched`）に持ち、Chats の会話を切り替えても消さない。bot ごとの分け方と終わった親の件数は、画面を持たない関数（`web/background-model.mjs` の `groupByOwner`・`visibleRows`）に出して単体で確かめる。

## 理由

子の様子を見る道は、Chats で磨いた形（状態の印・題・経過・子の会話）がすでにある。スレッドに別の見た目を作ると、同じ子が画面ごとに違って見え、直すところも 2 倍になる。範囲を引数にするだけで、Chats の部品がそのまま使える。bot ごとに分けるのは、スレッドに複数の bot がいて、どの bot が頼んだ子かが分からないと追えないため。チップは「動いているものの種類」を見せるだけなので、子がいなければ出さない（Chats と同じ）。

## 影響

- スレッドの入力欄の上に 1 行のチップが増える（子がいるときだけ。[ADR 0119](0119-channel-budget-and-resting.md) の予算の表示など、入力欄の上の帯とは別の行）。
- Chats の作業ダイアログの題は、スレッドから開いたときだけ「サブエージェント」になる（Chats からは「バックグラウンド」のまま）。
- 過去のネイティブのサブエージェント（Claude の Task など）をスレッドの一覧へ後から引き直す道は無い（動いている間と、カードの矢印から開いたものだけ）。
- [ADR 0138](0138-quiet-wait-notices.md) とあわせ、子が待っているだけの間の「止まっている可能性」の通知を、この一覧で状態を見ることで代える。
