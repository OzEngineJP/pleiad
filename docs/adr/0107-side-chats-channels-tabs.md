# 0107 脇を Chats / Channels の 2 タブにする（design-system「無いもの: 場面切替」の例外）

- 状態: 承認（2026-10-03）。一部置換（[0255](0255-sidebar-show-all-rows.md)、承認（2026-10-23））: ルーティンを 3 件に絞らず、すべてを出す

## 状況

bot と Channels（0106）を入れると、脇の一覧に別の並べ方の物が増える。Chats は「利用者が作る状態」で木を組み、行は会話。Channels は `# 名前` のチャンネル、アイコン付きの bot、次の時刻の近い順のルーティンで、並べ方も操作（未読・あなた宛て・状態）も違う。

`docs/design-system.md` §2.3 は「無いもの: 場面切替」として、モードやタブで画面を切り替える作りを置いていない（同じ画面で足す）。

2026-10-03 に、ユーザーが 2 つの案（A: Chats / Channels の 2 タブ、B: 1 本の一覧に「チャンネル」「Bots」の節を足す）から A を承認した。

## 決定

- **ヘッダーの下、検索の上に `[ Chats | Channels ]` の 2 択（pill）を置く。** 狭い画面でも同じ位置。切り替えは脇の中身とメインの面を入れ替えるだけで、設定の画面と同じく会話は描いたまま覆う（スクロール位置・下書きを失わない）。選んだ側は覚える。設定を開いている間はタブも隠す。←→ で移り、Ctrl+Shift+F の検索は今のタブに入る。
- **見ていない側の札に点を付ける。** あなたを待っているもの（承認・質問）は差し色 `--ink-mark` の ◆、未読だけなら青い丸（一覧と同じ）。
- **Channels 側の一覧は 3 つの節。** 「チャンネル」（`# 名前`。未読は太字、あなた宛ては件数）、「Bots」（アイコン・名前・状態: 待機 / 作業中の回る弧 / あなた待ち ◆。＋で作る）、「ルーティン」（次に動く時刻の近い 3 件。一時停止は薄く、直近の失敗は「✕ 失敗」）。
- **Chats 側に bot の会話は出さない。** あなたを待っている間だけ、一覧の先頭の仮の行（進行中の位置）に出し、行に bot のアイコンと `#チャンネル` を添える。
- **例外は脇のこの 2 タブだけ。** メインの中（スレッド・bot のページ）にタブやモードは足さない。

## 理由

- 並べ方と操作が違う物を 1 本に混ぜると、Chats の木（状態で組む）の意味が崩れる。B は節の数だけ縦に伸び、会話の一覧が押し下げられる。
- 2 択に絞れば、今どちらを見ているかが札で分かり、見ていない側の「あなた待ち」は点で漏れない（思い出すために離れる、を増やさない）。
- 切り替えが画面全体の場面切替にならないよう、変わるのは脇とメインの面だけで、右パネルの道具・承認カード・検索は同じものを使う。
- 採らなかった案: B（上記）、検索に両方を混ぜるだけで一覧を分けない案（行の操作が違うので出どころの区別が要る）。

## 影響

- `docs/design-system.md` §2.3 の「無いもの: 場面切替」に「（例外: 脇の Chats / Channels、ADR 0107）」を足し、脇の節を書く。
- `web/index.html` に `#sideTabs`・`#channelsSide`・`#channelsView` が入り、`html.side-channels` / `body.channels` で出し分ける。
- 検索は Channels 側ではタブごとの検索から始め、Chats 側の結果にチャンネルの当たりを混ぜる横断は後の段で足す。
