# 0210 Pleiad の指示の既定から「委譲の進め方」を外す

- 状態: 承認（2026-10-14）
- 置き換えた: 0026（既定の項目「委譲の進め方」）

## 状況

Pleiad の指示の既定の項目「委譲の進め方」（`delegate`。0023・0026）は、依頼元の会話に毎ターン「委譲を基本にする。コマンド 1 回や 1〜2 ファイルの小さな編集より大きい作業は、自分でやらずに ply_delegate で任せる」と「この会話で自分でやるのは、方針を決める・任せた結果を確かめる…だけ」を入れていた。コンテキストの節約・速さ・質のためと考えていたが、確かめていなかった。

2026-10-14 に、過去の会話の記録と対照実験で効果を確かめた。

- 記録（~/.claude/projects の会話と `pleiad.db`）: 既定を入れた後、委譲の回数ははっきり増えた（ネイティブのサブエージェントが `ply_delegate` に置き換わった）。依頼元のコンテキスト・かかった時間・質がよくなった様子は見えなかった。子のトークンは約 4.7 倍、子の失敗は 1.3% から 5.7% に増えた（多くは使用枠の上限）。
- 対照実験（4 つの課題〔調べもの・小さな実装・バグ修正・レビュー〕× 3 つの条件〔利用者の「なるべく多く委譲する」の指示＋既定／既定だけ／委譲の指示なし〕× 2 回。答えを伏せた採点）: 委譲が起きたのは、互いに独立した 5 つの問いの調べものだけ。既定のある条件は毎回 5 本を同時に任せ、指示の無い条件は自分で調べた。中央値で、既定だけの条件は 5.7 分・1.61M トークン・9.55 点、指示なしは 4.2 分・0.53M トークン・9.70 点。ほかの 3 つの課題では、どの条件も委譲せず、差はばらつきの範囲だった。

## 決定

- **既定の項目「委譲の進め方」（`delegate`）を無くす。** Pleiad は依頼元に委譲を勧める指示を入れない。委譲するか・どこまで任せるかは、利用者が「＋ 指示を追加」で自分の指示として書く。
- 残す既定: 「委譲された会話でのコマンドの扱い」（`child`）、「Codex の実行前の拒否」（`codexPolicy`）。どちらも委譲を勧めるものではなく、任された子の振る舞いの決まり。
- 残す連動の項目: 「委譲の振り分けの使い方」（`route`）。委譲するときの `ply_delegate` の引数の約束で、委譲するかは決めない。`ply_agents` の instructions（委譲ツールの説明）もそのまま。
- **保存済みの値の移し方**（`normalizePlyInstructions`）:
  - 本文を編集していない `delegate` は捨てる（スイッチが入っていても切れていても）。
  - 本文を編集していた `delegate` は、利用者の文なので、自分で足した指示（id `u-delegate`）に変えて、並びの位置・スイッチ・入れる会話・エージェントのまま残す。名前を編集していなければ前の版の名前（「委譲の進め方」）を付ける。
  - 前の版の `addedContext`（`{ delegation: false }`）は、`child` のスイッチにだけ写す。

## 理由

- 測った範囲では、既定は委譲の回数を増やしただけで、速さも質もよくならず、トークンを約 3 倍使った。分けにくい作業は既定があっても委譲されず、分けやすい調べものほど、自分でやれば 4 分で終わるものまで 5 本に分けていた。
- どれだけ任せるかの好みは、使い方・使用枠・作業の大きさで人ごとに違う。Pleiad が既定で決めるより、利用者が自分の指示で書くほうが合う。
- 編集した本文を黙って捨てると、利用者の書いた決まりが消える。自分で足した指示に変えれば、画面で見えて、そのまま削除も編集もできる。
- 採らなかった案: 既定のまま切った状態で出す（中身が「委譲を基本にする」のままで、入れたい人にも合う文面ではない）、条件を絞った文面に書き換える（「15 分以上かかり独立した部分がある作業だけ」など。測っていない新しい既定をまた入れることになる）。

## 影響

- 依頼元の会話に毎ターン入る指示が、既定の分だけ短くなる（日本語で約 200 トークン）。編集していない利用者は、更新後のターンから入らない。
- 委譲の回数は減る見込み。何時間もかかる大きな作業でコンテキストを守る効果は測っていないので、そうした使い方の利用者は自分の指示で足す。
- 前の版に戻すと、前の版の読み込みが既定の `delegate` を足し直す（スイッチは入った状態）。
- 仕様は context-runtime.md「Pleiad の指示」と agent-delegation.md「委譲の指示」。
