# 0348 設定 › プラグインに範囲（全体の設定・フォルダー）を戻し、フォルダーの設定を行ごとの差分で持つ

- 状態: 承認済み（2026-11-24）。Issue #25
- 置き換えた: [ADR 0026](0026-context-global-settings-and-ply-instructions.md) の「設定 › コンテキストは全体の設定だけ」と「場所ごとの設定は会話の右パネルの『この場所だけ変える』」。会話の右パネルの種類ごとの一覧・指示の量・Pleiad の指示の面は 0026 のまま
- 関係: [ADR 0337](0337-context-instructions-skills-by-name-and-agent.md)（指示・Skills の行ごとの規則 `context-agents.json`）、[ADR 0327](0327-external-mcp-by-name-and-agent.md)（外部 MCP の名前 × エージェント）、[ADR 0338](0338-hooks-by-hook-and-agent.md)（Hooks の Hook × エージェント）、[ADR 0331](0331-context-tabs-and-lock-tooltip.md)（4 つの横タブ）

## 状況

- フォルダーの設定は、そのフォルダーで開いた会話の右パネルの「この場所だけ変える」からしか見られず、直せなかった。直す入口が設定の表と右パネルの 2 つあり、形も種類ごとに違った（外部 MCP は旧い 2 択、Hooks は「この場所で使うか」だけ）。
- 見つからなくなったフォルダーの設定は、どこにも出ず消せなかった。フォルダーで足した探す場所は UI に出ず、足すことも外すこともできなかった。
- `context-scans.json` 形式 3 は場所に種類の設定の丸ごとの写しを持ち、作業場所に一番近い場所の写しが勝った。このため、どの行をそのフォルダーで変えたかが分からず、1 行だけ戻せず、後で全体を変えてもフォルダーに届かなかった。
- 承認したモック（v2）は、4 タブの上に範囲のプルダウンを置き、4 タブとも同じ段・同じ行の印で、全体の設定とフォルダーの設定を同じ画面で直す形だった。

## 決定

- **範囲のプルダウン（設定 › プラグイン、タブの上）。** ボタンは「全体の設定」（地球）か、フォルダー名とパス（フォルダー）。一覧は「全体の設定」、見出し「フォルダー」の下に保存済みのフォルダー（パス · 最後に使った日、右に「変更 n」）、見つからないフォルダー（点線のアイコンと「見つかりません」）を最後に、末尾に「別のフォルダーを選ぶ…」（パスの入力と最近の会話の場所の候補。選んで最初に変えたときに保存する）。最後に使った日は会話の記録（その場所で最後に動いた会話）から引き、保存の形には足さない。↑↓ Home End Enter Esc で操作し、閉じたら範囲のボタンへフォーカスを戻す。
- **ボタンの横の状態。** 変えていないフォルダーは「全体の設定どおり」「<上のフォルダー> の設定どおり」。変えたフォルダーは「n 件変更」と「全体の設定に戻す…」（子フォルダーは「<上> の設定から n 件変更」と「<上> の設定に戻す…」）。見つからないフォルダーは「見つかりません · 変更 n 件」と「設定を消す…」（赤）。戻す・消すは確認を出す（「website で変えた 3 件と、追加したスキャン場所 2 か所を消します。」）。
- **範囲とタブの帯は画面の上に貼り付ける。** 帯の高さはスクロールの上の余白に渡し、フォーカスや送りで行が帯の下に隠れないようにする。タブには「変更 n」を付ける。
- **4 タブとも同じ段の並び。** カードの見出し（指示・Skills など）は置かない。
  1. **スキャン場所**（「?」の説明「エージェントが読み込む場所です。Git のルートから作業フォルダーまでと、追加した場所を探します。」）。全体の範囲では、すべてのフォルダーに共通の規則「Git のルートから作業フォルダーまで」、全体で追加したスキャン場所（「外す」）、「＋ スキャン場所を追加」。フォルダーの範囲では、そのフォルダーと親フォルダーの標準のスキャン場所をフォルダーごとのまとまり（まとまりのスイッチでまとめてオン・オフ。止められない所は鍵のまま）、全体で追加したスキャン場所（受け継ぎ）、このフォルダーで追加したスキャン場所（「● 追加」と「外す」。親で追加した分は「<上> の設定」）、「＋ スキャン場所を追加」。全体で追加したスキャン場所はユーザースコープの一覧に混ぜない。
  2. **ユーザースコープの指示 / Skills / 外部 MCP / Hooks**。ホームフォルダーの下の一覧。フォルダーの範囲では同じ一覧を受け継いで出し、行ごとに上書きできる。旧「エージェントの設定」の段は無くし、Hooks の「エージェントの設定に追加」は「ユーザースコープに追加」にする。
  3. **Pleiad の指示 / Pleiad に登録**。フォルダーの範囲では一覧だけ（追加のボタンと「すべての場所に共通」は出さない）。Pleiad の指示はすべての場所に共通のままで、フォルダーの範囲では見るだけ。
- **行の印（4 タブ共通。`web/context-scope-marks.mjs`）。** このフォルダーで変えた行は青い「● 変更」と「戻す」（読み上げは「<名前> を全体の設定に戻す」「… を <上> の設定に戻す」）。親フォルダーから受け継いだ行は「<上> の設定」（押すとその範囲へ移る）。全体から受け継いだ行は印なし。全体の範囲の行は、どこかのフォルダーが上書きしていれば補足に「<場所> で別の設定」「n か所で別の設定」。
- **見つからないフォルダー** は読むだけ（スイッチとエージェントの印は押せない）。標準のスキャン場所は「フォルダーが見つかりません」、追加したスキャン場所は見せるが外せない。「＋ スキャン場所を追加」は出さない。消すのは「設定を消す…」だけ（移した先を選ぶ操作は今回は入れない）。
- **会話の右パネルの編集モードを無くす。** 場所の 1 行にパスと状態（「全体の設定どおり」「このフォルダーで n 件変更」「<上> の設定から n 件変更」）と「この場所の設定を開く」（範囲をその場所にした設定 › プラグインを開く）。「この場所だけ変える」と末尾の「すべての場所の設定は プラグインの設定を開く →」は消す。指示の量・Pleiad の指示など下の面は今のまま。
- **保存は行ごとの差分。** 受け継ぐ値（全体 → 祖先のフォルダー）と同じに戻した上書きは消す。全体を変えると、その行を変えていないフォルダーにも届く。
  - `context-scans.json` 形式 4: 既定（全体）は丸ごと、場所は差分だけ（`kinds` の項目・名前ごとの差分、`roots` にこの場所で足したスキャン場所、`rootsOff` に受け継ぐのに使わないスキャン場所）。種類に `hooks` のスキャン場所を足す。形式 1〜3 は読み込み時に `context-scans.v<n>-backup.json` を取り、コピーの上で形式 3 を経て 4 へ移し、受け継ぐ値と同じ差分を除き、同じ結果になることを確かめてから置き換える。確かめられなければ元のファイルのまま止まる。
  - 指示・Skills は `context-agents.json`（ADR 0337 の行ごとの規則。`resolveRuleForItem`）のまま。外部 MCP は形式 4 の `kinds.mcp.agents` の名前（行）ごとの差分。Hooks は `hooks-agents.json` 形式 2 で、場所は受け継ぐ値と違う行だけを持つ（形式 1 は `hooks-agents.v1-backup.json` を取って移す）。実行時は同じ規則で祖先から行ごとに解決する。
  - 外部 MCP と Hooks の追加したスキャン場所は、その場所の `.mcp.json`、`.claude/settings.json`・`.codex/hooks.json` などを読む（読むだけ。エージェントの設定ファイルは書かない）。
- **操作。** `contextScopes`（保存したフォルダーの一覧: 見つかるか・上のフォルダー・変えた数）、`removeContextPlace`（フォルダーの設定を全部消す。フォルダーが無くても消せる）、`revertDocRows`・`revertHookRow`・`removeHookPlace`、`setContextSettings` の `revertRows`・`addRoot`・`removeRoot`。

## 理由

直す入口を設定 1 つにし、全体とフォルダーを同じ画面・同じ行の印で見比べられる。行ごとの差分にすると「変更 / 受け継ぎ」の区別と 1 行だけ戻す操作ができ、全体の変更がフォルダーに届く。見つからないフォルダーの設定も一覧に出て消せる。

## 影響

- 見た目の規則は [design-system.md](../design-system.md) §9「プラグイン」、保存と解決は [context-management.md](../context-management.md)・[context-runtime.md](../context-runtime.md)。
- 形式 3 のフォルダーの写しは、移行で受け継ぐ値との差分に変わる（効く値は変わらない）。古い版の Pleiad は形式 4 を読めないので、戻すときは `context-scans.v3-backup.json` を使う。
- 360px では帯が上の 150px ほどを使う。
