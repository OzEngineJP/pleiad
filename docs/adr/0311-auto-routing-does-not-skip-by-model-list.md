# 0311 自動の振り分けはモデル一覧で候補を飛ばさず、CLI に断られたら次の候補へ任せ直す

## 状態

承認（2026-11-10）。0309（モデルの確かめは選ぶときに一本化し、送信直前には見ない）と 0310（Claude のモデル一覧は作業場所ごとに引く）のうち、「振り分けが一覧で確かめる」部分を置き換える。両方の本文は書き換えない。

## 状況

自動の振り分け（`ply_delegate` の `backend` 省略）は、候補のモデルが今のモデル一覧に無いと `model_unknown` で飛ばしていた。しかし一覧は使えるモデルの正本ではない。作業場所・ログイン・CLI の版で変わり、実際には使えるのに一覧に出ない名前がある（`claude-fable-5-2` のように行の `resolvedModel` でしか当たらないものなど）。

自動の振り分けは「選ぶ」と「送る」が同時で、間に人がいない。飛ばし間違えると、誰も気付かないまま次の候補（たいてい弱いモデル）で仕事が走る。反対に、通し間違えても CLI/API が理由つきで断る。

## 決定

- 自動の振り分けは、一覧に無いことを理由に候補を飛ばさない（`checkCandidate`・委譲先の再確認・任せ直しの再確認から `model_unknown` を外す）。残すのは、使えない・アカウント・使用量の確認、Devin の `runnableModel`、モデル名の形（`isModelId`）。
- 自動で選んだ子（`backend` を固定していない）が、最初のターンで CLI/API にモデルを断られ、まだ仕事が始まっていなければ、ADR 0302 の任せ直しの経路で次の候補で子を作り直す。断られた候補は `routing.skipped` に新しい理由 `model_rejected` で残す。候補が尽きたら `routing.exhausted` の文で失敗する。
- 断られた枠は 30 分、振り分けから外す（`core/model-rejects.mjs`。`core/slot-limits.mjs` と同じ鍵。保存せずサーバーの間だけ、延ばさない、同じ枠のターンが通れば消す、振り分けの設定を保存したら忘れる）。
- 断りの検出は `core/backends/` の中で行い、正規化した印（`turnResult` の `kind: 'model'`）として外へ渡す。Claude は `api_error_status: 404` の結果と断りの文面、Codex は `model_not_found` など。Antigravity・OpenCode・Grok・Devin は確実に見分ける形が無いので、理由つきの普通の失敗のままにする。
- 設定の警告（`settingsWarnings`・候補の `modelNotListed`）は止めない知らせとして残し、文面を「一覧に見当たらない（使えるかは CLI が決める）」に改める。行の `resolvedModel` に正確に当たる名前は一覧にあるものとして数える。

変えないもの: 固定の委譲（`backend` と `model` を書く）の `model_unknown`（`tasks.modelUnknown`）、親の送信（`sendModel`）、`reserveTurnSettings`、会話を作るときの `resolveModel`。

## 理由

- 一覧は正本ではない。使えるかどうかを一番よく知っているのは、実際に送られる CLI/API である。
- 飛ばし間違いは黙って弱いモデルで走る（気付けない）。通し間違いは最初のターンで理由つきに断られ、次の候補へ進む（気付ける・自動で回復する）。損の大きさが違う。
- 任せ直しの経路（0302）と枠の保留（slot-limits）が既にあるので、新しい仕組みは断りの記憶だけで足りる。

## 影響

- 一覧に無いモデルが候補に入っていても選ばれる。使えなければ最初のターンで断られ、`model_rejected` で 30 分外れる。
- Antigravity・OpenCode・Grok・Devin のモデルが使えないと、任せ直さず失敗として返る（CLI の理由つき）。
- 断りの文面は CLI の版で変わりうる。検出が外れたときは普通の失敗に戻るだけで、誤って任せ直すことはない。
