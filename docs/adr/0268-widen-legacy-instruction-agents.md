# Pleiad の指示の対象エージェントを、前の版の「Claude・Codex だけ」から今の全部へ広げる

状態: 承認（2026-10-24）

## 状況

Pleiad の指示（設定 › プラグイン）は、項目ごとに対象のエージェントを持つ。2026-09-27 にこの設定を作ったときは、選べるエージェントが Claude と Codex の 2 つだけだった（当時の全部）。2026-10-19 に対象を本番の全エージェントへ広げたが、保存済みの `agents: ['claude','codex']` は「当時の全部」か「その 2 つだけを選んだ」か判別できないため、そのまま残した。

その結果、当時作った項目は Devin・Antigravity・OpenCode・Grok の会話に入らず、会話側にもそのことが出ていなかった。利用者からは「メインエージェントは作業しない、という指示が伝わっていない」と見える。

## 決定

一度だけ、`u-…` の項目で `agents` がちょうど `['claude','codex']` のものを、今の全エージェント（`AGENTS`）へ広げる。保存に `agentsMigrated: true` の印を付け、以後は広げない。

- 既定の項目（`child`・`codexPolicy`）は触らない。`codexPolicy` は Codex だけが対象の項目で、広げると意味が変わる
- `['claude']` のような 1 つだけの選択と、3 つ以上の選択は広げない（当時の UI では作れない組み合わせなので、意図した絞り込みと読める）
- 会話の「この会話のプラグイン」では、入れなかった理由に対象のエージェントを添える（「このエージェントには入れない設定（Claude・Codex だけ）」）

## 理由

当時の UI には 2 つしか選択肢が無く、既定も 2 つとも選ばれていた。したがって `['claude','codex']` は「その 2 つだけを選んだ」ではなく「当時の全部」と読むのが自然で、広げないと新しいエージェントを足すたびに同じ取りこぼしが起きる。印を付けて 1 回だけにすることで、以後に利用者が 2 つだけへ絞り直した選択は壊さない。

## 影響

- 更新後の最初の起動で、prefs.json の `plyInstructions` が書き換わる（対象が広がる）。会話の次のターンから効く
- 2 つだけを意図して選んでいた利用者（2026-10-19 以降に作った項目）も、一度だけ広がる。狭め直すには設定で選び直す
- 既存の `agentsMigrated` の無い置き場では、初回起動時に一度だけ書き込みが走る
