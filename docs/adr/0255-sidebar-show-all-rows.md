# 0255 脇の区画は件数で絞らず、すべての項目を出す

- 状態: 承認（2026-10-23。利用者の指示「サイドメニュー、少なく表示するモードができてから、漏れが増えたので使いにくいことが分かりました。廃止してください。」）

## 状況

脇の置き場所の木（[ADR 0251](0251-sidebar-place-tree.md)）は、区画ごとに数件だけを出し、残りを「ほか n 件」に畳んでいた。押すと全部を出し、「少なく表示」で戻す。開いた区画は端末ごとの好み（`localStorage` の `agent-host-side` の `chMore`・`statusMore`）に覚えていた。

- 一時チャットの状態ごとに 5 件（2026-10-22、ADR 0251 の決定 2）
- チャンネルのスレッドは最近 3 件（2026-10-06 の脇の統合で入り、ADR 0251 の決定 4 が引き継いだ）
- ルーティンは次に動く時刻の近い 3 件、残りは［ほか n 件を見る］（2026-10-03、[ADR 0107](0107-side-chats-channels-tabs.md)）

開いている会話とあなた待ちは件数の外でも残していたが、それ以外の項目は畳まれた先に隠れた。利用者は、この形になってから項目の見落とし（漏れ）が増え、使いにくいと判断した。

## 決定

1. 脇のどの区画も、件数で絞らずにすべての項目を出す（一時チャットの状態ごとの会話と fork の器・チャンネルのスレッド・ルーティン）。「ほか n 件」と「少なく表示」の行・ボタン、開いた区画の好み、辞書の文言を取り除く。ADR 0251 の決定 2 と 4 のうち件数で畳む部分と、ADR 0107 のルーティンを 3 件に絞る部分を置き換える。
2. 区画の見出しの開閉（状態・一時チャット・チャンネルを畳む）と、fork の器の開閉は残す。一覧の長さを抑えたいときは、利用者が見出しを畳む。
3. 前の版が保存した `chMore`・`statusMore` は読まずに無視し、次に好みを保存したときに消える。

## 理由

件数で畳むと、畳まれた先の項目はそこにあることを示す数だけになり、探している会話やスレッドを見落とす。見落としを防ぐことを、一覧の短さより優先する。畳むかどうかを利用者が見出しで決める形なら、隠れている範囲は利用者が知っている。

## 影響

保存形式・操作の一覧・会話とスレッドの正本は変えない。端末ごとの好みから 2 つの項目が無くなる（残っていても害は無い）。狭い画面の引き出しは、脇の中で済む操作（見出しの開閉・フィルター・「…」）で閉じず、移動で閉じる点は変わらない。画面の今の形は design-system.md「脇」と §4.1、docs/channels.md のルーティンの節に書く。
