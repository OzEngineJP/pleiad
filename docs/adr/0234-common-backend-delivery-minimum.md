# 0234. 共通機能の配達を全バックエンドの最低限にする

状態: 提案（2026-10-20）

## 状況

配達物を能力の印で絞る契約は、受け取らない機能を明示させる。一方、実装が抜けても `false` と宣言すれば契約を満たすため、利用者が必要とする共通機能の不足は検出できない。

## 決定

標準で選べる全バックエンドについて、指示の配達・委譲・ブラウザー・操作の一覧・秘密情報と変数の能力を必須にする。`backend-contract` が対応する能力の印を検査し、各能力の契約試験が配達と消費を検査する。

## 理由

利用者がバックエンドを切り替えても、作業に必要な共通機能が届くようにする。能力を `false` へ変更するだけで実装漏れを隠せる状態を防ぐ。

## 影響

バックエンドを標準の選択肢へ追加するときは、この範囲の配達と対応する契約試験を実装する必要がある。それ以外の機能は引き続き能力の印で対応差を表す。上流の制約で最低限を満たせなくなった場合は、対応方針を改めて判断する。
