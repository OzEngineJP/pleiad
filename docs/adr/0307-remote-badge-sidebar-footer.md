# 0307 リモートの印を脇のいちばん下の行へ、上端をホストと同じ構造に戻す

- 状態: 承認（2026-11-09）

## 状況

リモートの窓だけ、帯の 1 行にホスト名のバッジ（左・脇の列の上）とタイトル行（右・会話の列の上）を載せ、脇の見出し（P の印・通知・開閉）を帯の下に落としていた（「H1・塗りなし」、2026-09-23）。帯の高さ・紙の角・行の中身がホストと別系統なので、上端を触るたびに 2 系統を直すことになる。700px 以下ではタイトル行が会話の中に戻るため、リモートの窓は幅で構造がさらに変わっていた。

## 決定

1. **帯・脇の見出し・タイトル行はホストと同じ構造に戻す。** `#sidebar` の `grid-area` を `1/1/-1/2`（見出しが帯に入る）に戻し、`main > .top` の fixed 化をやめる。`#sidebar` の `--p-top`・`--rail-top`・見出しの drag・mac の検索の行の左の余白など、`:not(.remote)` で外していた規則を全部ホストと同じにする。帯の地（`--surface-0`・点）の `!important` も外す（700px 以下で紙になるのもホストと同じ）。
2. **リモートの印は脇のいちばん下、アカウント行（`.side-foot`）の下の 1 行**「⇄ リモート: <ホスト名>」（`#remoteBadge`。差しの青 `--ink-blue`、ホスト名は等幅 `--font-mono`、高さとホバーは脇の行と同じ、上に髪の線）。つながっていない間だけ、行の右に弱い字で状態を添える（今のバッジと同じ規則・同じ文言）。押すと接続の情報の面（`.remote-pop`）が上向きに開く。面の中身・文言は変えない。
3. **畳んだレールでは ⇄ を設定の上に置く**（`#remoteRail`。左下の Pleiad Plus の丸は動かさない）。押すと同じ面が開く。
4. **700px 以下（脇が引き出し）ではタイトルの下の行（`#titleSub`）に「· ⇄ <ホスト名>」**を出す（`#remoteSub`、`.host-sub`。モバイル版の殻と同じ置き方）。押すと同じ面が開く。
5. **変えないもの**: 印の見た目と文言（⇄・「リモート:」・等幅のホスト名・差しの青）、面の中身、OS の窓タイトル「Pleiad — リモート: …」、タスクバーの重ねアイコン、モバイル版の殻の今の形（§8.2）。

## 理由

- 上端の構造が 2 系統あると、帯・脇の見出し・タイトル行を触る変更を 2 度直す。印を脇の中に移せばリモート専用の配置ルールをまるごと外せ、ホストとまったく同じ構造になる。
- 窓の身分は下端の身分欄（アカウント）と同居させると、「目立つが割り込まない」位置になる。一覧・状況の行を 1 段も食わない。VS Code のリモート印（左下）と同じ位置で、利用者の習慣にも合う。
- 脇の先頭（案 B）も目立つが、Bots の帯・絞り込みの札と並ぶ一覧の頭は既に密度が高く、「この窓の身分」の表示が一覧の項目と意味が混ざりやすいので選ばなかった。

## 影響

- `web/remote-badge.mjs`: バッジを `#sidebar` の `.side-foot` の次へ、面は body 直下のまま上向きに開く。`.side-rail` に設定の上の ⇄（`#remoteRail`）、`.title-sub` に `.host-sub`（`#remoteSub`）を足す。3 つの印は同じ面を開き、状態の添え方は共有する（`paint`）。Esc は開けた印へ焦点を戻す。
- `web/style.css`: リモート専用の配置（`#sidebar` の `grid-area`、`main > .top` の fixed、帯の `!important`、mac の見出しの位置）を外し、`:not(.remote)` ガードを解除する。バッジの行・レールの ⇄・上向きの面の規則を足す。700px 以下の `.host-sub` を `:root.remote-mobile` から `:root.remote` へ広げる。
- `web/index.html`・`web/client.mjs`: コメントと引き出しの inert の一覧（バッジは脇の中なので対象外）を新しい置き場に合わせる。レールのボタンの `tabIndex` は `paintSideChrome` がほかと揃える。
- `docs/remote.md` §7.2 を新しい形に書き直す。i18n の文言は足さない（今の `remote.*` を流用）。
- OS の窓タイトル・タスクバーの重ねアイコン・`desktop/remote-windows.cjs`・`desktop/remote-preload.cjs` は変えない。

## ずれの直し（2026-11-09 承認・同日追記）

実画面の計測で確定した 2 件のずれを直した:

1. **開いた脇で Plus の丸（`#sideAvatar`、`.side-avb`）が印の行に重なる。** 脇が開いている間だけ `.side-avb` を `bottom:40px`（印の行 32px＋元の 8px）にして `.side-me` の左に載せる（701px 以上・`:root.remote:not(.remote-mobile)`。丸の移りは `bottom` の `--dur-fast` の遷移）。畳んだレール（`:root.side-closed body:not(.settings)`）では最下部（`bottom:8px`）のまま。⇄→歯車→丸の並びは変えない
2. **700px 以下の添え字（`#remoteSub`、`.host-sub`）から開く面が窓の下端に出る**（約 540px 離れる）。添え字から開いたときはその行の直下に出す（`getBoundingClientRect` で位置を取る）。脇の行（`#remoteBadge`）・レール（`#remoteRail`）から開く面は下端固定（`bottom:44px`/`left:12px`）のまま

併せて、印の行の上の髪の線は `border-top` から `::before`（`linear-gradient(var(--line-faint) …)`）へ描き方を変えた。片側の `border-*` は `one-sided-line`（design-lint の --strict）で落ちるため。見た目（1px・`--line-faint`・行の上端いっぱい）は変わらない。

面の中身（再試行・「このウィンドウを閉じる」・Esc など）と文言（`remote.*`）、レールの並び、700px 以下の添え字の置き方、OS タイトル・タスクバー、モバイルの殻（`setupHostBar`）は変えない。
