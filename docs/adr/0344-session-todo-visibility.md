# 0344 会話の ToDo はその場で全文を開き、担当と委譲の進み具合を見せる

- 状態: 承認（2026-11-19）
- 関係: [0342](0342-session-todo.md) の閲覧、作業状態、リストとフローの決定を改訂する。

## 状況

会話の ToDo では、短い画面で文が切れると、閲覧中に最後まで読めなかった。分岐はリストでは見えず、フローでは項目と線が増えると進み具合を追いにくかった。委譲の進み具合と人の返事が必要な場面を知るには、会話の別の場所を開く必要があった。

## 決定

- 文は 2 行で省略し、切れた項目は押すか Enter / Space でその場に全文を展開する。フローの箱は下に伸ばして前面に置き、配置を保つ。閲覧中の展開では作業状態を変更しない。文の保存は既存の 1 欄で行い、500 字の上限を除く。
- 担当の名前と人の返事待ちを別々に記録する。先の作業による待ちは依存から求める。委譲は項目ごとにこの会話から開始したタスクを 1 件結べる。開始・完了・承認待ちを反映し、失敗・取り消し・中断は印を添える。手動で完了した項目はそのままにする。
- リストは分岐を字下げし、合流で戻す。フローでは未完了の線を破線にし、合流の入口を分け、選んだ項目へ入る線を強める。フローの項目が 8 件を超えるときは、先に終える順で先頭から、依存先がすべて同じまとまりに入る完了項目を集め、3 件以上なら一つの「完了 N」に畳む。分岐・合流や依存の無い完了項目も含める。残りは、全体の件数にかかわらず、分岐をまたがずに続く完了が 3 件以上あれば畳む。
- PC の浮く面はリスト 360px、フロー 640px を既定の幅とし、左・下・左下のつまみで変えられる。会話を切り替えても表示ごとの寸法を保つ。狭い画面と大きく表示した面では画面に合わせる。

## 理由と保存

展開しても前後の項目がその場に残るため、読む位置を保てる。人の返事待ちを担当や依存と分けると、今必要な行動が分かる。委譲タスクの状態をサーバー側で保存し、会話を開いていない間も進み具合を反映する。

追加情報は `todos.external` の既存の JSON 欄へ保存する。列の変更や形式 4 の移行は不要。既存の行は担当・返事待ち・委譲が空の項目として読める。形式 4 を扱う旧版はこの欄を保存時も保持する。サイズはブラウザーのローカル設定に置く。
