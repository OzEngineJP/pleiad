# ADR 0300: 空の Markdown 構造行を同じ行で解除する

- 状態: 一部置換（0301）
- 置き換えた: [0298](0298-markdown-editing-state.md)
- 置き換えられた: [0301](0301-markdown-rows-truth.md)（段落境界の `breakBefore`・空引用の Shift+Enter・遅延の続きの維持）

## 状況

空の引用・リストで Enter を押すと、現在行を浅くしたうえで次の編集行を追加していた。その後の Backspace は段落の区切りだけを消し、次の文字が CommonMark の lazy continuation として引用・項目へ戻った。空の子項目が残り、二重引用では編集画面と送信後の深さもずれていた。

## 決定

- 空の構造行の Enter と行頭の Backspace は、同じ処理で現在行を一段解除する。余分な編集行を作らず、カーソルはその行頭に残す。文字のある構造行の Enter は次の行へ進んで構造を続ける。
- 必要な段落境界は行の `breakBefore` として持つ（0301 で廃止。区切りは隣り合う行から送るときに作る）。引用から本文へ戻った場合、編集欄は引用と本文の二行、送信本文は `> a\n\nb` となる。選択削除・貼り付け・Undo/Redo・下書き復元でも境界を保つ。
- 解除直後の空の本文行でさらに行頭の Backspace を押すと、前行末へ結合し、その時点から結合先の構造で描く。`>`・Space・`a`・Enter・Enter・Backspace・`b` は `> ab` の一行になる。
- 入れ子も一段ずつ解除する。空の子リスト項目は親と同じ深さの次の項目へ戻し、元の空項目を残さない。引用内リストを解除した行には項目の字下げを残さない。
- 空の確定リストを解析のために仮の本文で補う場合、その行が段落を終えることも表す。空の引用は仮の本文で補わず、空行として解析する。編集画面・送信・保存復元の深さをそろえる。
- 未確定の記号に装飾を先付けせず Space で確定する。空引用の Shift+Enter、既存 Markdown の読込時の原文、正当な lazy continuation は維持する（0301 で、空引用の Shift+Enter は引用の行を足し、送る Markdown には遅延の続きを作らないに変えた。読込時の原文は維持）。共通構造解析と履歴の描画は変更しない。
- 0298 の本文と編集情報の分離・範囲API・保存時の検証は引き継ぐ。保存形式は `v: 1` のままとし、既存の編集情報も復元する。

## 理由

構造の解除は同じ行に対する操作としてそろえる。送信用の区切りを独立して持つことで、余分な空行を移動・削除する必要をなくし、解除後の本文が前の構造へ戻ることを防ぐ。

## 影響

`docs/design-system.md` の入力欄の規則を更新する。保存形式の変更・データ移行は不要。旧版で保存した編集行の数はそのまま復元し、読込だけで本文や空行を書き換えない。
