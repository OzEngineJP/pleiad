# 0041 内蔵ブラウザーを会話の隣に最小限で置く

- 状態: 承認（2026-09-27）。エージェントの操作は 0148 の第 7 段で PC の Chrome へ移し、内蔵ブラウザーは人が見るビューアとして残した（2026-10-08）。置換（0291）: 内蔵ブラウザーをやめ、右のパネルは会話ごとの Chrome のウィンドウにする

## 状況

エージェントが立てた開発サーバー（localhost）や、会話の中のリンク、HTML ファイルを見るには、今は OS の既定のブラウザーへ移る。見るために会話を離れることになる（design.md §2.1）。リモートの端末からは localhost も PC のファイルも届かない。Codex のデスクトップ版は、ユーザーとエージェントが同じページを見る内蔵ブラウザーを持つ。一方で「やらない」に公式クライアントの完全代替があり、ブラウザーは作り始めるとブックマーク・履歴・拡張・パスワード管理へ膨らみやすい。

## 決定

- 右パネルに「ブラウザー」モードを足す（ADR 0015 の表に `browserSlots` を加える）。Electron の `WebContentsView` をパネルの位置に重ねる。`<webview>` は使わない。
- 機能は **タブ・戻る/進む・再読み込み・アドレス欄・DevTools・別の窓に出す・既定のブラウザーで開く** に限る。既定のブラウザーで開く操作はアドレス欄の横に常に出す。ブックマーク・履歴の検索・拡張・パスワード管理・ダウンロードの管理は持たない。
- 保存領域は `persist:pleiad-browser` で、Pleiad 本体とリモートの窓から分ける。一度ログインすれば残る。権限の要求は既定で断り、`window.open` は新しいタブに変える。
- 会話の外部リンク・プレビューの中のリンク・「ブラウザーで開く」・localhost の URL の受け皿にする。Ctrl/⌘+クリックと中クリックは既定のブラウザー。設定で「リンクの開き先: 内蔵ブラウザー / 既定のブラウザー」を選べる。
- 既存のブラウザーとの接続と、ブックマーク・履歴・Cookie の取り込みは持たない。Windows の Chrome/Edge は 127 以降 App-Bound Encryption で他のアプリから Cookie を読めず、回避は権限の昇格やポリシーの変更になる。
- リモートの端末でリンクを押したら「この端末で開く / PC のブラウザーで見る」を選ぶ。localhost と PC のファイルは PC だけ。PC で見るときは内蔵ブラウザーの画面を中継で送り、入力を送り返す。

## 理由

- 見るために離れる負担を無くす目的に、見る・一緒に操作する最小限で足りる。普段使いの機能は既定のブラウザーが持っている。
- 保存領域を分けると、サイトのスクリプトや Cookie が Pleiad の認証に届かない。
- 採らなかった案: OS の既定のブラウザーへ渡し続ける（離れる負担が残り、エージェントと同じページを見られない）。Cookie を写す（Windows では読めず、写せても Pleiad が秘密を持つ面が増える）。ユーザーの Chrome につなぐ（Chrome 144 以降の許可で可能だが、今回は要らない。要れば agent-browser の `--auto-connect` で足せる）。

## 影響

- 内蔵ブラウザーはデスクトップ版のホストの画面だけ。ブラウザーで開いた Pleiad とリモートの窓では、リンクは今どおり新しいタブか端末のブラウザーで開く。
- エージェントの操作は ADR 0043、プレビューの外部の読み込みは ADR 0042。

## 追記（2026-10-06）: エージェントの操作は Chrome へ

[ADR 0148](0148-agent-browser-in-chrome.md) で、エージェントのブラウザー操作は PC の Chrome の専用の窓に移る。内蔵ブラウザーは**人が見るだけのビューア**として残り、エージェントは触らない（「エージェントの操作は ADR 0043」「同じ `persist:pleiad-browser` をエージェントと共有」はこの範囲で置き換わる）。保存領域は `persist:pleiad-browser` の 1 つ（人のログイン用）。「ユーザーの Chrome につなぐ」は採らなかった案だったが、ADR 0148 で採る（Cookie は写さず、Chrome へ直接つなぐ）。
