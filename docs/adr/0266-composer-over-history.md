# 0266 会話の入力欄を履歴に重ね、空いた所から履歴を見せる

## 状態

承認（2026-10-24）。利用者が、入力欄のまわりの空いた所（帯の左・箱の左右）を透過にし、履歴の見える所を増やすよう依頼。境目にグラデーションを付けないことは、撮り比べで決めた。

- 置き換えた: [0261](0261-wait-dot-and-composer-strip.md) の「履歴と入力欄を重ねず」と「作業ボタンの背景はホバー・フォーカス時だけ」（常時の背景は紙の面になる。重なる履歴が無いところの見た目は透明と同じ）。[0265](0265-activity-node-at-thread-end.md) が 0261 のまま残した部分のうち、この 2 点

## 状況

Chats の会話では、履歴（`#log`）が入力欄（`#composer`。作業ボタン・文脈・使用量の 1 段と入力の箱）の上で終わっていた。入力欄の帯は高さ 126px（PC）・153px（360px のスマホ）あり、見える部品は列（760px）の中の箱と、段の右寄せの札だけで、帯の左の空き・箱の左右の余白は紙の色で塞がっていた。その分だけ履歴を読む高さが削られていた。先に段の高さを詰めた（0261）が、塞いだ面そのものは残った。

## 決定

- 履歴（`.log-frame`）を `main` の下端まで伸ばし、入力欄をその下端に重ねる（`#composer` を `position:absolute; bottom:0`）。見える面（入力の箱・メーターの面・作業ボタン）だけが履歴を隠す。帯の左の空き、箱の左右の余白からは履歴が透けて見える。
- 空いた所は押しても選んでも履歴に届く。`#composer` は `pointer-events:none` とし、子（帯の中は帯の子）だけ `auto` に戻す。透けて見えるリンクは押せ、字はドラッグで選べる。
- 箱の下の余白（PC 12px・480px 以下は 8px、ホームバーの分を含む `--cpad-b`）は紙の面で塞ぐ。細い隙間に字の切れ端が覗くと散らかるため。左右の余白の履歴は箱の下端でそろって切れる。
- 面の無い字の部品（帯の作業ボタン・帯の状態の字・欄の上の一行の知らせ（失敗・接続・再開））は、紙の面（`--surface-paper`）に置き、透けた字と重ねない。作業ボタンのホバー・フォーカスの面は `--surface-2` のまま。
- 境目のグラデーション（紙から透明へのぼかし）は付けない。撮り比べると、帯の左に履歴が覗く高さ（約 32px）がぼかしでほぼ消え、重ねない場合と変わらなかった。見える面の縁がはっきりしているので、ぼかしが無くても字は読める。
- 入力欄の高さを `client.mjs` の `ResizeObserver` で測り、`.log-frame` の `--composer-h` に入れる。字の欄が伸びる・添付の札が付く・帯が出入りする・画面の幅が変わるたびに追う。
  - `#log` の末尾の余白は `--composer-h` + 24px（700px 以下は + 12px）。末尾まで送ると、最後の行と稼働表示は入力欄の上に出る。
  - 「最新へ」は下端から `--composer-h` + 14px（700px 以下は + 12px）。
  - 末尾の判定（`conversation-nav-view.mjs` の IntersectionObserver の rootMargin）からも `--composer-h` を引く（`setBottomInset`）。入力欄の後ろに隠れている所は「見えている」と数えない。
  - 高さが変わった時点で末尾にいたら、末尾に合わせ直す（伸びた入力欄の後ろに最後の行を隠さない）。末尾にいなければ読んでいる位置を動かさない。
- 重ねるのは Chats の会話の入力欄だけ。Channels のスレッドの入力欄・設定・Channels の画面は今のまま。ホームの 2 列（左に流れ）では、入力欄を会話の側（`left:var(--home-feed-w)`）に寄せる。
- 会話の地図（右端の細い筋）は `#log` の高さ全体に置いたまま（入力欄の後ろも含む）。列が 816px 未満で箱が右端に寄ると、地図の押せる領域の左の 4px ほどが箱の後ろに入るが、線は箱の外に残る。

## 理由

入力欄の帯のうち、使っているのは列の中の箱と右寄せの札だけで、残りは何も載らない面だった。そこを透かせば、画面の大きさを変えずに履歴の見える量が増える。押す・選ぶを履歴へ通せば、透けて見える字は飾りではなく、ふつうの履歴として使える。末尾の余白と末尾の判定を入力欄の高さに合わせれば、最後の行は今までどおり入力欄の上に出て、読み終わりの位置は変わらない。

## 影響

`web/style.css`（入力欄の重ね方・面・余白）、`web/conversation-nav.css`（最新への位置）、`web/channels-side.css`（ホームの 2 列）、`web/conversation-nav-view.mjs`（`setBottomInset`）、`web/client.mjs`（高さの計測）。試験は `tests/browser/composer-overlay.cjs`（重なり・押す・選ぶ・最新へ・高さの追従を PC・360px・右のパネルで）と `tests/browser/wait-strip.cjs`。データ形式・エージェントの実行には変更がない。
