# ADR 0347: チャットの送信を会話ごとに受け付け、準備と配送を後で行う

## 状態

承認済み（2026-11-23）。第 1 段はチャットの入力欄と作業場所の作成が対象。第 2 段（2026-11-23）はホームの Bot への送信、チャンネル・スレッドの入力欄、作業の画面の子への送信、音声の送信、履歴の巻き戻し・分岐して送るへ広げた。第 3 段（2026-11-23）は会話の ToDo の削除、会話名の保存、承認・委譲カードと ToDo の変更の表示、スクロールの補正、通知の既読へ広げた。

## 状況

チャットの入力欄は会話間で共有する。会話の作成、設定の保存、worktree の作成が終わるまで待ってから欄を読むと、その間に別の会話を開いた場合に送信を続けられない。送信待ちの読み書きも、配送の準備が終わるまで同じ会話で待たされていた。

## 決定

- 画面は送信を押した時点で宛先、メッセージ ID、本文、添付の順序と文中の位置、設定、下書きの版を確定する。受付確認後は送った版だけを片付ける。
- ホストは会話の送信待ちに項目を永続化して受付を返す。設定の適用と worktree 作成は配送側で進め、準備中も一覧取得と配送前の取り消しを受け付ける。再起動時は配送前の項目を続ける。配送開始後の結果が確認できない項目は「届いたか不明」として扱う。
- 会話の作成要求には画面が発行した要求 ID を使う。ホストは正式な会話 ID と要求 ID の対応を保存する。作成の再試行では同じ会話を返し、送信の再試行では会話の送信待ちに保存した同じメッセージ ID の項目を返す。
- 通常のターンと途中送信はその項目の設定を使う。後から選んだ設定は次の送信で使う。使えなくなった接続先やアカウントはその項目の失敗理由にする。
- 第 2 段の入力欄（ホームの Bot、チャンネル・スレッド、作業の画面の子、音声）も、押した時点の宛先・本文・添付・設定・下書きの版で送る。応答を待つ間に別の宛先へ移っても、送り先と片付ける下書きは押した時のもので、移った先の字・添付・表示には触れない。失敗は押した時の宛先の欄へ戻すか、移った後なら通知で知らせる。
- 履歴の巻き戻しと分岐は、実行中かを対象の会話で確かめ、履歴の変更と送る内容を 1 つの要求にする。巻き戻しはホストが先に同じメッセージ ID の受付を確かめ、受付済みなら巻き戻さずにその項目を返し、内容が違えば履歴を変えずに断る。分岐は `fork` に送る内容（`send`）を渡し、ホストが分岐の作成と受付をまとめて行う。送る内容が不正なら分岐を作らない。受付に失敗したときは分岐先の下書きに戻す。
- 第 3 段: ToDo の項目を消すときは、残りの項目のつなぎ直しを押した時点の並びで決め、`todos.remove` の `items` に入れて削除と同じ版で 1 回だけ書く。書き込み中の印は会話ごとに持つ。会話名の保存は、会話 ID と値の組で送っている間の二重送信を止める。
- 第 3 段: 承認カードは ID と版（`rev`。`permissionUpdate` と開き直しの保留中の一覧に載る）で当て、片付いた ID と版の古い中身は当てない。承認の差し替えと中継のカードの終わりは、開いていない会話の分も受ける。委譲カードは更新時刻で比べ、古い取得結果で新しい行を上書きしない。チャンネルの写しにしか無いカードも取り直す。開いていない会話の ToDo の変更は会話ごとに覚え、読み直しても変更の印を消さない。スクロールの補正は、表示している項目が替わったらやめる。
- 第 3 段: 通知の一覧の既読は、画面が実際に表示した位置までにする。ホストは live の履歴の返事に読み出した時点（`shownAt`）を付け、画面は描き終えた会話にだけ、閲覧状況の報告（`presence`）でその時点を返す。ホストはその時点までの通知を既読にする。描き終えた画面が見ている会話で起きた通知だけを、最初から既読で載せる。読み込み中・読み込みに失敗した画面の報告では既読にしない。スマホへ通知を送らない・消す判定は、今の閲覧状況の報告のまま使う。

## 理由

会話を切り替えても、開始時に確定した対象に処理を続けられる。受付と準備の時間が分かれ、画面や接続が切れても同じ ID で受付を確かめられる。

## 影響

入力欄と配送の見え方は [design-system.md](../design-system.md) の「入力欄の待ち」「作業中の設定の変更」に記載する。既存の送信待ちの項目は従来の設定の取り込み方で動く。ADR 0326 の「待ちの間に別の会話へ移ったら送らずに知らせる」動きと、その記録 `submit-switched` は外した。
