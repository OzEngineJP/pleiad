# 0233: 公開前に実画面の起動を検査し、不具合版の配布を取り下げる

## 状態

承認（2026-10-19）。利用者が配布停止と実画面の起動検査を依頼。

## 状況

0.28.1 への自動更新後、画面の初期化が `usageSource` の宣言前の参照で停止した。サーバーの応答と通常テストの成功だけでは、会話一覧と入力欄を利用できることを保証できなかった。公開済みの添付ファイルは immutable で、更新メタデータの差し替えによる停止もできない。

## 決定

- ビルド済みパッケージの実画面を Chromium で開き、初回起動と保存した会話の再起動後の表示を検査してから公開用 artifact をアップロードする。通常テストの再利用時も省略しない。
- 不具合版のタグと理由を台帳に記録し、公開処理で拒否する。配布済みの場合は監査情報を保存してから Release と添付ダウンロードを取り下げ、ソースのタグは保持する。
- 配布停止後は公開一覧と Latest、公開後は実際の更新メタデータまで読み直し、利用者の更新先が切り替わったことを確かめる。

## 理由

画面のソース順序を検査するテストだけでは、別の初期化例外を防げない。ソースを直接開くだけでも、パッケージに必要なファイルが欠けた場合を見落とす。公開後に書き換えられない配布物には、停止方法を別途用意する必要がある。

## 影響

リリースに Electron の画面検査を追加する。検査は fake・一時データを使い、本物の会話・資格情報・動作中のアプリに触れない。配布停止は既に取得したファイルの回収や旧版への自動復帰を保証しない。インストーラーと main/preload の確認は従来どおり別途必要。
