# 0063 会話の移動: 残る問い・最新へ・地図・目次と検索

- 状態: 承認（2026-09-29）

## 状況

長い会話では、前の決定や質問を探すだけで何画面もさかのぼる。読んでいる返答が何への返答かを見失い、さかのぼった後に最新へ戻る手段はスクロールしかなく、読み返している間に届いた返答にも気付けない。会話の中を言葉で探す手段も無い。利用者がモック（AsIs / ToBe、明暗・デスクトップ・スマホ）で形を確かめて承認した。

## 決定

会話の画面に 4 つの部品を足す（形・大きさ・時間・出る条件は [design-system.md](../design-system.md)「会話の移動」）。

- **A 問いが上に残る**: 返答を読んでいる間、その返答を生んだ発言を会話の上端に 1 行で残す。問いの下端が上端から出たときだけ出し、次の問いで入れ替える。影は使わず、白から透明へのグラデーションでつなぐ。
- **C 最新へ**: 末尾から離れたときだけ、会話の右下に丸いアイコンボタン。新着は青い丸（脇の一覧の「完了・未確認」と同じ印）、走っている間は既存の弧。Alt+↑/↓ で前後の自分の発言、End で最新へ。
- **B 会話の地図**: 会話の右端の細いレールに各発言を点で置く。長さが画面の 2 倍を超えるときだけ出す。区別する形は承認待ち・圧縮の境目・分岐・可視化だけ。触れると時刻と発言の中身を出す。点・空白のドラッグ・キーで移動する。
- **D 目次と会話の中の検索**: 右パネル（ファイルプレビューと同じ枠）に、発言の目次と検索。対象を「発言 / ＋返答 / ＋ツール」で切り替え、並び順を替えられる。狭い画面では A の見出しからシートで開く。

抜粋（上に残る問い・地図の浮く面・目次の行）は、改行と連続する空白を 1 つの空白に畳み、コードブロックは「‹コード›」、添付の行は「添付 ファイル名」に置き換える。

採らなかった案:

| 案 | 理由 |
|---|---|
| 「元の位置へ」のボタン | 目次とキー操作（Alt+↑/↓）で足りる。押せる物を増やさない。 |
| 地図の失敗の印 | 地図は戻る先を探す道具。失敗はツールの行（✕ 失敗）で分かる。 |
| 新着の件数の札 | 脇の一覧の青い丸と別の語彙になる。件数は名前（title・読み上げ）で伝える。 |
| 過去のターンを自動で畳む | 読んでいた場所が変わり、文脈や検索結果が隠れる。 |
| 本文を縮小した地図 | 文字が読めず、コードや表の密度に引っ張られる。 |
| 常時表示の前へ・次へ | 読む場所を圧迫する。目次とショートカットで補う。 |

## 理由

読む場所を保つこと（新着でも動かさない）、既にある語彙を使うこと（青い丸・弧・右パネルの枠）、押せる物を増やさないことを優先した。地図は本文の縮小ではなく、発言を点にして実際の高さに比例させるので、コードや表の密度に引っ張られない。検索を右パネルに置くのは、会話の本文を隠さずに結果の一覧と本文を並べて読めるため。

## 影響

- `#log` が `.log-frame` の中に入る。会話の右端に地図が出る間は、`#log` の細いスクロールバーを隠す（地図が現在位置とドラッグの役を引き継ぐ）。
- 会話に `tabindex=0` を付ける（Alt+↑/↓・End を受けるため）。
- 発言の位置は 1 度の走査で測って持つ。長い会話を開く時間とスクロールの重さを悪化させないことを条件とする。
- 右パネルの枠（`web/side-panel.mjs` の `customSlots`）に目次を載せる。幅は 340px 前後。

## 改訂（2026-10-02）: 狭い画面も残る問いは問いへ戻す

- 状態: 承認（2026-10-02）。
- 決定: 決定 D の「狭い画面では A の見出しからシートで開く」のうち、**上に残る問い（A）を押すと目次のシートが開く**部分をやめる。残る問いは、どの幅でも押すとその問いの先頭へ送り、着いたら吹き出しに既存の `note-flash` の輪を 1 度だけ付ける。目次は見出しのアイコン（狭い画面でも常にある）から開く。
- 理由: 当時は狭い画面で目次へ入る口を残る問いに兼ねさせていたが、今は見出しに目次のアイコンがある。「問いへ戻りたい」のに目次のシートと検索欄の自動フォーカス（タッチではキーボードが上がりうる）が出ると、押した結果が看板（「↳ 時刻 · 抜粋」）と食い違う。残る問いの長押しで目次を開くような隠れた操作は足さない（この ADR の「押せる物を増やさない」）。
- 影響: 押したときの処理から `openToc` を外す（`web/conversation-nav-view.mjs`）。title・読み上げ名は「この問いへ戻る」。静かな読み直し（[ADR 0062](0062-incremental-session-load.md)）で行が置き換わっていたら、押した時点で並びを取り直して発言の uuid で引き直す。ほかの決定は変わらない。

## 改訂（2026-10-25）: 狭い画面では残る問いを出さない

- 状態: 承認（2026-10-25）。
- 決定: 狭い画面（700px 以下）では、上に残る問い（A）を出さない。広い画面では従来どおり出す。問いへの移動は、狭い画面でも目次・スクロールでできる（地図はもともと狭い画面では出さない）。
- 理由: 狭い画面では 62px の帯が表示領域を圧迫し、利用者が不要と判断した。
- 影響: `web/conversation-nav-view.mjs` の `paintSticky` が `narrow` で出すかを決める（出さない間は `turn.ub` の測定も走らない）。狭い画面向けの `.nav-sticky` の規則を `web/conversation-nav.css` から外す。ほかの決定は変わらない。
