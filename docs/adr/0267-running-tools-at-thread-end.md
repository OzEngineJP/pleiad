# 0267 実行中のツール行を会話末尾へ移し、完了したら履歴へ戻す

## 状態

承認（2026-10-24）。実行中のツールを末尾に置いて動きを示し、考え中の概算トークン数を消す形。

- 一部を置き換える: [0061](0061-tool-call-bundles.md) の実行中の通常ツールを履歴の最新行に置いて末尾表示を隠す部分と、[0265](0265-activity-node-at-thread-end.md) の末尾を単一の稼働行として扱う部分。
- 維持する: 0061 の完了したツールのまとまり・承認カード・委譲カード、0265 の 7px の節・本文列・弧と衛星、[0266](0266-composer-over-history.md) の入力欄と履歴の重なり・末尾余白・最新へ・末尾判定。

## 状況

通常ツールを実行すると、末尾の稼働表示を隠し、呼び出した発言の中のツール行に弧を置いていた。並列実行では新しい行を優先する折り畳みで古い未完了の行も隠れ、本文が続くと実行中のツールを探すために遡る必要があった。

会話末尾に実行中のツール行そのものを置けば、同じ情報を二重に出さず、現在の作業を読み取れる。考え中の概算トークン数は次の操作の判断に使わないため、この稼働表示から除く。

## 決定

### 実行中のツールの置き場所

実行中の通常ツールは、会話の最後の節（`.mw.activity`）へ同じ行を移す。左の 7px の節と本文列は 0265 のままで、各行の左に 18px の `runMark()`、その右に「実行中」「読み込み中」「検索中」などの動詞・対象・経過を置く。新しい面・枠・帯・完了率・点滅は足さない。

同時に走るツールは開始順に並べ、初期表示は 3 件と「ほか N 件」にする。ボタンを押すと残りも同じ節の中で開く。完了した行だけが抜け、残った行を並べ替えない。各行の時計は呼び出しの開始から `m:ss`、1 時間以上は `h:mm:ss`。別のツールの開始や完了で時計を戻さない。実行中は開始時刻のボタンより経過を優先する。

実行中の行は入力・結果を開け、キーボードでも操作できる。対象を省略した場合も詳細で全文を読める。スマホの押せる行は 44px 以上を確保する。状態変更は `role=status` で通知し、回転印と毎秒変わる経過を読み上げない。

### 状態と優先順位

| 状態 | 末尾の表示 | 印・経過 |
|---|---|---|
| 通常ツール 1 件・複数件 | 開始順のツール行 | 各行に弧と、その呼び出し開始からの経過 |
| ツールを実行しながら考える・本文を書く | 思考や本文は節の手前に増え、ツール行は末尾に保つ | ツール行を優先し、汎用の弧を重ねない |
| 親が動き、子も実行中 | 親のツール・思考・応答 | 子の件数は既存の作業の入口に残す |
| ツールなし・考え中 | 「考えている」 | 弧とターン開始からの経過。概算トークン数は出さない |
| ツールなし・応答中 | 「書いている」 | 弧とターン開始からの経過 |
| 親は進めず、子の結果だけを待つ | 「サブエージェントを待っている」 | `satMark(n)` の衛星（最大 3 個）とターン開始からの経過 |
| 完了後の次の状態が未到着 | 完了行を履歴へ戻して次を待つ。0.6 秒以上空くと既存の「動いている」 | すぐ次のツールや思考が来る場合は汎用行を挟まない |
| 承認・回答待ち | 既存の承認カード・質問カードをその場所に置く | 既存の ◆ と文言。回る印を付けない |
| 中断要求から終了通知まで | 「中断している」 | 弧。終了したら印を外し、止めた行を履歴へ戻す |
| 接続切断・状態が古い | 既存の接続表示と最後に分かっていた対象 | 回転・時計を静止し、復帰時に元の開始時刻から再計算 |
| ターン完了・待つ子もなし | 末尾の稼働行を外す | 完了した行に回転印を残さない |

### 行の完了と入れ替わり

ツールの終了イベントは呼び出し ID に対応する同じ行へ適用する。その行を元の発言・まとまり・順序へ戻し、結果・開いていた詳細・選んだタブ・キーボードの焦点を引き継ぐ。履歴と末尾に複製せず、本文や委譲で分けたまとまりも並べ替えない。履歴へ戻した開始時刻のボタンは、終了時刻ではなく元の開始時刻を表示する。

行の入れ替わりは既存の `--dur`（240ms）と `--ease-out`（`cubic-bezier(.2,.7,.2,1)`）を使う。完了行は移動前後の座標差をつなぎ、不透明度 `.65 → 1`。次の末尾は `translateY(6px) → 0` と不透明度 `.3 → 1` で現れる。弧は 2 秒、衛星は 4 秒で 1 周する。

動きを減らす設定（`prefers-reduced-motion: reduce`）では移動・フェード・回転を止め、瞬時に切り替える。静止した印・状態文言・経過は残す。ページ非表示中は回転を一時停止する。

### スクロールと再表示

会話末尾を見ていた場合だけ新着と行の移動に追従する。履歴を読んでいる場合は下へ引き戻さず、0266 の入力欄の実測高さに合わせた末尾余白・末尾判定・「最新へ」を共通で使う。

履歴の再生・ストリームの復元でも、呼び出し ID・元の所属と順序・開始時刻から同じ配置と経過を組み立てる。再表示で未完了の古いツールを履歴の折り畳みへ隠したり、経過をゼロへ戻したりしない。

## 影響

概算トークン数の削除は画面側だけで行う。`web/client.mjs` の `thinkTokens` の状態と、日英辞書の `activity.thinkingTokens_*` を除き、サーバー・バックエンドのイベントは維持する。使用量・文脈量・考えた内容の文字数はこの変更の対象に含めない。

再発防止では単独ツール、並列 5 件で古い未完了も末尾にあること、途中に本文が増える場合、完了行の帰属・詳細・焦点・時刻、概算トークン数がないこと、再表示を確認する。狭い画面・ダーク・動きを減らす設定・履歴閲覧中のスクロールも同じ規則で扱う。
