# コンテンツのレーティングとそのほかの申告（回答案）

## コンテンツのレーティング

Play Console の「アプリのコンテンツ › コンテンツのレーティング」で、IARC の質問票に答える。答えによって、地域ごとの機関（IARC・ESRB・PEGI など）のレーティングが付く。答えが不正確だとアプリが削除・停止されることがあり、内容を変えたら答え直す（[コンテンツのレーティング](https://support.google.com/googleplay/android-developer/answer/9898843)、[アプリとゲーム、そこで配信される広告のコンテンツのレーティングに関する要件](https://support.google.com/googleplay/android-developer/answer/188189)）。質問の言い回しは Play Console の画面で変わることがあるので、下は中身ごとの答えの方針として使う。

### カテゴリ

**ゲーム・SNS 以外のアプリ（英語の画面では「All Other App Types」）。** Pleiad は、利用者が自分の PC のエージェントの作業を見て承認するための道具で、ほかの利用者とつながる機能が無い。

### 答え

| 中身 | 答え | 理由 |
|---|---|---|
| 暴力・流血・性的な内容・裸・下品な言葉・差別・薬物・酒・たばこ・ギャンブル・怖い内容 | いいえ | アプリ自身はそういう内容を持たない。表示するのは、利用者が自分のアカウントで使う AI のエージェントの、利用者自身の作業の出力 |
| ほかの利用者と交流する・内容を交換する（チャット・投稿・共有） | いいえ | 会話の相手は利用者自身の PC だけで、ほかの利用者はいない。Plus のアカウントは、自分の PC と端末を同じアカウントでつなぐためのもので、利用者どうしの交流は無い |
| 利用者の位置を、ほかの利用者と共有する | いいえ | 位置情報を扱わない |
| デジタルのものを売る（アプリ内の購入） | いいえ | 無料・購入なし |
| 年齢制限のある品やサービスの宣伝・販売 | いいえ | |
| ウェブブラウザーや検索エンジンか（制限の無いインターネットへのアクセス） | いいえ | 外のリンクは端末のブラウザーで開く。アプリの中の WebView は利用者のホストの画面だけを出す |
| 外部の内容の宣伝 | いいえ | 広告なし |

見込み: すべての年齢（IARC 3+、全年齢相当）。

### 気をつけること

- AI が作る内容: Play の AI 生成コンテンツのポリシーは、AI で内容を作るアプリに、アプリを出ずに不快な内容を開発者へ報告・フラグできる機能を求める（[AI 生成コンテンツ](https://support.google.com/googleplay/android-developer/answer/13985936)）。Pleiad のアプリは AI を動かさず、利用者の PC の Pleiad が、利用者自身のアカウントで AI のサービスを使う。それでも、審査員が「AI のチャットのアプリ」と見ることはありうる。質問票や審査で問われたら、上の構成を説明する。求められたときの対策は、ホストの画面の「…」の操作に「問題を報告」（開発者への連絡先を開く）を足すこと。
- 質問票に生成 AI についての問いが出たら、「アプリ自身は生成 AI を組み込まず、利用者が PC で使う AI の出力を表示する」として答える。

## ターゲット層

**18 歳以上だけ**を選ぶ。

- 子ども向けではない。13 歳未満を含めると「ファミリー」のポリシーの要件（広告・SDK・保護者の同意など）がかかる。
- ホストで使う AI のサービスの利用規約が成人を前提にしているものがある。
- ストアの掲載は子どもの気を引く作りにしない（[listing.md](listing.md)）。

## そのほかの申告

| 申告 | 回答 |
|---|---|
| 広告 | 含まない |
| アプリへのアクセス | 制限がある（[app-access.md](app-access.md)） |
| データセーフティ | [data-safety.md](data-safety.md) |
| 前面サービス | `remoteMessaging`（[foreground-service.md](foreground-service.md)） |
| 政府のアプリ | いいえ |
| 金融に関する機能 | なし |
| 健康 | なし |
| ニュース・雑誌のアプリ | いいえ |
| 新型コロナウイルスの接触確認・状況のアプリ | いいえ |
| アカウントの削除 | 当てはまる（Plus のログインで、アカウントができる）。アプリの「アカウントを管理」から開くページで削除でき、Web の削除の URL を Play Console に入れる（[data-safety.md](data-safety.md)） |
