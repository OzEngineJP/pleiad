# デスクトップ対応とオンボーディング

## 配布と起動

Pleiad は共通の web/core を Electron に同梱する。利用者による Node.js・サーバーの起動は不要。
Windows は NSIS（x64/ARM64）、macOS は DMG/ZIP（Intel/Apple Silicon）。
開発は Node.js 22.13.0 以上で `npm ci` → `npm run desktop`。
`npm run desktop:pack` は実行可能なディレクトリ、`npm run desktop:dist` はインストーラーを生成する。
Windows で x64 だけ生成する場合は `npm run desktop:dist -- --win --x64 --publish never`。
macOS の配布物は macOS 上で生成する。`.github/workflows/desktop.yml` は手動実行の両OSパッケージ生成。

署名・Apple notarization の資格情報は含めていない。生成物は開発・評価用の未署名配布物であり、
一般配布前に発行者の証明書を用意し、Windows署名・macOS署名/notarizationを組み込む必要がある。
Windows ARM64、macOS のインストール・起動・アップグレードは各実機で確認する。
自動更新・署名付き配布・先行版と段階配信は [デスクトップのリリース運用](desktop-releases.md) を参照。
ストア配布は対象外。

専用のlocalhostサーバーを空きポートで起動し、ランダムトークンをIPCで画面へ渡す。
Node integration 無効、context isolation と sandbox 有効。公開するIPCはフォルダー選択のみ。
外部HTTPSリンクはOSブラウザーで開き、外部ページをアプリ内で実行しない。
二重起動は既存ウィンドウに戻す。終了時はサーバーへ実行中件数を問い合わせ、作業中なら会話へ戻す。
データは既存の `~/.agent-host`、各CLIのログイン・履歴も既存の保存先を使用する。
開発版（パッケージ版でない起動。`npm run desktop`）は、インストール版と別のアプリとして起こす。アプリの名前を `Pleiad Dev` にし（キーチェーンの項目 `Pleiad Dev Safe Storage`・userData `Pleiad Dev`）、既定のデータ置き場を `~/.agent-host-dev` にする（`AGENT_HOST_DATA` を渡せばその場所）。インストール版に開発版のキーチェーンの確認を出さず、二つを同時に起こせる（`desktop/dev-identity.cjs`・[ADR 0255](adr/0255-separate-dev-desktop-identity.md)）。

## 利用可能になるまで

初回は設定とは別のオンボーディング画面を開く。初回表示済みの記録を完了状態とは別にサーバーへ保存する。
表示済みで利用可能なエージェントが1つ以上あれば、途中で閉じてもリロード時に再表示しない。
エージェントが全て未導入・未ログインの場合は再表示する。認証状態の取得失敗やログイン処理中は未設定と決めつけない。
設定は左メニューの「エージェント設定」「外観」「コンテキスト」で構成し、使い方ガイドは置かない。
完了状態・選択エージェントもサーバー側に保存し、デスクトップのポート変更で初期化しない。作業ディレクトリは初期ダイアログのエージェントの一覧の下で選ぶ（[ADR 0033](adr/0033-choose-working-directory-in-onboarding.md)）。既定はホーム（前に決めたものがあればそれ）で、フルパスとホームであることを見せ、「フォルダーを選ぶ…」で変えられる（デスクトップ版は OS のダイアログ、ブラウザー版は簡易ブラウザー）。選ばずに始めてもよく、「あとで」で閉じた場合もホームで始まる。どちらも会話画面で変更可能。

| 利用者・環境の状態 | 導線と完了条件 | 対応 |
|---|---|---|
| CLIが1つもない | 各行をインストールリンクにする。好きな1つを入れて再確認 | 実装 |
| 1つだけインストール済み | そのCLIにログインし選択。他は必須にしない | 実装 |
| 既存CLIでログイン済み | 既存認証を確認し、再ログインなしで進む | 実装 |
| インストール済み・未ログイン | ログインを開始し、完了後にCLIの状態を再取得 | 実装 |
| 認証状態不明・古いCLI | 未ログインと確認エラーを分け、更新・再確認へ案内 | 実装 |
| ログインの期限切れ（Claude） | CLI は期限が切れてもログイン済みを返すので、状態の確認では分からない。会話のターンが 401 で失敗したときに、その失敗の行と設定の行で知らせ、その場でログインし直せる（design-system.md「ログインの期限切れ」、[ADR 0212](adr/0212-claude-auth-expired.md)） | 実装。Codex・Antigravity は未対応 |
| 会社のSSO・利用制限・プロキシ | 各CLIの公式設定を使用。管理者に確認する案内 | 案内。端末管理の自動設定はしない |
| APIキー／クラウドプロバイダー利用 | CLI側の既存設定を利用。Claude statusが有効と判定した場合に進む | 設定方式ごとの実機確認が必要 |
| 複数エージェント | 全部の状態を表示し、最初に使う1つを明示選択 | 実装 |
| インストール直後、PATH未反映 | 状態を再確認。PATHと一般的なユーザーインストール先を探索 | 実装。独自場所は環境変数で指定 |
| 作業フォルダーの指定 | 初期設定ダイアログで選べる（既定はホーム。フルパスを表示）。会話画面でも変えられる | 実装 |
| 初期設定を途中で閉じた／再起動 | 表示済みかつエージェント設定済みなら再表示しない。認証情報はCLI側に残る | 実装 |
| 設定完了後にCLI削除・認証失効 | 完了履歴とは別に現在の状態を再確認できる | 実装 |
| インターネット接続不可／利用上限 | 失敗内容から再試行。利用可能判定は認証・フォルダー確認まで | 実サービスの疎通・残高保証はしない |
| WSL内にだけCLIがある | Windows側のインストールを案内 | WSLの自動橋渡しは未対応 |

インストール先: [Codex公式](https://developers.openai.com/codex/cli/)、
[Claude Code公式](https://code.claude.com/docs/en/setup)。
Claudeは [公式CLI](https://code.claude.com/docs/en/cli-reference) の `auth status --json` / `auth login` / `auth logout` を使用する。
認証トークンをアプリで抽出・複製しない。ログイン中の重複実行を拒否し、10分で時間切れにする。

独自CLI: `AGENT_HOST_CLAUDE_BIN`、`AGENT_HOST_CODEX_BIN`。

## 利用開始後の業務パターン

全職種の名前を列挙する代わりに「入力→作業→成果→判断→継続」で分類する。
以下は業務パターンの検討表。設定画面に使い方や例文の一覧は表示しない。

| 業務パターン | 主な入力 | 最初の依頼 | 成果の確認 | 次の操作 |
|---|---|---|---|---|
| 調査・資料把握・引き継ぎ | 資料、議事録、既存成果物 | 範囲を確認して要点・根拠・不明点を整理 | 出典・抜け・新旧情報 | 不明点を追加調査、状態を付けて保留 |
| 文書・報告書・営業メール | 元資料、読者、目的 | 構成案から下書きへ | 読者適合・固有名詞・事実 | 修正依頼、送信は別途判断 |
| 集計・分析・経営報告 | 表データ、指標、期間 | 列・欠損・集計単位と手順を確認 | 分母・数字・検証・元データ保持 | 条件変更、別案を分岐 |
| 開発・修正・レビュー | リポジトリ、再現条件、仕様 | 構成・方針・検証を確認 | 差分・テスト・副作用 | 追加修正、レビュー待ち、完了 |
| ファイル整理・定型業務 | フォルダー、命名規則、頻度 | 対象と変更予定を先に列挙 | 対象外・例外・上書きの有無 | 承認して実行、手順を再利用 |
| 企画・比較・意思決定 | 目的、制約、複数案 | 評価軸・選択肢・前提を整理 | 基準・反例・未検証の仮定 | 枝ごとに案を深める、判断待ち |

共通の使い方: 目的と完成条件を伝える → 資料・作業場所を指定 → 承認・質問へ回答 →
成果を確認 → 同じ会話で修正／別案を分岐 → 名前と状態で整理 → 検索から再開。
利用中の割り込み、中断、別の仕事への切り替え、設定変更の次ターン適用、
失敗後の再試行、数日後の再開もガイドに含める。

## 検証観点

- 初回・再起動・途中離脱、未導入・未認証・認証済み・確認失敗の各状態。
- ログイン済みのエージェントを1つ選んで開始できる。未ログイン時はログイン導線が機能する。
- ダイアログの中でログインを始めた場合も、URL と手貼りの欄がダイアログ内に出る（modal の裏に隠れない）。
- モーダルのEsc・閉じる・背景クリック、一覧の矢印キー選択とフォーカス移動、狭い画面と明暗テーマ。
- 例文は未送信の新規会話に入り、既存下書きは残る。
- 外部リンク、通常終了・実行中の終了抑止。
- 各OSのインストーラー、CLIを入れていない端末、各CPU、署名済み配布の検証はリリース前に別途必要。
