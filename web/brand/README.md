# Backend logos

These marks identify the corresponding agent in the session list. They belong to
their respective owners and are stored locally to avoid runtime third-party requests.

- `openai.svg`: transparent OpenAI Blossom from LobeHub's icon collection
  https://cdn.jsdelivr.net/npm/@lobehub/icons-static-svg@latest/icons/openai.svg
  (https://github.com/lobehub/lobe-icons, MIT). Added a path ID and fill rule for
  SVG `use`; the path geometry is unchanged. Rendered black in light mode and white in dark mode.
  Brand guidelines: https://openai.com/brand/
- `antigravity.svg`: Antigravity mark from LobeHub's icon collection
  https://cdn.jsdelivr.net/npm/@lobehub/icons-static-svg@latest/icons/antigravity.svg
  (https://github.com/lobehub/lobe-icons, MIT). Added a path ID for SVG `use`; the path
  geometry is unchanged. Rendered in the Google blue.
- `claude.svg`: Claude mark, downloaded unchanged from https://claude.ai/favicon.svg
- `opencode.svg`: opencode mark from LobeHub's icon collection
  https://cdn.jsdelivr.net/npm/@lobehub/icons-static-svg@latest/icons/opencode.svg
  (https://github.com/lobehub/lobe-icons, MIT). Added a path ID for SVG `use` and the title; the path
  geometry is unchanged. Rendered in the text color (retrieved 2026-10-18).
- `devin.svg`: Devin mark from LobeHub's icon collection
  https://cdn.jsdelivr.net/npm/@lobehub/icons-static-svg@latest/icons/devin.svg
  (https://github.com/lobehub/lobe-icons, MIT). Wrapped the three paths in a `mark`
  group for SVG `use`; the path geometry is unchanged. Rendered like OpenAI (dark in
  light mode, white in dark mode).

- `grok.svg`: Grok mark from LobeHub's icon collection
  https://cdn.jsdelivr.net/npm/@lobehub/icons-static-svg@latest/icons/grok.svg
  (https://github.com/lobehub/lobe-icons, MIT). Added a path ID for SVG `use`; the path
  geometry is unchanged. Rendered in the text color (retrieved 2026-10-18).

Retrieved 2026-09-12 (`antigravity.svg`: 2026-09-16). Original colors and aspect ratios are preserved.
