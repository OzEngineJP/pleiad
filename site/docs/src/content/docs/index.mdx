Pleiad は、AI のエージェントに仕事を頼むためのアプリです。使うエージェントと作業ディレクトリを選び、会話で指示を送ると、エージェントがファイルを読み書きしながら進めます。

- [はじめに](./getting-started/) — インストールから、エージェントの接続、最初の会話まで
- [エージェント](./agents/) — つなげるエージェントの一覧と、それぞれの入れ方・ログイン
- [困ったとき](./troubleshooting/) — よくある問題と、見えたエラーの文からの逆引き
