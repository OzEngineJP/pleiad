---
title: 困ったとき
description: よくある問題と、見えたエラーの文からの逆引き。
---

よくある問題を起動・ログイン・会話・更新に分けて並べています。見えた文が分かるときは、下の[エラーの文からの逆引き](#エラーの文からの逆引き)から探してください。

## 起動・開くとき

**Windows で SmartScreen の確認が出る**
初めて開くときに出ます。［詳細情報］→［実行］で進めます。

**「Pleiad の起動に失敗しました」「サーバーの起動が時間切れになりました」「サーバーを起動できませんでした」**
もう一度起動してみてください。続くときは PC を再起動し、セキュリティ対策ソフトが Pleiad の起動を止めていないか確かめてください。

**「サーバーが予期せず終了し、自動で起動し直せませんでした」**
Pleiad を起動し直してください。保存済みの会話は残っています。

**「切断」「サーバーから返事がありません」**
画面を開き直してください。デスクトップ版ならアプリを起動し直します。続くときは PC を再起動してください。

**「接続の認証が切れています。起動時のURLから開き直してください」**
ブラウザー版で、開いていたタブの有効期限が切れています。起動したときの URL（トークン付き）から開き直してください。

## エージェントのインストール

**インストールしたのに「未インストール」のまま**
設定 ›「エージェント設定」で「状態を再確認」を押してください。それでも見つからないときは Pleiad をいったん終了して起動し直してください（入れたばかりの CLI の置き場が、起動済みのアプリに届いていないことがあります）。

**「（エージェント）が見つかりません。インストールしてから再確認してください」**
そのエージェントの CLI が入っていません。[エージェント](./agents/)の一覧から入れ方を開いてインストールし、「状態を再確認」を押してください。

**Claude Agent SDK が「取得できませんでした」**
通信を確かめて、Claude の行の「もう一度取得」を押してください。

## ログイン

**「ログインできませんでした」**
もう一度「ログイン」を押してください。ログインの待ち時間はおよそ 10 分です。待っている間に止めたいときは「やめる」を押します。

**「時間切れになりました」「端末でのログインが終わらなかった」**
端末でのログイン（`agy`、`opencode auth login`、`devin auth login`、`grok login`）は、端末の画面の案内が終わるまで待ってください。終わっているのにこの文が出るときは、もう一度「ログイン」を押してやり直してください。

**「⚠ ログインの有効期限が切れています」**
「ログインし直す」を押して、もう一度ログインしてください。

**リモート・スマホの画面でログインできない**
ログインは、Pleiad が動いている PC（ホスト）の画面で行います。ホスト側の画面でエージェント設定を開いてください。

## 会話の中

**「認証が通りませんでした」「ログインできませんでした」と返ってくる**
エージェントのログインが切れています。設定 ›「エージェント設定」からログインし直してください。

**「この Claude Code は裏のコマンドを止められません。`claude update` で更新してください」**
端末で `claude update` を実行して Claude Code を新しくし、「状態を再確認」を押してください。

**「この codex はバックグラウンド端末を止められません。`codex update` で更新してください」**
端末で `codex update` を実行して codex を新しくし、「状態を再確認」を押してください。

**「MCP に接続できません。接続先・認証・起動コマンドを確認してください」**
設定 ›「プラグイン」に登録した MCP の設定（接続先・起動コマンド）を見直してください。ログインが要るものはログインし直してください。

**「ログインの待ち時間（10 分）を過ぎました。もう一度「ログイン」してください」**
MCP サーバーへのログインの待ち時間が切れています。その MCP の行から「ログイン」をやり直してください。

**「画面がロックされているか、管理者の確認の画面です」**
コンピューターの操作を使っているときに出ます。PC のロックを解除してから続けてください。

**「Pleiad の更新中のため、コンピューターの操作を止めました」**
更新が終わってから、もう一度頼んでください。

**「送れなかった添付があります」「画像の取得が時間内に終わりませんでした」**
その添付を外すか、もう一度付けて送り直してください。

## 更新

**「更新を取得できませんでした」**
ネットワーク接続を確かめて、しばらくしてから設定 ›「アプリ情報・更新」の「確認」を押してください。今のバージョンはそのまま使えます。

**「更新ファイルの安全性を確認できなかったため、適用を中止しました」**
時間をおいてもう一度確かめてください。今のバージョンはそのまま使えます。

**「新しい版を起動できなかったため、前の版で動いています」**
Pleiad を起動し直してください。続くときは、設定 ›「アプリ情報・更新」から再度更新を確かめてください。

**「30 秒待っても止まらない作業がありました。更新は準備済みのまま残ります」**
走っている作業が止まりませんでした。作業が終わるか止めてから、もう一度更新してください。

## エラーの文からの逆引き

| 見えた文 | 意味とやること |
| --- | --- |
| Pleiad の起動に失敗しました | アプリが起動できませんでした。起動し直し、続くなら PC を再起動 |
| サーバーの起動が時間切れになりました / サーバーを起動できませんでした | 中のサーバーが起こせませんでした。起動し直し、続くならセキュリティ対策ソフトの遮断を確認 |
| 切断 / サーバーから返事がありません | 画面とサーバーの間が切れています。画面を開き直す・アプリを起動し直す |
| 接続の認証が切れています。起動時のURLから開き直してください | ブラウザー版のタブの期限切れ。起動時の URL から開き直す |
| 保存データを新しい形式へ移行できませんでした（…）。元のデータは変更していません | この版では起動できません。解決するまで前の版を使うか、サポートへ連絡 |
| 未インストール | CLI が見つかりません。「状態を再確認」、続くなら Pleiad を起動し直す |
| （エージェント）が見つかりません。インストールしてから再確認してください | CLI が入っていません。インストールして「状態を再確認」 |
| ログインできませんでした | ログインをやり直す |
| 時間切れになりました（10 分）/ 端末でのログインが終わらなかった | ログインの待ち時間切れ。端末側が終わったか確かめてやり直す |
| ⚠ ログインの有効期限が切れています | 「ログインし直す」で再ログイン |
| この Claude Code は裏のコマンドを止められません | 端末で `claude update` |
| この codex はバックグラウンド端末を止められません | 端末で `codex update` |
| Grok Build CLI にログインしていません | 端末で `grok login`（ブラウザーが無いときは `grok login --device-auth`） |
| MCP に接続できません | 設定 ›「プラグイン」の MCP の接続先・認証・起動コマンドを確認 |
| ログインの待ち時間（10 分）を過ぎました | MCP のログインをやり直す |
| 画面がロックされているか、管理者の確認の画面です | PC のロックを解除してから続ける |
| Pleiad の更新中のため、コンピューターの操作を止めました | 更新の完了を待ってからやり直す |
| この環境ではコンピューターの操作を使えません | コンピューターの操作はデスクトップ版のホストでだけ使えます |
| この PC では内蔵ブラウザーを使えません（デスクトップ版だけ） | 内蔵ブラウザーはデスクトップ版でだけ使えます |
| エージェントのブラウザー（Chrome）は、この OS・この環境ではまだ使えません | その OS・環境では Chrome の操作は未対応です |
| 送れなかった添付があります。再試行するか外してください | 添付を付け直すか外して送る |
| 画像の取得が時間内に終わりませんでした | 通信を確かめて付け直す |
| このファイルはプレビューできません | その形式はプレビューに対応していません |
| 更新を取得できませんでした | ネットワークを確かめて時間をおいて「確認」 |
| 更新ファイルの安全性を確認できなかったため、適用を中止しました | 時間をおいて再確認。今の版は使えます |
| 新しい版を起動できなかったため、前の版で動いています | Pleiad を起動し直す |
| GitHub の認証情報（GH_TOKEN や GitHub CLI のログイン）が受け付けられませんでした | 配布先の閲覧権限が要ります。GH_TOKEN を確かめるか `gh auth login` をやり直す |
| 30 秒待っても止まらない作業がありました | 作業を止めてから更新をやり直す |

## それでも直らないとき

使っている版は 設定 ›「アプリ情報・更新」で確かめられます。見えた文と、直前にやったことを添えて [GitHub の Issues](https://github.com/OzEngineJP/pleiad/issues) へお知らせください。
