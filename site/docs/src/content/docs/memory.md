bot は、あなたの発言を根拠にした事実のメモ（記憶）を持ち、会話の始まりに渡します。記憶は bot のページの「記憶」で見られます。「あなたについて」（全 bot 共通）と「この bot だけ」の 2 層で、各行は直したり忘れたりできます。

記憶まわりの設定は 設定 ›「記憶」にあります。

## 全般

「会話の区切りで、記録から組み立て直す」のスイッチです。入れている間は、放置した後やエージェントを切り替えた後の会話の区切りで、要約の代わりにあなたの発言・索引・直近のやりとりを記録から組み立て直して渡します（その間、放置した会話の自動圧縮は止まります）。

以前のバージョンで「試験的な機能」にあった設定と同じもので、入切の状態はそのまま引き継がれます。

## bot

「記憶の自動整理」は、決まった時刻に会話を読み直して記憶へ写す仕組みです。**既定はオフ**です。新しく使い始めた人も、前のバージョンから移行した人も、自分で入れるまで動きません。入切を変えても、すでにある記憶は消えません。

- **整理する時刻**: 自動整理を始める時刻（PC の現地時刻）。
- **bot との会話を要約して引き継ぐ**: 静まった bot との会話を要約し、次の会話へ引き継ぎます。自動整理がオンの間だけ動きます。既定はオフで、入切の状態は自動整理を止めても残ります。

自動整理がオフの間、時刻と要約は選べません（値は残ります）。

### 整理に使うエージェント

整理と要約の呼び出しは、1 回きりの内部呼び出しで行います（エージェント・モデルは整理の設定に従います）。Pleiad の会話としても、エージェント側の会話履歴としても残りません。

- **呼び出せるエージェント**: Claude・Codex
- **呼び出せないエージェント**: Antigravity・Devin・Grok・OpenCode — エージェント側に会話を残さないことを確かめられないため、整理・要約は実行されず、状態の行に理由が出ます（ふつうの会話へ切り替わることはありません）

以前の版が内部の整理用に作った会話は、確かなものだけ会話の一覧・検索・最近の場所から外れます（データは消えません）。

### 状態と操作

入切の下の状態の行に、自動整理の今の様子が出ます。

- **オン**: 次の予定を待っています。「今すぐ整理」ですぐに 1 回走らせられます。
- **整理しています**: いま走っています。
- **失敗しました / 止まっています**: 失敗のあとの再試行待ち、または認証などの問題・再試行の上限で止まった状態です。「もう一度」で再開できます。
- **ログインを待っています**: 整理に使うエージェントのログインが切れています。ログインを済ませてください。失敗や停止で止まっている場合は、ログインしたあと「もう一度」で再開します（止まった状態はログインだけでは戻りません）。
- **接続状態は未確認**: エージェントに繋がっているかを受動的には確かめられない状態です。ログインの画面を開きうる接続の確認は、「接続を確認」を押したときだけ行います。

bot のページの「記憶」の見出しにも「自動整理: … ›」が出ます。押すとこのページを開きます。
