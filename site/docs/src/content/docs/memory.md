bot は、あなたの発言を根拠にした事実のメモ（記憶）を持ち、会話の始まりに渡します。記憶は bot のページの「記憶」で見られます。「あなたについて」（全 bot 共通）と「この bot だけ」の 2 層で、各行は直したり忘れたりできます。

記憶まわりの設定は 設定 ›「bot」の「記憶」にあります。

## 渡す場面の 3 つ

各行には、AI へ渡す場面を示す札（「毎回渡す」「このフォルダーのときだけ」「渡さない」。まだ決まっていないものは「渡す場面は未定」）が付きます。

| 札 | 渡し方 |
| --- | --- |
| 毎回渡す | 作業場所に関係なく、会話の始まりに毎回渡します。 |
| このフォルダーのときだけ | その作業フォルダーの会話のときだけ渡します。作業場所は、覚えた会話の作業フォルダーから決まります（git のリポジトリなら、リポジトリの根。worktree は元のリポジトリと同じ場所として扱います）。 |
| 渡さない | 消さずに残しますが、AI には渡しません。一覧で見られ、あとから変えられます。 |

- 会話の始まりに渡す量は、合わせて最大 9,000 トークンです。入りきらない記憶は、関係する話のときに渡ります。
- あなたが書いた記憶は「毎回渡す」になります。bot が書く記憶は、会話に作業場所があれば「このフォルダーのときだけ」、無ければ「毎回渡す」になります。
- 行の「直す」で、本文のほかに渡す場面と、「このフォルダーのときだけ」のときの作業場所を変えられます。
- 「渡す場面は未定」の記憶は、毎晩の整理が決めるまで、今までどおりの渡し方のままです（下の「渡す場面を決める」）。

## 約束と作業の経過

約束や作業の経過は、記憶に書かれません。スレッドに ToDo があれば ToDo へ、無ければ bot の気がかりに置かれます。今ある約束の記憶は「渡さない」に移ります（消えません）。

## 毎晩の整理

設定 ›「bot」の「毎晩、会話から覚え直す」は、決まった時刻（既定は 02:00）に会話を読み直して記憶へ写す仕組みです。**既定はオフ**です。新しく使い始めた人も、前のバージョンから移行した人も、自分で入れるまで動きません。入切を変えても、すでにある記憶は消えません。

新しく覚えるだけでなく、すでにある記憶の渡す場面の付け直しも行います（1 回に 20 件まで。bot のページの「記憶」の整理の結果に「渡す場面を決め直した N 件」が出ます）。記憶を全部は送らず、関係するものだけを送ります。

- **時刻**: 整理を始める時刻（PC の現地時刻）。
- **スレッドの話を、次のスレッドへ引き継ぐ**: 静かになった bot のスレッドを短くまとめ、同じ bot の次のスレッドの最初に渡します。毎晩の整理がオンの間だけ動きます。既定はオフで、入切の状態は毎晩の整理を止めても残ります。

毎晩の整理がオフの間、時刻と引き継ぎは選べません（値は残ります）。

### 整理に使うエージェント

整理と要約の呼び出しは、1 回きりの内部呼び出しで行います（エージェント・モデルは整理の設定に従います）。Pleiad の会話としても、エージェント側の会話履歴としても残りません。

- **呼び出せるエージェント**: Claude・Codex
- **呼び出せないエージェント**: Antigravity・Devin・Grok・OpenCode — エージェント側に会話を残さないことを確かめられないため、整理・要約は実行されず、状態の行に理由が出ます（ふつうの会話へ切り替わることはありません）

以前の版が内部の整理用に作った会話は、確かなものだけ会話の一覧・検索・最近の場所から外れます（データは消えません）。

### 状態と操作

入切の下の状態の行に、毎晩の整理の今の様子が出ます。

- **オン**: 次の予定を待っています。「今すぐ整理」ですぐに 1 回走らせられます。
- **整理しています**: いま走っています。
- **失敗しました / 止まっています**: 失敗のあとの再試行待ち、または認証などの問題・再試行の上限で止まった状態です。「もう一度」で再開できます。
- **ログインを待っています**: 整理に使うエージェントのログインが切れています。ログインを済ませてください。失敗や停止で止まっている場合は、ログインしたあと「もう一度」で再開します（止まった状態はログインだけでは戻りません）。
- **接続状態は未確認**: エージェントに繋がっているかを受動的には確かめられない状態です。ログインの画面を開きうる接続の確認は、「接続を確認」を押したときだけ行います。

bot のページの「記憶」の見出しにも「毎晩の整理: … ›」が出ます。押すとこのページを開きます。「記憶を見る」の行には bot の名前が並び、押すとその bot のページへ行けます。

## 渡す場面を決める

「渡す場面は未定」の記憶は、毎晩の整理の最後に、AI が「毎回渡す」「このフォルダーのときだけ」「渡さない」へ少しずつ決めます。**始める操作はありません**。毎晩の整理がオンの間、1 晩に最大 500 件まで進みます（1,490 件ならおよそ 3 晩）。オフの間は進みません。決めるまでは、今までどおりの渡し方のままです。

- 記憶の本文は書き換えません。付けるのは渡す場面と作業場所だけです。作業場所が決まらない記憶は「渡さない」になります。
- 整理に使うエージェント（上の「整理に使うエージェント」と同じ）で行います。
- 設定 ›「bot」の状態には、「渡す場面が決まっていない記憶 N 件」と「毎晩 500 件ずつ決めます（あと N 晩ほど）」、決めた分の内訳が出ます。前の晩にうまくいかなかったときは、次の晩に続きから決めます。
- 止めたいときは「毎晩、会話から覚え直す」を切ります。済んだ分は残ります。
- 決めた分は［決めた分を取り消す］で外せます（毎晩の整理が切れていても使えます）。決めた後にあなたが直した記憶は戻しません。取り消した後は、「毎晩、会話から覚え直す」を入れ直すまで決め直しません。
