bot のページの「記憶」では、記憶が「やりかけ」「決めたこと」「好み」「分担」「メモ」「完了」「やめたこと」のフォルダーに分かれます。「この bot の全スレッド」と「全 bot 共通」を切り替えられます。検索は閉じたフォルダーの記憶も対象です。記憶を開くと出どころを確認し、本文や渡す場面を直したり、記憶を忘れたりできます。

## 渡す場面の 3 つ

記憶の詳細には、AI へ渡す場面を示す札（「毎回渡す」「このフォルダーのときだけ」「渡さない」。まだ決まっていないものは「渡す場面は未定」）が付きます。

| 札 | 渡し方 |
| --- | --- |
| 毎回渡す | 作業場所に関係なく、会話の始まりに毎回渡します。 |
| このフォルダーのときだけ | その作業フォルダーの会話のときだけ渡します。作業場所は、覚えた会話の作業フォルダーから決まります（git のリポジトリなら、リポジトリの根。worktree は元のリポジトリと同じ場所として扱います）。 |
| 渡さない | 消さずに残しますが、AI には渡しません。一覧で見られ、あとから変えられます。 |

- 会話の始まりに渡す量は、合わせて最大 9,000 トークンです。入りきらない記憶は、関係する話のときに渡ります。
- あなたが書いた記憶は「毎回渡す」になります。bot が書く記憶は、会話に作業場所があれば「このフォルダーのときだけ」、無ければ「毎回渡す」になります。
- 詳細の「直す」で、本文のほかに渡す場面と、「このフォルダーのときだけ」のときの作業場所を変えられます。
- 「渡す場面は未定」の記憶は、毎晩の整理が決めるまで、今までどおりの渡し方のままです（下の「渡す場面を決める」）。

## 約束と作業の経過

気がかりと継続中の約束は「やりかけ」に、履行済みのものは「完了」に、取りやめたものは「やめたこと」にあります。気がかりの詳細で期限と再確認条件を確認できます。追跡を止めるには「この件を追うのをやめる」を押します。以前の約束で状態が分からないものは「メモ」にあります。

## 毎晩の記憶の整理

設定 ›「bot」の「毎晩、記憶を整理する」をオンにすると、決めた時刻（既定は PC の現地時刻 02:00）に、人の発言を根拠に記憶を追加・更新し、約束や気がかりの状態を見直します。既定はオフです。「記憶を見る」から bot を選ぶと、記憶の一覧が開きます。

「記憶を整理できませんでした。」と出たら「再試行」を押してください。整理に使うエージェントの認証が必要な場合は、同じ欄からログインできます。整理は Claude または Codex の内部呼び出しで実行します。

## 渡す場面を決める

毎晩の記憶の整理は、「渡す場面は未定」の既存の記憶を 1 晩に最大 500 件まで振り分けます。決まるまでは今までの渡し方が続きます。作業場所が決まらない記憶は「渡さない」になります。個別の記憶を開くと渡す場面を変更できます。
