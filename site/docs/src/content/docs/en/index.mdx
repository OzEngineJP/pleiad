Pleiad is an app for giving work to AI agents. You pick an agent and a working directory, send instructions in a conversation, and the agent works through your files.

- [Getting started](./getting-started/) — install, connect an agent, start your first conversation
- [Agents](./agents/) — the agents Pleiad can connect to, and how to install and sign in to each
- [Troubleshooting](./troubleshooting/) — common problems, and what to do for the error text you see
