## インストールする

[ダウンロード](https://pleiad.dev/download/)から OS に合うものを入れます。

- **Windows**（10 / 11）: x64 または ARM64 のインストーラー。初めて開くとき SmartScreen の確認が出ます。［詳細情報］→［実行］で進めます。
- **macOS**（13 以降）: Apple Silicon / Intel のインストーラー。
- **Linux**: デスクトップ版はありません。[ソースから動かすブラウザー版](https://github.com/OzEngineJP/pleiad#run-from-source)があります。
- **Android**（13 以降）: PC に入れた Pleiad にスマホからつなぐアプリ（APK）です。使うには中継サーバーの用意が要ります。

デスクトップ版は更新を自動で知らせます。設定 ›「アプリ情報・更新」から手動でも確かめられます。会話で「Pleiad を更新して」「再起動して」と頼むと、エージェントが更新の確認から適用、同じ版での再起動まで行い、つながり直した後に結果を確かめます（適用と再起動は会話の承認の設定に従います）。

## エージェントをつなぐ

Pleiad は、AI のエージェントと話すための器です。使うエージェントごとに、そのエージェントの CLI（コマンド）とログインが要ります。料金・契約は各エージェントの提供元に従います。

1. エージェントの CLI をインストールします（入れ方は各エージェントの案内。設定 ›「エージェント設定」の「インストール」からも開けます）。
2. Pleiad の 設定 ›「エージェント設定」で「状態を再確認」を押すと、入った CLI を見つけます。「インストール」を押して待っている間は、入ったことを Pleiad が自動で見つけるので、押さなくても行が切り替わります。
3. エージェントの行の「接続先」を開き、「CLI のログイン」のカードの「ログインする」を押します。
4. 終わると行が「ログイン中」になり、会話で使えます。

ログインの進み方はエージェントごとに違います。

| エージェント | ログインのしかた | ログアウト |
| --- | --- | --- |
| Claude | ブラウザーでログインの画面を開き、Anthropic のアカウントで許可 | 「CLI のログイン」のカードの「ログアウト」 |
| Codex | ブラウザーでログインの画面を開き、ChatGPT のアカウントで許可 | 「CLI のログイン」のカードの「ログアウト」 |
| Antigravity | 表示されたコマンド（`agy`）を端末で実行し、Google にログイン | `agy` 側で行う（資格情報は OS の資格情報ストア。「CLI のログイン」のカードに「ログアウト」は出ず、外し方の 1 行が出る） |
| OpenCode | `opencode auth login` を端末で実行し、つなぐ接続先を選ぶ | `opencode auth logout` を端末で実行 |
| Devin | `devin auth login` を端末で実行し、ブラウザーで許可 | Pleiad の「ログアウト」 |
| Grok | `grok login` を端末で実行（ブラウザーが無いときは `grok login --device-auth`） | 「CLI のログイン」のカードの「ログアウト」 |

- Claude・Codex・OpenCode・Grok・Antigravity の「接続先」には、「CLI のログイン」のほかに、足したアカウントと互換の接続先が同じ一覧に並びます。「＋ 接続先を追加」で足し、新しい会話で使うものは「既定にする」で決めます。Devin の行は、今までどおり行の「ログイン」「ログアウト」です。
- 待ち時間はおよそ 10 分です。止めたいときは「やめる」を押します。
- Claude は、CLI のほかに Claude Agent SDK も要ります。Claude の行の「取得する」を押します（CLI のインストールやログインを待たずに取得できます）。取得できなかったときは、行の「もう一度取得」を押します。
- OpenCode はログインしなくても無料のモデルを使えます。ほかの接続先を使うときにログインします。
- スマホや他の PC から開いている画面では、その端末ではなく Pleiad が動いている PC（ホスト）のほうでログインします。

つなげられるエージェントの一覧は[エージェント](./agents/)にあります。

## 最初の会話を始める

初めて起動すると「Pleiad へようこそ」の画面が出ます。

1. **使用するエージェント**を選びます。一覧には全部のエージェントが出て、入っていないものには「インストール」、ログインしていないものには「ログイン」がその場に出るので、この画面からつなぐこともできます。インストールのコマンドが分かるエージェントは、行にコマンドと「コピー」が出ます。
2. **作業ディレクトリ**を選びます。エージェントはこのフォルダーの中のファイルを読み書きします。
3. 「会話を始める」を押します。

あとは入力欄に頼みたいことを書いて送るだけです。ファイルの変更やコマンドの実行など、危なさに応じて承認の確認が出ます（「許可」「常に許可」「拒否」で答えます）。

使えるエージェントが 1 つもないうちは、この画面は閉じられません（「会話を始める」も押せません）。1 つ使えるようになると、そのエージェントが選ばれて先へ進めます。一度この画面を終えた人でも、起動したときに使えるエージェントが 0 件だと「使えるエージェントがありません」の画面が出ます。

送信に少し時間がかかるときは、入力欄に「送信中」が表示されます。作業中の会話ですぐに渡せない発言には、いつ送られるかが表示されます。

会話を送ろうとしたときにエージェントが見つからなかった場合は、送信の行に「再送する」「取り消す」が出ます。その場で入れ直したりログインし直したりして、「再送する」で続けられます。

エージェントと作業ディレクトリは会話画面でいつでも変えられます。エージェントの追加やログインは、設定 ›「エージェント設定」からいつでもできます。

会話の ToDo は、作業前の確認、3 手順以上の作業の追加、開始・完了と成果物の記録をエージェントに促します。すべてのエージェントと委譲された会話で既定で有効です。止めるには、設定の「指示」›「Pleiad の指示」で「会話の ToDo」をオフにします。

## 可視化とファイルを右の欄で開く

エージェントが HTML や可視化を作ると、会話の中にカードとして表示されます。右の欄（会話のブラウザー）のタブでは、ファイル・フォルダー・git・プラグインと同じようにページとして開けます。

- カードの「ページで開く」は、**元の HTML の今の内容**を右の欄で開きます。元のファイルが消えていれば、会話に保存した当時の版へ切り替えて知らせます。
- タブの「＋」（新しいタブ）の「この会話」には、変更・プラグインの入口と、その会話の可視化の一覧（新しい順 5 件＋「すべて表示」）があります。行を押すと元の HTML を開き、元の記録が無いものは「保存した版」をそのまま開きます。
- 「保存した版」のタブは、アドレスバーに「保存した版」の札と題を出します。会話に残る当時の見た目の写しで、今の元のファイルとは別物です。
- カードには「既定のブラウザーで開く」のボタンがあり、行やカードの「⋯」からは元のファイルをエクスプローラーで開く・パスをコピーする・保存した版を開く・HTML を保存する操作を選べます（元のファイルの記録が無いものは、パスを使う操作は出ません。他の端末から開いている画面では、Pleiad が動いている PC を操作する項目は出しません）。

## 脇の「チャット」と「bot」

脇の上の切り替えで、「チャット」と「bot」の 2 つの面を選びます。

- **チャット**: 普通の会話だけが並びます。
- **bot**: ルーティン・bot・チャンネルが並びます。Bots 一覧は 1 体につき 1 行です。DM（ダイレクトメッセージ）のスレッドは、DM の中の元の投稿から開きます。bot に話しかけた一時チャットは「チャット」の一覧に表示されます。

## bot を作る

bot の面の「Bots」の見出しの［＋］を押します。bot がまだ無いときは、bot の面を開くと 1 段目から始まります。

1. **名前**を入れます。
2. **色**を選びます。
3. **人格**（性格・役割・話し方）を書いて、［作る］を押します。人格は空でも作れます。

［次へ］［戻る］で段を行き来できます。エージェント・モデル・承認モードは既定のまま作られ、あとから bot のページで変えられます。作ると、その bot の DM が開きます。

## bot の色を変える

bot の顔は、大きな目の顔 1 つです。選べるのは 8 色の色だけで、絵文字と画像は選べません。bot のページで顔を押して色を選ぶと、すぐに変わります。

以前に絵文字や画像を設定した bot も、色の顔で表示します（保存した絵文字・画像は残りますが、表示には使いません）。

## @ で bot を呼ぶ

チャンネルとそのスレッドの入力欄で `@` を打つと、bot の候補が出ます。選んだ bot は「顔＋名前」の 1 つの塊になり、Backspace 1 回か塊の「×」で外せます。何体でも並べられ、並べた全員に届きます。送った後の発言でも、宛先は bot の色の塊で出ます。

- **@ が無いとき**: DM ではその bot に、bot が答えたスレッドでは前に答えた bot に届きます。チャンネルの最初の投稿や、bot がまだ答えていないスレッドでは、bot は反応しません。送る前に入力欄の上に「誰も呼ばれていないので、bot は反応しません」と［@〈bot〉を呼ぶ］が出るので、押すと塊が入ります。
- **メンバーでない bot**: チャンネルのメンバーでない bot を `@` で呼ぶと、投稿のときにメンバーに足し、「〈名前〉をメンバーに足しました」と知らせます。
- **bot の動かし方**: bot のページでエージェント、モデル、接続先の候補を順に並べられます。使用量の上限に当たると、承認モードに合う次の候補を使います。投稿や外部操作を始めていれば切り替えを知らせ、次の応答から新しい候補を使います。作業フォルダーと承認モードも bot のページで設定します。

## bot の次の発言候補を使う

bot がチャンネル、スレッド、または DM で返答すると、入力欄に会話に合わせた次の発言候補が表示されます。候補を選ぶと入力欄に下書きとして入るので、編集してから送信できます。候補を選んだだけでは送信されません。キーボードでは Tab で候補を選び、Shift+Tab で切り替えられます。

## 作成した bot を削除する

bot のページや Bots 一覧の「⋯」から「bot を削除…」を選びます。Bots 一覧では、右クリック、Shift+F10、メニューキーでも同じメニューが開きます。確認画面で削除する情報と残す会話を確かめ、「削除する」を押します。組み込みの bot は削除できません。

削除すると、その bot の設定・活動メモ・専用の記憶を消し、ルーティンを一時停止します。共通の「あなたについて」の記憶は残ります。過去の会話は「チャット」から閲覧できますが、続けて送信することはできません。作業中・承認待ち・送信待ちのときは、処理が終わってから削除してください。削除は元に戻せません。
