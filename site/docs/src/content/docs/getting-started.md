## インストールする

[ダウンロード](https://pleiad.dev/download/)から OS に合うものを入れます。

- **Windows**（10 / 11）: x64 または ARM64 のインストーラー。初めて開くとき SmartScreen の確認が出ます。［詳細情報］→［実行］で進めます。
- **macOS**（13 以降）: Apple Silicon / Intel のインストーラー。
- **Linux**: デスクトップ版はありません。[ソースから動かすブラウザー版](https://github.com/OzEngineJP/pleiad#run-from-source)があります。
- **Android**（13 以降）: PC に入れた Pleiad にスマホからつなぐアプリ（APK）です。使うには中継サーバーの用意が要ります。

デスクトップ版は更新を自動で知らせます。設定 ›「アプリ情報・更新」から手動でも確かめられます。

## エージェントをつなぐ

Pleiad は、AI のエージェントと話すための器です。使うエージェントごとに、そのエージェントの CLI（コマンド）とログインが要ります。料金・契約は各エージェントの提供元に従います。

1. エージェントの CLI をインストールします（入れ方は各エージェントの案内。設定 ›「エージェント設定」の「インストール」からも開けます）。
2. Pleiad の 設定 ›「エージェント設定」で「状態を再確認」を押すと、入った CLI を見つけます。
3. エージェントの行の「ログイン」を押します。
4. 終わると行が「ログイン中」になり、会話で使えます。

ログインの進み方はエージェントごとに違います。

| エージェント | ログインのしかた | ログアウト |
| --- | --- | --- |
| Claude | ブラウザーでログインの画面を開き、Anthropic のアカウントで許可 | Pleiad の「ログアウト」 |
| Codex | ブラウザーでログインの画面を開き、ChatGPT のアカウントで許可 | Pleiad の「ログアウト」 |
| Antigravity | 表示されたコマンド（`agy`）を端末で実行し、Google にログイン | `agy` 側で行う（資格情報は OS の資格情報ストア） |
| OpenCode | `opencode auth login` を端末で実行し、つなぐ接続先を選ぶ | `opencode auth logout` を端末で実行 |
| Devin | `devin auth login` を端末で実行し、ブラウザーで許可 | Pleiad の「ログアウト」 |
| Grok | `grok login` を端末で実行（ブラウザーが無いときは `grok login --device-auth`） | Pleiad の「ログアウト」 |

- 待ち時間はおよそ 10 分です。止めたいときは「やめる」を押します。
- Claude は、初めて使うときに Claude Agent SDK の取得も要ります（Claude の行に案内が出ます）。
- OpenCode はログインしなくても無料のモデルを使えます。ほかの接続先を使うときにログインします。
- スマホや他の PC から開いている画面では、その端末ではなく Pleiad が動いている PC（ホスト）のほうでログインします。

つなげられるエージェントの一覧は[エージェント](./agents/)にあります。

## 最初の会話を始める

初めて起動すると「Pleiad へようこそ」の画面が出ます。

1. **使用するエージェント**を選びます。一覧には全部のエージェントが出て、入っていないものには「インストール」、ログインしていないものには「ログイン」がその場に出るので、この画面からつなぐこともできます。
2. **作業ディレクトリ**を選びます。エージェントはこのフォルダーの中のファイルを読み書きします。
3. 「会話を始める」を押します。

あとは入力欄に頼みたいことを書いて送るだけです。ファイルの変更やコマンドの実行など、危なさに応じて承認の確認が出ます（「許可」「常に許可」「拒否」で答えます）。

エージェントと作業ディレクトリは会話画面でいつでも変えられます。エージェントの追加やログインは、設定 ›「エージェント設定」からいつでもできます。

## 可視化とファイルを右の欄で開く

エージェントが HTML や可視化を作ると、会話の中にカードとして表示されます。右の欄（会話のブラウザー）のタブでは、ファイル・フォルダー・git・プラグインと同じようにページとして開けます。

- カードの「ページで開く」は、**元の HTML の今の内容**を右の欄で開きます。元のファイルが消えていれば、会話に保存した当時の版へ切り替えて知らせます。
- タブの「＋」（新しいタブ）の「この会話」には、変更・プラグインの入口と、その会話の可視化の一覧（新しい順 5 件＋「すべて表示」）があります。行を押すと元の HTML を開き、元の記録が無いものは「保存した版」をそのまま開きます。
- 「保存した版」のタブは、アドレスバーに「保存した版」の札と題を出します。会話に残る当時の見た目の写しで、今の元のファイルとは別物です。
- カードには「既定のブラウザーで開く」のボタンがあり、行やカードの「⋯」からは元のファイルをエクスプローラーで開く・パスをコピーする・保存した版を開く・HTML を保存する操作を選べます（元のファイルの記録が無いものは、パスを使う操作は出ません。他の端末から開いている画面では、Pleiad が動いている PC を操作する項目は出しません）。

## bot のアイコンを変える

bot のページで、右下に鉛筆の付いた丸いアイコンを押します。「未設定」「絵文字を選ぶ」「画像を選ぶ」から選べます。未設定では名前の先頭の 1 文字が表示されます。画像は PNG・JPEG・WebP、10 MB まで使えます。

画像を使っているときは、同じ丸いアイコンから画像の変更・削除ができます。絵文字や未設定を選ぶと画像は外れます。「画像を削除」は画像だけを外し、以前の絵文字または名前の先頭文字に戻します。

## 作成した bot を削除する

bot のページで「DM を開く」の横にある「⋯」を押し、「bot を削除…」を選びます。サイドバーの bot を右クリックしても同じ操作ができます。確認画面で削除する情報と残す会話を確かめ、「削除する」を押します。組み込みの bot は削除できません。

削除すると、その bot の設定・活動メモ・専用の記憶を消し、ルーティンを一時停止します。共通の「あなたについて」の記憶は残ります。過去の会話は「一時チャット」から閲覧できますが、続けて送信することはできません。作業中・承認待ち・送信待ちのときは、処理が終わってから削除してください。削除は元に戻せません。
