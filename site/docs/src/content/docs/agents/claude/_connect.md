## つなぎ方

1. Claude Code をインストールします（[導入の案内](https://code.claude.com/docs/en/setup)）。
2. Pleiad の 設定 ›「エージェント設定」で、Claude の行の「状態を再確認」を押します。
3. 「ログイン」を押すと、ログインの画面のリンクが出ます。「ログインの画面を開く」でブラウザーが開くので、Anthropic のアカウントで許可します（ブラウザーが開かないときは「リンクをコピー」して開きます）。
4. 完了を待ちます（およそ 10 分で時間切れになります）。行が「ログイン中」になったら使えます。

はじめて使うときは、Anthropic の Claude Agent SDK の取得も要ります。Claude の行に案内が出るので、「取得する」を押します。

- ログアウトは、Claude の行の「ログアウト」からできます。
- ログインの途中で止めたいときは「やめる」を押します。
