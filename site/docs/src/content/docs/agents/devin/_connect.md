## つなぎ方

1. Devin CLI をインストールします（[導入の案内](https://docs.devin.ai/cli)）。
2. Pleiad の 設定 ›「エージェント設定」で、Devin の行の「状態を再確認」を押します。
3. 「ログイン」を押すと、端末で実行するコマンド（`devin auth login`）が出ます。「コピー」して端末で実行し、開いたブラウザーで Devin にログインします（Devin のログインは端末からしか行えません）。
4. 終わると行が自動で「ログイン中」に切り替わります（およそ 10 分で時間切れになります）。

- ログアウトは、Devin の行の「ログアウト」からできます（`devin auth logout` が実行されます）。
- 待っているログインを止めたいときは「やめる」を押します。
