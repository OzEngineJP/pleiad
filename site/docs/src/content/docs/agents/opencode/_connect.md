## つなぎ方

1. OpenCode をインストールします（[導入の案内](https://opencode.ai/docs/)）。
2. Pleiad の 設定 ›「エージェント設定」で、OpenCode の行の「状態を再確認」を押します。

ログインしなくても、OpenCode Zen の無料のモデルは使えます。ほかの接続先（プロバイダー）を使うときは、次のようにログインします。

3. 「ログイン」を押すと、端末で実行するコマンド（`opencode auth login`）が出ます。「コピー」して端末で実行し、つなぐ接続先を選んでログインします。
4. 終わると行が自動で「ログイン中」に切り替わります（およそ 10 分で時間切れになります）。

- 接続先を外す（ログアウトに相当）は、端末で `opencode auth logout` を実行します。Pleiad からは外せません。
- 待っているログインを止めたいときは「やめる」を押します。
