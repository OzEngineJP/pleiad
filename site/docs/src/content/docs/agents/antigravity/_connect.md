## つなぎ方

1. Antigravity CLI（`agy`）をインストールします（[導入の案内](https://antigravity.google/docs/cli/install/)）。
   - Pleiad は `agy acp` で動かすので、`agy` は 1.5.15 以降が必要です。古いときは端末で `agy update` を実行してください。
2. Pleiad の 設定 ›「エージェント設定」で、Antigravity の行の「状態を再確認」を押します。
   - Windows では、インストーラーが `%LOCALAPPDATA%\agy\bin` に置き、そのあと `agy install` が PATH を書きます。見つからないときは「状態を再確認」を押すか、Pleiad を起動し直してください。
3. 「ログイン」を押すと、端末で実行するコマンドが出ます。「コピー」して端末で実行し、画面の案内に沿って Google のアカウントでログインします（Antigravity のログインは端末からしか行えません）。
4. 終わると行が自動で「ログイン中」に切り替わります（およそ 10 分で時間切れになります）。

- Antigravity からのログアウトは Pleiad からはできません。`agy` 側で行ってください（資格情報は OS の資格情報ストアにあります）。
- 待っているログインを止めたいときは「やめる」を押します。

## 2 つ目の Google アカウントを足す

仕事用と個人用のように、目的の違うアカウントを分けて使えます。上の手順でログインしたアカウントが 1 つ目で、そのまま使います。

1. 「接続先」を開き、「＋ 接続先を追加」→「公式のアカウント」を押します。
2. 注意の画面が出ます。使用量の上限を避けるためにアカウントを自動で順に回す使い方は、Google の FAQ で個人向けプランのサポート対象外とされています。内容を確かめ、「理解して追加する」を押します（「やめる」で中止）。
3. 名前（「仕事用」など）を入れて「足してログインする」を押します。開いたブラウザーで Google にログインします。

- 2 つ目以降のログインの情報は、Pleiad のデータの置き場にあるそのアカウント専用のフォルダーに、ファイルとして保存されます（本人の Windows ユーザーだけが読める設定です）。1 つ目の OS の資格情報ストアは変わりません。
- 「この版の agy では 2 つ目以降のアカウントを分けられません」と出たときは、`agy update` で更新してからもう一度お試しください。
- Pleiad のデータの置き場がユーザーフォルダーと別のドライブにあると、2 つ目以降は使えません。
- 「このアカウントでログインしてください」と出たときは、そのアカウントの「ログインする」を押します。
