## つなぎ方

1. Grok Build CLI（`grok`）をインストールします（[導入の案内](https://x.ai/cli)）。
2. Pleiad の 設定 ›「エージェント設定」で、Grok の行の「状態を再確認」を押します。
3. 「ログイン」を押すと、端末で実行するコマンド（`grok login`）が出ます。「コピー」して端末で実行し、画面の案内に沿って Grok にログインします（Grok のログインは端末からしか行えません。ブラウザーが無い環境では `grok login --device-auth` を使います）。
4. 終わると行が自動で「ログイン中」に切り替わります（およそ 10 分で時間切れになります）。

- ログアウトは、Grok の行の「ログアウト」からできます（`grok logout` が実行されます）。
- 待っているログインを止めたいときは「やめる」を押します。
