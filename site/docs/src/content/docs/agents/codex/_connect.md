## つなぎ方

1. Codex CLI をインストールします（[導入の案内](https://developers.openai.com/codex/cli/)）。
2. Pleiad の 設定 ›「エージェント設定」で、Codex の行の「状態を再確認」を押します。
3. 「ログイン」を押すと、ログインの画面のリンクが出ます。「ログインの画面を開く」でブラウザーが開くので、ChatGPT のアカウントで許可します（ブラウザーが開かないときは「リンクをコピー」して開きます）。
4. 完了を待ちます（およそ 10 分で時間切れになります）。行が「ログイン中」になったら使えます。

- ログアウトは、Codex の行の「ログアウト」からできます。
- ログインの途中で止めたいときは「やめる」を押します。
